---
title: Swiplets
---

A swiplet is an automation app that runs inside Swipt. It includes:

- UI: A native SwiftUI interface that opens in Swipt.
- Actions: Functions you can call from the UI, Shortcuts, and the Swipt API.
- Service: Automation that keeps running after you turn it on.

## Install Swiplets

You can install a swiplet from a `.swiplet` package, but we recommend using a swiplet repository, which lets you install and update multiple swiplets.

Swipt includes the Official Swiplets repository, with source code at [swipt-automation/official-swiplets](https://github.com/swipt-automation/official-swiplets). Read its documentation to learn what swiplets can do.
