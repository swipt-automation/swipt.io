## Overview

Swipt is an automation platform.

## Requirements

- Sideloading
- iOS 27 (First-tier support)
- iOS 17.4–26 (Requires an additional Mac, Windows, or Linux device to create a pairing file. I don’t have physical devices for testing, so support will rely heavily on external contributions.)

## Sideload with a Mac

If you don’t want to install a standalone sideloading framework, we recommend the `sideload` tool built into the Swipt CLI.

It signs and installs Swipt with Xcode, so it can:

- Use the Apple Account you’re already signed in to, without asking you to sign in again.
- Configure Swipt to use your Mac’s existing pairing with the device, without pairing again on the device.
- Trust the free developer certificate and perform other initial setup on your device.

In Terminal, run:

```shell
npm install -g @swipt/cli
swipt sideload install
```

Then follow the prompts to choose the device to install on and the team to sign with.

Swipt completes almost all of the setup automatically, but you still need to start the Loopback VPN. See [Setup](./setup.mdx).

```shell
swipt sideload update # Update Swipt or renew its expiration
swipt sideload uninstall # Uninstall Swipt
```
