## Ikhtisar

Swipt adalah platform otomatisasi.

## Persyaratan

- Sideload
- iOS 27 (Dukungan tingkat pertama)
- iOS 17.4–26 (Memerlukan perangkat Mac, Windows, atau Linux tambahan untuk membuat file pemasangan. Saya tidak memiliki perangkat fisik untuk pengujian, sehingga dukungan akan sangat bergantung pada kontribusi eksternal.)

## Sideload dengan Mac

Jika Anda tidak ingin menginstal framework sideload mandiri, disarankan menggunakan alat `sideload` bawaan Swipt CLI.

Alat ini menggunakan Xcode untuk menandatangani dan menginstal Swipt, sehingga dapat:

- Menggunakan Akun Apple yang sudah Anda pakai untuk masuk, tanpa meminta Anda masuk lagi.
- Mengonfigurasi Swipt agar menggunakan pemasangan yang sudah ada antara Mac Anda dan perangkat, tanpa perlu dipasangkan lagi di perangkat.
- Memercayai sertifikat pengembang gratis dan melakukan penyiapan awal lainnya di perangkat Anda.

Di Terminal, jalankan:

```shell
npm install -g @swipt/cli
swipt sideload install
```

Lalu, ikuti petunjuk untuk memilih perangkat tempat Swipt diinstal dan tim yang digunakan untuk menandatangani.

Swipt menyelesaikan hampir semua penyiapan secara otomatis, tetapi Anda tetap perlu mengaktifkan VPN Loopback. Lihat [Penyiapan](./setup.mdx).

```shell
swipt sideload update # Perbarui Swipt atau perpanjang masa berlakunya
swipt sideload uninstall # Hapus instalan Swipt
```
