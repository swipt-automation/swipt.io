## Dan par med din enhed

Swipt skal danne par med din enhed for at oprette forbindelse til enhedens udviklertjenester.

Parringen konfigureres automatisk, hvis du har sideloadet Swipt med Swipt CLI. Følg ellers instruktionerne i appen for at danne par:

- [Jitterbug](https://github.com/osy/Jitterbug): `.mobiledevicepairing`

## Loopback-VPN

Swipt skal bruge et loopback-VPN for at oprette forbindelse til udviklertjenester. Følgende software understøttes:

#### LocalDevVPN

Installer appen fra [App Store](https://apps.apple.com/app/id6755608044), og aktiver VPN.

#### sing-box

Installer appen fra [App Store](https://apps.apple.com/app/id6785326793), skriv en korrekt konfiguration, og aktiver VPN.

Du skal konfigurere `tun.loopback_address` og `tun.route_address`.

Eksempel på konfiguration:

```json
{
  "inbounds": [
    {
      "type": "tun",
      "address": "172.19.0.1/30",
      "auto_route": true,
      "loopback_address": "10.7.0.1",
      "route_address": "10.7.0.1/32"
    }
  ],
  "route": {
    "auto_detect_interface": true
  }
}
```

Hvis du kører sing-box på en gateway, f.eks. en router, virker det for hele det lokale netværk.

#### Clash

Installer appen fra [App Store](https://apps.apple.com/app/id6794257189), skriv en korrekt konfiguration, og aktiver VPN.

Du skal konfigurere `tun.loopback-address`:

```yaml
tun:
  loopback-address:
    - 10.7.0.1
```

#### Software med lukket kildekode

Hvis du abonnerer på og bruger Surge, skal du konfigurere `General.tun-included-routes` og `IP Rewrite`:

```ini
[General]
tun-included-routes = %INSERT% 10.7.0.1/32

[IP Rewrite]
10.7.0.1 = reflect
```

Swipt kræver ikke `ipv6-vif = disabled`.

Spørg udviklerne af andre Surge-lignende apps uden offentlig dokumentation om, hvordan de konfigureres.

## Automatisk oplåsning

Gem din adgangskode, så Swipt automatisk kan låse din enhed op, når den er låst.

Swipt CLI kan nærmere bestemt låse din enhed op for at starte Swipt API/MCP, og Swipt CLI, MCP og installerede Swiplets kan låse din enhed op for at betjene den.
