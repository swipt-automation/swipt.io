## Susiejimas su įrenginiu

„Swipt” turi susisieti su jūsų įrenginiu, kad galėtų prisijungti prie jo kūrėjo paslaugų.

Jei „Swipt” įdiegėte šoniniu įkėlimu naudodami „Swipt CLI”, susiejimas nustatomas automatiškai. Kitu atveju susiekite vykdydami nurodymus:

Jei naudojate „iOS/iPadOS 27”, galite susieti pačiame įrenginyje vykdydami programoje pateikiamus nurodymus:

Jei susieti įrenginyje nepavyksta, sukurkite pranešimą apie problemą („issue”).

Jei naudojate ankstesnę „iOS” versiją ir turite „Mac” kompiuterį, įkėlę „Swipt” šoniniu būdu rankiniu būdu vis tiek galite nustatyti susiejimą naudodami `swipt sideload setup`. Kitu atveju turite susieti naudodami kitą programinę įrangą.

Galite importuoti susiejimo failus, sukurtus beveik bet kokia kita programine įranga, pavyzdžiui:

- [Jitterbug](https://github.com/osy/Jitterbug): `.mobiledevicepairing`
- [idevice](https://github.com/jkcoxson/idevice): `ios_pairing_file.plist`
- [go-ios](https://github.com/danielpaulus/go-ios): `selfIdentity.plist`

Štai dažniausias būdas gauti susiejimo failą:

1. Atsisiųskite ir įdiekite „[iloader](https://iloader.app)”. „Windows” sistemoje pirmiausia įdiekite „[iTunes](https://www.apple.com/itunes/download/win64)”. „Linux” sistemoje įdiekite `usbmuxd`, jei jis nėra iš anksto įdiegtas.
2. Prijunkite „iPhone” arba „iPad” prie kompiuterio USB kabeliu. Jei būsite paraginti, pasitikėkite kompiuteriu ir įveskite slaptakodį.
3. Atidarykite „iloader” ir pasirinkite savo „iPhone” arba „iPad”.
4. Pasirinkite „Manage Pairing File”.
5. Pasirinkite „Export (Not Recommended)”, tada pasirinkite „Confirm” ir išsaugokite susiejimo failą.
6. Perkelkite susiejimo failą į „iPhone” arba „iPad”, pavyzdžiui, naudodami „AirDrop” arba „iCloud Drive”.

Jei anksčiau esate įdiegę „SideStore”, greičiausiai jau turite susiejimo failą!

## Grįžtamojo ryšio VPN

Programai „Swipt” reikia grįžtamojo ryšio VPN, kad galėtų prisijungti prie kūrėjo paslaugų. Palaikoma ši programinė įranga:

#### LocalDevVPN

Įdiekite programą iš „[App Store](https://apps.apple.com/app/id6755608044)” ir įjunkite VPN.

#### sing-box

Įdiekite programą iš „[App Store](https://apps.apple.com/app/id6785326793)”, parašykite tinkamą konfigūraciją ir įjunkite VPN.

Reikia sukonfigūruoti `tun.loopback_address` ir `tun.route_address`.

Konfigūracijos pavyzdys:

```json
{
  "inbounds": [
    {
      "type": "tun",
      "address": "172.19.0.1/30",
      "auto_route": true,
      "loopback_address": "10.7.0.1",
      "route_address": "10.7.0.1/32"
    }
  ],
  "route": {
    "auto_detect_interface": true
  }
}
```

Įdiegus „sing-box” tinklų sietuve, pavyzdžiui, maršruto parinktuve, jis veiks visame vietiniame tinkle.

#### Clash

Įdiekite programą iš „[App Store](https://apps.apple.com/app/id6794257189)”, parašykite tinkamą konfigūraciją ir įjunkite VPN.

Reikia sukonfigūruoti `tun.loopback-address`:

```yaml
tun:
  loopback-address:
    - 10.7.0.1
```

#### Uždarojo kodo programinė įranga

Jei naudojate „Surge” su prenumerata, reikia sukonfigūruoti `General.tun-included-routes` ir `IP Rewrite`:

```ini
[General]
tun-included-routes = %INSERT% 10.7.0.1/32

[IP Rewrite]
10.7.0.1 = reflect
```

„Swipt” nereikalauja nustatyti `ipv6-vif = disabled`.

Jei naudojate kitą į „Surge” panašią programą, kuri neturi viešos dokumentacijos, paklauskite jos kūrėjų, kaip ją sukonfigūruoti.

## Automatinis atrakinimas

Išsaugokite prieigos kodą, kad „Swipt” galėtų automatiškai atrakinti jūsų įrenginį, kai jis užrakintas.

Konkrečiai, „Swipt CLI” gali atrakinti jūsų įrenginį, kad paleistų „Swipt API/MCP”, o „Swipt CLI”, MCP ir įdiegtos „Swiplet” programos gali atrakinti jūsų įrenginį, kad galėtų jį valdyti.
