## Огляд

Swipt — платформа для автоматизації.

## Вимоги

- Стороннє встановлення
- iOS 27 (Першочергова підтримка)
- iOS 17.4–26 (Потрібен додатковий пристрій Mac, Windows або Linux, щоб створити файл створення пари. У мене немає фізичних пристроїв для тестування, тож підтримка значною мірою залежатиме від зовнішніх внесків.)

## Стороннє встановлення за допомогою Mac

Щоб обійтися без окремого фреймворку для стороннього встановлення, рекомендуємо скористатися інструментом `sideload`, вбудованим у Swipt CLI.

Він підписує та встановлює програму Swipt за допомогою Xcode, тому може:

- Використовувати обліковий запис Apple, у який ви вже ввійшли, без повторного входу.
- Налаштувати програму Swipt так, щоб вона використовувала наявну пару між Mac і пристроєм, без повторного створення пари на пристрої.
- Підтвердити довіру до безплатного сертифіката розробника й виконати інші кроки початкового налаштування на пристрої.

У програмі «Термінал» виконайте такі команди:

```shell
npm install -g @swipt/cli
swipt sideload install
```

Потім дотримуйтеся підказок, щоб обрати пристрій для встановлення та команду розробників для підписування.

Програма Swipt виконує майже все налаштування автоматично, але VPN зворотної петлі потрібно запустити самостійно. Дивіться розділ [Початкове налаштування](./setup.mdx).

```shell
swipt sideload update # Оновити Swipt або продовжити строк дії
swipt sideload uninstall # Видалити Swipt
```
