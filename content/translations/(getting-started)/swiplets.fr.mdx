---
title: Swiplets
---

Un Swiplet est une app d’automatisation qui s’exécute dans Swipt. Il comprend :

- Interface : une interface SwiftUI native qui s’ouvre dans Swipt.
- Actions : des fonctions que vous pouvez appeler depuis l’interface, Raccourcis et Swipt API.
- Service : une automatisation qui continue de s’exécuter une fois activée.

## Installation des Swiplets

Vous pouvez installer un Swiplet à partir d’un paquet `.swiplet`, mais nous vous recommandons d’utiliser un dépôt de Swiplets, qui permet d’installer et de mettre à jour plusieurs Swiplets.

Swipt intègre le dépôt Swiplets officiels, dont le code source se trouve sur [swipt-automation/official-swiplets](https://github.com/swipt-automation/official-swiplets). Consultez sa documentation pour découvrir ce que les Swiplets permettent de faire.
