## קישור למכשיר

כדי להתחבר לשירותי המפתחים של המכשיר, יש לקשר אותו ל-Swipt.

אם Swipt הותקן בהתקנה צדדית באמצעות Swipt CLI, הקישור מוגדר אוטומטית. אחרת, כדי לבצע את הקישור יש לפעול לפי ההוראות:

אם המכשיר פועל עם iOS/iPadOS 27, אפשר לבצע את הקישור במכשיר עצמו לפי ההוראות ביישום:

  </div>

  </div>

אם הקישור במכשיר נכשל, יש לפתוח דיווח על בעיה.

אם המכשיר פועל עם גרסה מוקדמת יותר של iOS ויש ברשותך Mac, עדיין אפשר להשתמש ב-`swipt sideload setup` כדי להגדיר את הקישור לאחר התקנה צדדית ידנית. אחרת, יש לבצע את הקישור באמצעות תוכנה אחרת.

אפשר לייבא קובצי קישור שנוצרו כמעט בכל תוכנה אחרת, כולל:

- [Jitterbug](https://github.com/osy/Jitterbug): `.mobiledevicepairing`
- [idevice](https://github.com/jkcoxson/idevice): `ios_pairing_file.plist`
- [go-ios](https://github.com/danielpaulus/go-ios): `selfIdentity.plist`

זו הדרך הנפוצה ביותר להשיג קובץ קישור:

1. יש להוריד ולהתקין את [iloader](https://iloader.app). ב-Windows, יש להתקין קודם את [iTunes](https://www.apple.com/itunes/download/win64). ב-Linux, יש להתקין את `usbmuxd` אם הוא לא מותקן מראש.
2. יש לחבר את ה-iPhone או ה-iPad למחשב באמצעות כבל USB. אם תופיע בקשה, יש לבחור לסמוך על המחשב ולהזין את קוד הגישה.
3. יש לפתוח את iloader ולבחור את ה-iPhone או ה-iPad.
4. יש לבחור ב-"Manage Pairing File".
5. יש לבחור ב-"Export (Not Recommended)", לאחר מכן לבחור ב-"Confirm" ולשמור את קובץ הקישור.
6. יש להעביר את קובץ הקישור ל-iPhone או ל-iPad, למשל באמצעות AirDrop או iCloud Drive.

אם SideStore הותקן בעבר, סביר מאוד שכבר יש לך קובץ קישור!

## VPN מסוג לולאה חוזרת

כדי להתחבר לשירותי המפתחים, Swipt זקוק ל-VPN מסוג לולאה חוזרת. התוכנות הבאות נתמכות:

#### LocalDevVPN

יש להתקין מ-[App Store](https://apps.apple.com/app/id6755608044) ולהפעיל את ה-VPN.

#### sing-box

יש להתקין מ-[App Store](https://apps.apple.com/app/id6785326793), לכתוב תצורה נכונה ולהפעיל את ה-VPN.

יש להגדיר את `tun.loopback_address` ואת `tun.route_address`.

תצורה לדוגמה:

```json
{
  "inbounds": [
    {
      "type": "tun",
      "address": "172.19.0.1/30",
      "auto_route": true,
      "loopback_address": "10.7.0.1",
      "route_address": "10.7.0.1/32"
    }
  ],
  "route": {
    "auto_detect_interface": true
  }
}
```

פריסה של sing-box בשער רשת, כמו נתב, מאפשרת לו לפעול בכל הרשת המקומית.

#### Clash

יש להתקין מ-[App Store](https://apps.apple.com/app/id6794257189), לכתוב תצורה נכונה ולהפעיל את ה-VPN.

יש להגדיר את `tun.loopback-address`:

```yaml
tun:
  loopback-address:
    - 10.7.0.1
```

#### תוכנות בקוד סגור

בעת שימוש ב-Surge עם מינוי, יש להגדיר את `General.tun-included-routes` ואת `IP Rewrite`:

```ini
[General]
tun-included-routes = %INSERT% 10.7.0.1/32

[IP Rewrite]
10.7.0.1 = reflect
```

Swipt לא דורש את `ipv6-vif = disabled`.

עבור יישומים אחרים בסגנון Surge שאין להם תיעוד ציבורי, יש לפנות למפתחים שלהם כדי לברר כיצד להגדיר אותם.

## ביטול נעילה אוטומטי

יש לשמור את קוד הגישה כדי ש-Swipt יוכל לבטל את נעילת המכשיר באופן אוטומטי כשהוא נעול.

באופן ספציפי, Swipt CLI יכול לבטל את נעילת המכשיר כדי להפעיל את Swipt API/MCP, ו-Swipt CLI, MCP ו-Swiplet מותקנים יכולים לבטל את נעילת המכשיר כדי לתפעל אותו.
