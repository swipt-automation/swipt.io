## അവലോകനം

Swipt ഒരു ഓട്ടോമേഷൻ പ്ലാറ്റ്ഫോമാണ്.

## ആവശ്യകതകൾ

- സൈഡ്ലോഡിങ്
- iOS 27 (ഒന്നാം നിര പിന്തുണ)
- iOS 17.4–26 (പെയറിങ് ഫയൽ സൃഷ്ടിക്കാൻ ഒരു അധിക Mac, Windows അല്ലെങ്കിൽ Linux ഡിവൈസ് ആവശ്യമാണ്. ടെസ്റ്റ് ചെയ്യാൻ എന്റെ കൈവശം ഫിസിക്കൽ ഡിവൈസുകൾ ഇല്ലാത്തതിനാൽ, പിന്തുണ പ്രധാനമായും ബാഹ്യ സംഭാവനകളെ ആശ്രയിച്ചിരിക്കും.)

## Mac ഉപയോഗിച്ച് സൈഡ്ലോഡ് ചെയ്യൂ

പ്രത്യേകമായി ഒരു സൈഡ്ലോഡിങ് ഫ്രെയിംവർക്ക് ഇൻസ്റ്റാൾ ചെയ്യാൻ താൽപ്പര്യമില്ലെങ്കിൽ, Swipt CLI-യിൽ ബിൽറ്റ്-ഇൻ ആയുള്ള `sideload` ടൂൾ ശുപാർശ ചെയ്യുന്നു.

ഇത് Xcode ഉപയോഗിച്ച് Swipt സൈൻ ചെയ്ത് ഇൻസ്റ്റാൾ ചെയ്യുന്നതിനാൽ, ഇതിന് ഇനിപ്പറയുന്നവ ചെയ്യാനാകും:

- വീണ്ടും സൈൻ ഇൻ ചെയ്യാൻ ആവശ്യപ്പെടാതെ, നിങ്ങൾ ഇതിനകം സൈൻ ഇൻ ചെയ്തിട്ടുള്ള Apple അക്കൗണ്ട് ഉപയോഗിക്കുക.
- ഡിവൈസിൽ വീണ്ടും പെയർ ചെയ്യാതെ, നിങ്ങളുടെ Mac-ന് ഡിവൈസുമായി നിലവിലുള്ള പെയറിങ് ഉപയോഗിക്കാൻ Swipt കോൺഫിഗർ ചെയ്യുക.
- നിങ്ങളുടെ ഡിവൈസിൽ സൗജന്യ ഡെവലപ്പർ സർട്ടിഫിക്കറ്റിനെ വിശ്വസിക്കുകയും ആദ്യമായി ചെയ്യേണ്ട മറ്റ് സജ്ജീകരണങ്ങൾ നടത്തുകയും ചെയ്യുക.

‘ടെർമിനലി’ൽ ഇനിപ്പറയുന്ന കമാൻഡുകൾ റൺ ചെയ്യൂ:

```shell
npm install -g @swipt/cli
swipt sideload install
```

തുടർന്ന്, ഇൻസ്റ്റാൾ ചെയ്യേണ്ട ഡിവൈസും സൈൻ ചെയ്യാൻ ഉപയോഗിക്കേണ്ട ടീമും തിരഞ്ഞെടുക്കാൻ നിർദ്ദേശങ്ങൾ പിന്തുടരൂ.

മിക്കവാറും എല്ലാ സജ്ജീകരണങ്ങളും Swipt ഓട്ടോമാറ്റിക്കായി പൂർത്തിയാക്കുന്നു, എങ്കിലും ലൂപ്പ്ബാക്ക് VPN നിങ്ങൾ തന്നെ ആരംഭിക്കേണ്ടതുണ്ട്. [സജ്ജീകരണം](./setup.mdx) എന്ന വിഭാഗം കാണൂ.

```shell
swipt sideload update # Swipt അപ്ഡേറ്റ് ചെയ്യുക അല്ലെങ്കിൽ അതിന്റെ കാലാവധി പുതുക്കുക
swipt sideload uninstall # Swipt അൺഇൻസ്റ്റാൾ ചെയ്യുക
```
