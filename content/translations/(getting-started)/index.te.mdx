## ఓవర్‌వ్యూ

Swipt అనేది ఆటోమేషన్ ప్లాట్‌ఫామ్.

## అవసరాలు

- సైడ్‌లోడింగ్
- iOS 27 (మొదటి శ్రేణి సపోర్ట్)
- iOS 17.4–26 (పెయిరింగ్ ఫైల్‌ను క్రియేట్ చేయడానికి అదనంగా ఒక Mac, Windows లేదా Linux డివైజ్ అవసరం. టెస్టింగ్ కోసం నా దగ్గర ఫిజికల్ డివైజ్‌లు లేవు, కాబట్టి సపోర్ట్ ఎక్కువగా బయటి కంట్రిబ్యూషన్‌లపైనే ఆధారపడి ఉంటుంది.)

## Macతో సైడ్‌లోడ్ చేయడం

మీరు సైడ్‌లోడింగ్ ఫ్రేమ్‌వర్క్‌ను విడిగా ఇన్‌స్టాల్ చేయకూడదనుకుంటే, Swipt CLIలోనే ఉన్న `sideload` టూల్‌ను ఉపయోగించడం సిఫార్సు చేయబడుతుంది.

ఇది Swiptను Xcodeతో సైన్ చేసి ఇన్‌స్టాల్ చేస్తుంది, కాబట్టి ఇవి చేయగలదు:

- మళ్లీ సైన్ ఇన్ చేయమని అడగకుండా, మీరు ఇప్పటికే సైన్ ఇన్ చేసిన Apple ఖాతాను ఉపయోగించగలదు.
- డివైజ్‌లో మళ్లీ పెయిర్ చేయాల్సిన అవసరం లేకుండా, ఆ డివైజ్‌తో మీ Macకు ఇప్పటికే ఉన్న పెయిరింగ్‌ను ఉపయోగించేలా Swiptను కాన్ఫిగర్ చేయగలదు.
- మీ డివైజ్‌లో ఉచిత డెవలపర్ సర్టిఫికేట్‌ను విశ్వసించగలదు, అలాగే మొదటిసారి చేయాల్సిన ఇతర కాన్ఫిగరేషన్‌ను కూడా పూర్తి చేయగలదు.

Terminalలో ఈ కమాండ్‌లను రన్ చేయండి:

```shell
npm install -g @swipt/cli
swipt sideload install
```

ఆ తర్వాత ప్రాంప్ట్‌లను అనుసరించి, Swiptను ఇన్‌స్టాల్ చేయాల్సిన డివైజ్‌ను, సైన్ చేయడానికి ఉపయోగించే టీమ్‌ను ఎంచుకోండి.

Swipt దాదాపు సెటప్ మొత్తాన్ని ఆటోమేటిక్‌గా పూర్తి చేస్తుంది, కానీ లూప్‌బ్యాక్ VPNను మాత్రం మీరే ప్రారంభించాలి. [సెటప్](./setup.mdx) విభాగాన్ని చూడండి.

```shell
swipt sideload update # Swiptను అప్‌డేట్ చేయండి లేదా దాని గడువును పొడిగించండి
swipt sideload uninstall # Swiptను అన్‌ఇన్‌స్టాల్ చేయండి
```
