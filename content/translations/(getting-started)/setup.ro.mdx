## Asocierea cu dispozitivul

Aplicația Swipt trebuie să se asocieze cu dispozitivul pentru a se conecta la serviciile pentru dezvoltatori ale acestuia.

Dacă ați instalat aplicația Swipt prin sideloading cu Swipt CLI, asocierea este configurată automat. În caz contrar, urmați instrucțiunile din aplicație pentru a realiza asocierea:

Dacă asocierea nu poate fi finalizată, raportați-ne problema. Alternativ, puteți importa un fișier de asociere din alte programe, inclusiv:

- [Jitterbug](https://github.com/osy/Jitterbug): `.mobiledevicepairing`
- [idevice](https://github.com/jkcoxson/idevice): `ios_pairing_file.plist`
- [go-ios](https://github.com/danielpaulus/go-ios): `selfIdentity.plist`

## VPN de loopback

Aplicația Swipt are nevoie de un VPN de loopback pentru a se conecta la serviciile pentru dezvoltatori. Este acceptat următorul software:

#### LocalDevVPN

Instalați aplicația din [App Store](https://apps.apple.com/app/id6755608044) și activați VPN-ul.

#### sing-box

Instalați aplicația din [App Store](https://apps.apple.com/app/id6785326793), scrieți o configurație corectă și activați VPN-ul.

Trebuie să configurați `tun.loopback_address` și `tun.route_address`.

Exemplu de configurație:

```json
{
  "inbounds": [
    {
      "type": "tun",
      "address": "172.19.0.1/30",
      "auto_route": true,
      "loopback_address": "10.7.0.1",
      "route_address": "10.7.0.1/32"
    }
  ],
  "route": {
    "auto_detect_interface": true
  }
}
```

Dacă implementați sing-box pe un gateway, cum ar fi un router, acesta va funcționa pentru întreaga rețea locală.

#### Clash

Instalați aplicația din [App Store](https://apps.apple.com/app/id6794257189), scrieți o configurație corectă și activați VPN-ul.

Trebuie să configurați `tun.loopback-address`:

```yaml
tun:
  loopback-address:
    - 10.7.0.1
```

#### Software cu sursă închisă

Dacă utilizați Surge cu abonament, trebuie să configurați `General.tun-included-routes` și `IP Rewrite`:

```ini
[General]
tun-included-routes = %INSERT% 10.7.0.1/32

[IP Rewrite]
10.7.0.1 = reflect
```

Aplicația Swipt nu necesită `ipv6-vif = disabled`.

Pentru alte aplicații asemănătoare cu Surge care nu au documentație publică, întrebați dezvoltatorii acestora cum se configurează.

## Deblocare automată

Salvați codul de acces pentru ca aplicația Swipt să vă poată debloca automat dispozitivul atunci când este blocat.

Mai exact, Swipt CLI poate debloca dispozitivul pentru a porni Swipt API/MCP, iar Swipt CLI, MCP și Swiplet-urile instalate pot debloca dispozitivul pentru a-l opera.
