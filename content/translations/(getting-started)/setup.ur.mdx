## اپنی ڈیوائس کے ساتھ پیئر کریں

ڈیوائس کی ڈیولپر سروسز سے کنکٹ ہونے کے لیے Swipt کا آپ کی ڈیوائس کے ساتھ پیئر ہونا ضروری ہے۔

اگر آپ نے Swipt کو Swipt CLI کے ذریعے سائیڈ لوڈ کیا ہے تو پیئرنگ خودکار طور پر سیٹ اپ ہو جاتی ہے۔ بصورت دیگر، پیئر کرنے کے لیے ہدایات پر عمل کریں:

اگر آپ iOS/iPadOS 27 استعمال کر رہے ہیں تو ایپ میں دی گئی ہدایات پر عمل کر کے ڈیوائس پر ہی پیئر کر سکتے ہیں:

اگر ڈیوائس پر پیئرنگ ناکام ہو جائے تو براہ کرم ایک ایشو کھولیں۔

اگر آپ iOS کا پرانا ورژن استعمال کر رہے ہیں اور آپ کے پاس Mac ہے تو دستی طور پر سائیڈ لوڈ کرنے کے بعد پیئرنگ سیٹ اپ کرنے کے لیے آپ اب بھی `swipt sideload setup` استعمال کر سکتے ہیں۔ بصورت دیگر، آپ کو دیگر سافٹ ویئر کے ذریعے پیئر کرنا ہوگا۔

آپ تقریباً کسی بھی دوسرے سافٹ ویئر سے بنائی گئی پیئرنگ فائلز امپورٹ کر سکتے ہیں، بشمول:

- [Jitterbug](https://github.com/osy/Jitterbug): `.mobiledevicepairing`
- [idevice](https://github.com/jkcoxson/idevice): `ios_pairing_file.plist`
- [go-ios](https://github.com/danielpaulus/go-ios): `selfIdentity.plist`

پیئرنگ فائل حاصل کرنے کا سب سے عام طریقہ یہ ہے:

1. [iloader](https://iloader.app) ڈاؤن لوڈ اور انسٹال کریں۔ Windows پر پہلے [iTunes](https://www.apple.com/itunes/download/win64) انسٹال کریں۔ Linux پر اگر `usbmuxd` پہلے سے انسٹال نہ ہو تو اسے انسٹال کریں۔
2. USB کیبل کے ذریعے اپنے iPhone یا iPad کو اپنے کمپیوٹر سے کنکٹ کریں۔ اگر کہا جائے تو کمپیوٹر پر اعتبار کریں اور اپنا پاس کوڈ درج کریں۔
3. iloader کھولیں اور اپنا iPhone یا iPad منتخب کریں۔
4. “Manage Pairing File” منتخب کریں۔
5. “Export (Not Recommended)” منتخب کریں، پھر “Confirm” منتخب کریں اور پیئرنگ فائل محفوظ کریں۔
6. پیئرنگ فائل کو اپنے iPhone یا iPad پر منتقل کریں، مثلاً AirDrop یا iCloud Drive کے ذریعے۔

اگر آپ پہلے SideStore انسٹال کر چکے ہیں تو غالباً آپ کے پاس پہلے سے ہی پیئرنگ فائل موجود ہے!

## لوپ بیک VPN

ڈیولپر سروسز سے کنکٹ ہونے کے لیے Swipt کو لوپ بیک VPN درکار ہے۔ درج ذیل سافٹ ویئر سپورٹ کیے جاتے ہیں:

#### LocalDevVPN

[App Store](https://apps.apple.com/app/id6755608044) سے انسٹال کریں اور VPN آن کریں۔

#### sing-box

[App Store](https://apps.apple.com/app/id6785326793) سے انسٹال کریں، درست کنفیگریشن لکھیں اور VPN آن کریں۔

آپ کو `tun.loopback_address` اور `tun.route_address` کنفیگر کرنے ہوں گے۔

نمونہ کنفیگریشن:

```json
{
  "inbounds": [
    {
      "type": "tun",
      "address": "172.19.0.1/30",
      "auto_route": true,
      "loopback_address": "10.7.0.1",
      "route_address": "10.7.0.1/32"
    }
  ],
  "route": {
    "auto_detect_interface": true
  }
}
```

اسے راؤٹر جیسے کسی گیٹ وے پر چلانے سے یہ پورے مقامی نیٹ ورک کے لیے کام کرتا ہے۔

#### Clash

[App Store](https://apps.apple.com/app/id6794257189) سے انسٹال کریں، درست کنفیگریشن لکھیں اور VPN آن کریں۔

آپ کو `tun.loopback-address` کنفیگر کرنا ہو گا:

```yaml
tun:
  loopback-address:
    - 10.7.0.1
```

#### کلوزڈ سورس سافٹ ویئر

اگر آپ سبسکرپشن کے ساتھ Surge استعمال کرتے ہیں تو آپ کو `General.tun-included-routes` اور `IP Rewrite` کنفیگر کرنے ہوں گے:

```ini
[General]
tun-included-routes = %INSERT% 10.7.0.1/32

[IP Rewrite]
10.7.0.1 = reflect
```

Swipt کے لیے `ipv6-vif = disabled` ضروری نہیں ہے۔

Surge جیسی دیگر ایپس کے لیے جن کی دستاویزات عوامی طور پر دستیاب نہیں ہیں، کنفیگریشن کا طریقہ ان کے ڈیولپرز سے معلوم کریں۔

## خودکار ان لاک

اپنا پاس کوڈ محفوظ کریں تاکہ ڈیوائس لاک ہونے پر Swipt اسے خودکار طور پر ان لاک کر سکے۔

خاص طور پر، Swipt CLI آپ کی ڈیوائس کو ان لاک کر کے Swipt API/MCP شروع کر سکتا ہے، اور Swipt CLI، MCP اور انسٹال شدہ Swiplet آپ کی ڈیوائس کو ان لاک کر کے اسے آپریٹ کر سکتے ہیں۔
