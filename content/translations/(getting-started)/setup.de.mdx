## Mit deinem Gerät koppeln

Swipt muss mit deinem Gerät gekoppelt werden, um sich mit dessen Entwicklerdiensten zu verbinden.

Wenn du Swipt per Sideloading mit der Swipt CLI installiert hast, wird die Kopplung automatisch eingerichtet. Folge andernfalls den Anweisungen, um die Kopplung durchzuführen:

Wenn du iOS/iPadOS 27 verwendest, kannst du die Kopplung auf dem Gerät durchführen, indem du den Anweisungen in der App folgst:

Wenn die Kopplung auf dem Gerät fehlschlägt, erstelle bitte ein Issue.

Wenn du eine ältere iOS-Version verwendest und einen Mac hast, kannst du nach dem manuellen Sideloading trotzdem `swipt sideload setup` verwenden, um die Kopplung einzurichten. Andernfalls musst du die Kopplung mit anderer Software durchführen.

Du kannst Kopplungsdateien importieren, die mit fast jeder anderen Software erstellt wurden, darunter:

- [Jitterbug](https://github.com/osy/Jitterbug): `.mobiledevicepairing`
- [idevice](https://github.com/jkcoxson/idevice): `ios_pairing_file.plist`
- [go-ios](https://github.com/danielpaulus/go-ios): `selfIdentity.plist`

So kommst du am häufigsten an eine Kopplungsdatei:

1. Lade [iloader](https://iloader.app) herunter und installiere es. Installiere unter Windows zuerst [iTunes](https://www.apple.com/itunes/download/win64). Installiere unter Linux `usbmuxd`, falls es nicht vorinstalliert ist.
2. Verbinde dein iPhone oder iPad über ein USB-Kabel mit deinem Computer. Wenn du dazu aufgefordert wirst, vertraue dem Computer und gib deinen Code ein.
3. Öffne iloader und wähle dein iPhone oder iPad aus.
4. Wähle „Manage Pairing File“.
5. Wähle „Export (Not Recommended)“, wähle dann „Confirm“ und sichere die Kopplungsdatei.
6. Übertrage die Kopplungsdatei auf dein iPhone oder iPad, zum Beispiel mit AirDrop oder iCloud Drive.

Wenn du SideStore schon einmal installiert hast, hast du höchstwahrscheinlich bereits eine Kopplungsdatei!

## Loopback-VPN

Swipt benötigt ein Loopback-VPN, um sich mit den Entwicklerdiensten zu verbinden. Folgende Software wird unterstützt:

#### LocalDevVPN

Installiere die App aus dem [App Store](https://apps.apple.com/app/id6755608044) und aktiviere das VPN.

#### sing-box

Installiere die App aus dem [App Store](https://apps.apple.com/app/id6785326793), erstelle eine korrekte Konfiguration und aktiviere das VPN.

Du musst `tun.loopback_address` und `tun.route_address` konfigurieren.

Beispielkonfiguration:

```json
{
  "inbounds": [
    {
      "type": "tun",
      "address": "172.19.0.1/30",
      "auto_route": true,
      "loopback_address": "10.7.0.1",
      "route_address": "10.7.0.1/32"
    }
  ],
  "route": {
    "auto_detect_interface": true
  }
}
```

Wenn du sing-box auf einem Gateway wie einem Router einsetzt, funktioniert das für das gesamte lokale Netzwerk.

#### Clash

Installiere die App aus dem [App Store](https://apps.apple.com/app/id6794257189), erstelle eine korrekte Konfiguration und aktiviere das VPN.

Du musst `tun.loopback-address` konfigurieren:

```yaml
tun:
  loopback-address:
    - 10.7.0.1
```

#### Closed-Source-Software

Wenn du Shadowrocket verwendest, aktiviere unter „Einstellungen“ die Option **Include Route 10.7.0.1/32** und verbinde dann das VPN neu. Wenn du diese Option nicht siehst, aktualisiere Shadowrocket.

Wenn du Surge abonniert hast und nutzt, musst du `General.tun-included-routes` und `IP Rewrite` konfigurieren:

```ini
[General]
tun-included-routes = %INSERT% 10.7.0.1/32

[IP Rewrite]
10.7.0.1 = reflect
```

`ipv6-vif = disabled` ist für Swipt nicht erforderlich.

Bei anderen Surge-ähnlichen Apps ohne öffentliche Dokumentation fragst du am besten die jeweiligen Entwickler, wie du sie einrichtest.

## Automatische Entsperrung

Sichere deinen Code, damit Swipt dein Gerät automatisch entsperren kann, wenn es gesperrt ist.

Genauer gesagt kann die Swipt CLI dein Gerät entsperren, um die Swipt API/MCP zu starten, und die Swipt CLI, MCP und installierte Swiplets können dein Gerät entsperren, um es zu bedienen.
