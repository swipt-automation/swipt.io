## Oversikt

Swipt er en automatiseringsplattform.

## Krav

- Sidelasting
- iOS 27 (Primær støtte)
- iOS 17.4–26 (Krever en ekstra Mac-, Windows- eller Linux-enhet for å opprette en sammenkoblingsfil. Jeg har ikke fysiske enheter å teste på, så støtten vil i stor grad være avhengig av eksterne bidrag.)

## Sidelasting med Mac

Vi anbefaler det innebygde `sideload`-verktøyet i Swipt CLI hvis du ikke vil installere et frittstående rammeverk for sidelasting.

Verktøyet signerer og installerer Swipt med Xcode og kan derfor:

- Bruke Apple-kontoen du allerede er logget på med, uten at du må logge på igjen.
- Konfigurere Swipt til å bruke sammenkoblingen som allerede finnes mellom Macen og enheten, uten at du må koble dem sammen igjen på enheten.
- Stole på det gratis utviklersertifikatet og utføre annet førstegangsoppsett på enheten.

Kjør dette i Terminal:

```shell
npm install -g @swipt/cli
swipt sideload install
```

Følg deretter instruksjonene for å velge hvilken enhet du vil installere på, og hvilket team du vil signere med.

Swipt fullfører nesten hele oppsettet automatisk, men du må fortsatt starte Loopback-VPN selv. Se [Oppsett](./setup.mdx).

```shell
swipt sideload update # Oppdater Swipt eller forleng gyldigheten
swipt sideload uninstall # Avinstaller Swipt
```
