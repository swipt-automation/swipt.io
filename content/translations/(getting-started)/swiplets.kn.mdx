Swiplet ಎಂಬುದು Swipt ಆ್ಯಪ್‌ನ ಒಳಗೆ ರನ್ ಆಗುವ ಆಟೋಮೇಷನ್ ಆ್ಯಪ್ ಆಗಿದೆ. ಇದು ಇವುಗಳನ್ನು ಒಳಗೊಂಡಿದೆ:

- ಇಂಟರ್‌ಫೇಸ್: Swipt ಆ್ಯಪ್‌ನಲ್ಲಿ ತೆರೆಯುವ ನೇಟಿವ್ SwiftUI ಇಂಟರ್‌ಫೇಸ್.
- ಕ್ರಿಯೆಗಳು: ಇಂಟರ್‌ಫೇಸ್, ಶಾರ್ಟ್‌ಕಟ್ಸ್‌ ಮತ್ತು Swipt API ನಿಂದ ನೀವು ಕರೆಯಬಹುದಾದ ಫಂಕ್ಷನ್‌ಗಳು.
- ಸೇವೆ: ಆನ್ ಮಾಡಿದ ನಂತರವೂ ರನ್ ಆಗುತ್ತಲೇ ಇರುವ ಆಟೋಮೇಷನ್.

## Swiplet ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡಿ

`.swiplet` ಪ್ಯಾಕೇಜ್‌ನಿಂದ ನೀವು Swiplet ಅನ್ನು ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡಬಹುದು, ಆದರೆ Swiplet ರೆಪೊಸಿಟರಿಯನ್ನು ಬಳಸಲು ನಾವು ಶಿಫಾರಸು ಮಾಡುತ್ತೇವೆ, ಅದರ ಮೂಲಕ ನೀವು ಅನೇಕ Swiplet ಅನ್ನು ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡಬಹುದು ಮತ್ತು ಅಪ್‌ಡೇಟ್ ಮಾಡಬಹುದು.

Swipt ಆ್ಯಪ್‌ನಲ್ಲಿ “ಅಧಿಕೃತ Swiplet” ರೆಪೊಸಿಟರಿ ಒಳಗೊಂಡಿದೆ, ಅದರ ಸೋರ್ಸ್ ಕೋಡ್ [swipt-automation/official-swiplets](https://github.com/swipt-automation/official-swiplets) ನಲ್ಲಿದೆ. Swiplet ಏನು ಮಾಡಬಹುದು ಎಂದು ತಿಳಿಯಲು ಅದರ ದಸ್ತಾವೇಜನ್ನು ಓದಿ.
