## Párosítás az eszközzel

A Swipt appot párosítani kell az eszközzel, hogy csatlakozhasson annak fejlesztői szolgáltatásaihoz.

Ha a Swipt appot a Swipt CLI-vel telepítette oldalról, a rendszer automatikusan beállítja a párosítást. Ellenkező esetben kövesse az appban megjelenő utasításokat a párosításhoz:

  </div>

Ha a párosítás nem hajtható végre, jelezze nekünk a problémát. Másik lehetőségként importálhat párosítási fájlt más szoftverekből, például:

- [Jitterbug](https://github.com/osy/Jitterbug): `.mobiledevicepairing`
- [idevice](https://github.com/jkcoxson/idevice): `ios_pairing_file.plist`
- [go-ios](https://github.com/danielpaulus/go-ios): `selfIdentity.plist`

## Visszacsatolási VPN

A Swipt appnak visszacsatolási VPN-re van szüksége a fejlesztői szolgáltatásokhoz való csatlakozáshoz. A következő szoftverek támogatottak:

#### LocalDevVPN

Telepítse az appot az [App Store-ból](https://apps.apple.com/app/id6755608044), majd kapcsolja be a VPN-t.

#### sing-box

Telepítse az appot az [App Store-ból](https://apps.apple.com/app/id6785326793), írjon egy helyes konfigurációt, majd kapcsolja be a VPN-t.

Be kell állítania a `tun.loopback_address` és a `tun.route_address` értékét.

Példakonfiguráció:

```json
{
  "inbounds": [
    {
      "type": "tun",
      "address": "172.19.0.1/30",
      "auto_route": true,
      "loopback_address": "10.7.0.1",
      "route_address": "10.7.0.1/32"
    }
  ],
  "route": {
    "auto_detect_interface": true
  }
}
```

Ha a sing-boxot egy átjárón, például egy routeren futtatja, a teljes helyi hálózaton működni fog.

#### Clash

Telepítse az appot az [App Store-ból](https://apps.apple.com/app/id6794257189), írjon egy helyes konfigurációt, majd kapcsolja be a VPN-t.

Be kell állítania a `tun.loopback-address` értékét:

```yaml
tun:
  loopback-address:
    - 10.7.0.1
```

#### Zárt forráskódú szoftverek

Ha előfizetéssel használja a Surge appot, be kell állítania a `General.tun-included-routes` beállítást és az `IP Rewrite` szakaszt:

```ini
[General]
tun-included-routes = %INSERT% 10.7.0.1/32

[IP Rewrite]
10.7.0.1 = reflect
```

A Swipt apphoz nem szükséges az `ipv6-vif = disabled` beállítás.

Az egyéb, Surge-szerű appok esetében, amelyekhez nem érhető el nyilvános dokumentáció, kérdezze meg azok fejlesztőit a beállítás módjáról.

## Automatikus feloldás

Mentse a jelkódját, hogy a Swipt app automatikusan feloldhassa az eszközét, amikor az zárolva van.

Pontosabban a Swipt CLI feloldhatja az eszközt a Swipt API/MCP elindításához, a Swipt CLI, az MCP és a telepített Swipletek pedig feloldhatják az eszközt annak kezeléséhez.
