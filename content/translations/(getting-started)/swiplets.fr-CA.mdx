---
title: Swiplets
---

Un Swiplet est une app d’automatisation qui fonctionne à l’intérieur de Swipt. Il comprend :

- Interface : une interface SwiftUI native qui s’ouvre dans l’app Swipt.
- Actions : des fonctions que vous pouvez appeler à partir de l’interface, de Raccourcis et de Swipt API.
- Service : une automatisation qui continue de fonctionner après son activation.

## Installation des Swiplets

Vous pouvez installer un Swiplet à partir d’un paquet `.swiplet`, mais nous vous recommandons plutôt d’utiliser un dépôt de Swiplets, qui vous permet d’installer et de mettre à jour plusieurs Swiplets.

L’app Swipt comprend le dépôt Swiplets officiels; son code source est accessible sur [swipt-automation/official-swiplets](https://github.com/swipt-automation/official-swiplets). Lisez sa documentation pour savoir ce que les Swiplets peuvent faire.
