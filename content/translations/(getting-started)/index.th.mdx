## ภาพรวม

Swipt เป็นแพลตฟอร์มการทำงานอัตโนมัติ

## ข้อกำหนด

- การไซด์โหลด
- iOS 27 (รองรับเป็นหลัก)
- iOS 17.4–26 (ต้องมีอุปกรณ์ Mac, Windows หรือ Linux เพิ่มอีกเครื่องเพื่อสร้างไฟล์จับคู่ ฉันไม่มีอุปกรณ์จริงสำหรับทดสอบ การรองรับจึงต้องพึ่งพาการมีส่วนร่วมจากภายนอกเป็นอย่างมาก)

## ติดตั้งแบบไซด์โหลดด้วย Mac

หากไม่ต้องการติดตั้งเฟรมเวิร์กไซด์โหลดแยกต่างหาก แนะนำให้ใช้เครื่องมือ `sideload` ที่มีมาให้ใน Swipt CLI

เครื่องมือนี้เซ็นชื่อและติดตั้ง Swipt ด้วย Xcode จึงสามารถ:

- ใช้บัญชี Apple ที่คุณลงชื่อเข้าไว้แล้ว โดยไม่ต้องลงชื่อเข้าอีกครั้ง
- กำหนดค่าให้ Swipt ใช้การจับคู่ที่มีอยู่แล้วระหว่าง Mac ของคุณกับอุปกรณ์ โดยไม่ต้องจับคู่อีกครั้งบนอุปกรณ์
- เชื่อถือใบรับรองนักพัฒนาแบบฟรีและตั้งค่าเบื้องต้นอื่นๆ บนอุปกรณ์ของคุณ

เรียกใช้คำสั่งต่อไปนี้ในเทอร์มินัล:

```shell
npm install -g @swipt/cli
swipt sideload install
```

จากนั้นทำตามข้อความแจ้งเพื่อเลือกอุปกรณ์ที่จะติดตั้งและทีมที่จะใช้เซ็นชื่อ

Swipt จะตั้งค่าเกือบทั้งหมดให้โดยอัตโนมัติ แต่คุณยังต้องเริ่ม VPN ลูปแบ็คเอง ดูส่วน[การตั้งค่าครั้งแรก](./setup.mdx)

```shell
swipt sideload update # อัปเดต Swipt หรือต่ออายุการใช้งาน
swipt sideload uninstall # ถอนการติดตั้ง Swipt
```
