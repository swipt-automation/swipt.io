## Apžvalga

„Swipt” yra automatizavimo platforma.

## Reikalavimai

- Šoninis įkėlimas
- „iOS 27” (pirmo lygio palaikymas)
- „iOS 17.4–26” (norint sukurti susiejimo failą, reikia papildomo „Mac”, „Windows” arba „Linux” įrenginio. Neturiu fizinių įrenginių testavimui, todėl palaikymas labai priklausys nuo išorinių indėlių.)

## Šoninis įkėlimas naudojant „Mac” kompiuterį

Jei nenorite diegti atskiros šoninio įkėlimo programos, rekomenduojame naudoti integruotą „Swipt CLI” įrankį `sideload`.

Jis pasirašo ir įdiegia „Swipt” naudodamas „Xcode”, todėl gali:

- Naudoti „Apple” paskyrą, prie kurios jau prisijungta, neprašydamas prisijungti iš naujo.
- Nustatyti, kad „Swipt” naudotų esamą jūsų „Mac” kompiuterio susiejimą su įrenginiu, be pakartotinio susiejimo įrenginyje.
- Įrenginyje pasitikėti nemokamu kūrėjo sertifikatu ir atlikti kitus pradinio nustatymo veiksmus.

Programoje „Terminal” paleiskite šias komandas:

```shell
npm install -g @swipt/cli
swipt sideload install
```

Tada pagal nurodymus pasirinkite įrenginį, į kurį diegsite, ir pasirašymui naudojamą komandą.

„Swipt” beveik visą sąranką atlieka automatiškai, tačiau vis tiek turite paleisti grįžtamojo ryšio VPN. Žr. skyrių „[Sąranka](./setup.mdx)”.

```shell
swipt sideload update # Atnaujinti „Swipt” arba pratęsti galiojimą
swipt sideload uninstall # Pašalinti „Swipt”
```
