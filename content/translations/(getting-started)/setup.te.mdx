## మీ డివైజ్‌తో పెయిర్ చేయండి

డివైజ్‌లోని డెవలపర్ సర్వీస్‌లకు కనెక్ట్ కావడానికి Swipt మీ డివైజ్‌తో పెయిర్ కావాలి.

మీరు Swipt CLIతో Swiptను సైడ్‌లోడ్ చేసి ఉంటే, పెయిరింగ్ ఆటోమేటిక్‌గా సెటప్ అవుతుంది. లేదంటే, పెయిర్ చేయడానికి సూచనలను అనుసరించండి:

మీరు iOS/iPadOS 27 ఉపయోగిస్తుంటే, యాప్‌లోని సూచనలను అనుసరించి డివైజ్‌లోనే పెయిర్ చేయవచ్చు:

డివైజ్‌లో పెయిరింగ్ విఫలమైతే, దయచేసి ఒక ఇష్యూను తెరవండి.

మీరు iOS పాత వెర్షన్‌ను ఉపయోగిస్తూ, మీ దగ్గర Mac ఉంటే, మాన్యువల్‌గా సైడ్‌లోడ్ చేసిన తర్వాత పెయిరింగ్‌ను సెటప్ చేయడానికి ఇప్పటికీ `swipt sideload setup`ను ఉపయోగించవచ్చు. లేదంటే, మీరు ఇతర సాఫ్ట్‌వేర్‌తో పెయిర్ చేయాలి.

దాదాపు ఏ ఇతర సాఫ్ట్‌వేర్‌తో క్రియేట్ చేసిన పెయిరింగ్ ఫైల్‌లనైనా మీరు ఇంపోర్ట్ చేయవచ్చు, ఉదాహరణకు:

- [Jitterbug](https://github.com/osy/Jitterbug): `.mobiledevicepairing`
- [idevice](https://github.com/jkcoxson/idevice): `ios_pairing_file.plist`
- [go-ios](https://github.com/danielpaulus/go-ios): `selfIdentity.plist`

పెయిరింగ్ ఫైల్‌ను పొందడానికి అత్యంత సాధారణ మార్గం ఇది:

1. [iloader](https://iloader.app)ను డౌన్‌లోడ్ చేసి ఇన్‌స్టాల్ చేయండి. Windowsలో, ముందుగా [iTunes](https://www.apple.com/itunes/download/win64)ను ఇన్‌స్టాల్ చేయండి. Linuxలో, `usbmuxd` ముందే ఇన్‌స్టాల్ చేసి లేకపోతే దాన్ని ఇన్‌స్టాల్ చేయండి.
2. USB కేబుల్ ద్వారా మీ iPhone లేదా iPadను మీ కంప్యూటర్‌కు కనెక్ట్ చేయండి. అడిగితే, కంప్యూటర్‌ను విశ్వసించి, మీ పాస్‌కోడ్‌ను ఎంటర్ చేయండి.
3. iloaderను తెరిచి, మీ iPhone లేదా iPadను ఎంచుకోండి.
4. ‘Manage Pairing File’ను ఎంచుకోండి.
5. ‘Export (Not Recommended)’ను ఎంచుకుని, ఆపై ‘Confirm’ను ఎంచుకుని పెయిరింగ్ ఫైల్‌ను సేవ్ చేయండి.
6. ఉదాహరణకు AirDrop లేదా iCloud Drive ద్వారా, పెయిరింగ్ ఫైల్‌ను మీ iPhone లేదా iPadకు బదిలీ చేయండి.

మీరు ఇంతకు ముందు SideStoreను ఇన్‌స్టాల్ చేసి ఉంటే, మీ దగ్గర ఇప్పటికే పెయిరింగ్ ఫైల్ ఉండే అవకాశం ఎక్కువ!

## లూప్‌బ్యాక్ VPN

డెవలపర్ సర్వీస్‌లకు కనెక్ట్ కావడానికి Swiptకు లూప్‌బ్యాక్ VPN అవసరం. కింది సాఫ్ట్‌వేర్‌లకు సపోర్ట్ ఉంది:

#### LocalDevVPN

[App Store](https://apps.apple.com/app/id6755608044) నుండి ఇన్‌స్టాల్ చేసి, VPNను ఆన్ చేయండి.

#### sing-box

[App Store](https://apps.apple.com/app/id6785326793) నుండి ఇన్‌స్టాల్ చేసి, సరైన కాన్ఫిగరేషన్‌ను రాసి, VPNను ఆన్ చేయండి.

మీరు `tun.loopback_address`, `tun.route_address`లను కాన్ఫిగర్ చేయాలి.

ఉదాహరణ కాన్ఫిగరేషన్:

```json
{
  "inbounds": [
    {
      "type": "tun",
      "address": "172.19.0.1/30",
      "auto_route": true,
      "loopback_address": "10.7.0.1",
      "route_address": "10.7.0.1/32"
    }
  ],
  "route": {
    "auto_detect_interface": true
  }
}
```

రూటర్ వంటి గేట్‌వేలో దీన్ని డిప్లాయ్ చేస్తే, ఇది మొత్తం లోకల్ నెట్‌వర్క్‌కు పని చేస్తుంది.

#### Clash

[App Store](https://apps.apple.com/app/id6794257189) నుండి ఇన్‌స్టాల్ చేసి, సరైన కాన్ఫిగరేషన్‌ను రాసి, VPNను ఆన్ చేయండి.

మీరు `tun.loopback-address`ను కాన్ఫిగర్ చేయాలి:

```yaml
tun:
  loopback-address:
    - 10.7.0.1
```

#### క్లోజ్డ్ సోర్స్ సాఫ్ట్‌వేర్

మీరు సబ్‌స్క్రిప్షన్‌తో Surgeను ఉపయోగిస్తుంటే, `General.tun-included-routes`, `IP Rewrite`లను కాన్ఫిగర్ చేయాలి:

```ini
[General]
tun-included-routes = %INSERT% 10.7.0.1/32

[IP Rewrite]
10.7.0.1 = reflect
```

Swiptకు `ipv6-vif = disabled` అవసరం లేదు.

పబ్లిక్ డాక్యుమెంటేషన్ లేని, Surge లాంటి ఇతర యాప్‌లను ఎలా కాన్ఫిగర్ చేయాలో వాటి డెవలపర్‌లను అడగండి.

## ఆటోమేటిక్ అన్‌లాక్

మీ పాస్‌కోడ్‌ను సేవ్ చేయండి, తద్వారా డివైజ్ లాక్ అయి ఉన్నప్పుడు Swipt దాన్ని ఆటోమేటిక్‌గా అన్‌లాక్ చేయగలదు.

ప్రత్యేకంగా చెప్పాలంటే, Swipt API/MCPని ప్రారంభించడానికి Swipt CLI మీ డివైజ్‌ను అన్‌లాక్ చేయగలదు, డివైజ్‌ను ఆపరేట్ చేయడానికి Swipt CLI, MCP, ఇన్‌స్టాల్ చేసిన Swiplet మీ డివైజ్‌ను అన్‌లాక్ చేయగలవు.
