## Επισκόπηση

Το Swipt είναι μια πλατφόρμα αυτοματοποίησης.

## Απαιτήσεις

- Πλευρική φόρτωση
- iOS 27 (Υποστήριξη πρώτης βαθμίδας)
- iOS 17.4–26 (Απαιτεί μια επιπλέον συσκευή Mac, Windows ή Linux για τη δημιουργία αρχείου ζευγοποίησης. Δεν διαθέτω φυσικές συσκευές για δοκιμές, επομένως η υποστήριξη θα βασίζεται σε μεγάλο βαθμό σε εξωτερικές συνεισφορές.)

## Πλευρική φόρτωση με Mac

Αν δεν θέλετε να εγκαταστήσετε ένα αυτόνομο πλαίσιο πλευρικής φόρτωσης, συνιστούμε το εργαλείο `sideload` που είναι ενσωματωμένο στο Swipt CLI.

Υπογράφει και εγκαθιστά το Swipt με το Xcode, επομένως μπορεί:

- Να χρησιμοποιεί τον λογαριασμό Apple στον οποίο έχετε ήδη συνδεθεί, χωρίς να σας ζητά να συνδεθείτε ξανά.
- Να ρυθμίζει το Swipt ώστε να χρησιμοποιεί την υπάρχουσα ζευγοποίηση του Mac σας με τη συσκευή, χωρίς να χρειάζεται νέα ζευγοποίηση στη συσκευή.
- Να εμπιστεύεται το δωρεάν πιστοποιητικό προγραμματιστή και να ολοκληρώνει άλλες αρχικές ρυθμίσεις στη συσκευή σας.

Εκτελέστε στο Τερματικό:

```shell
npm install -g @swipt/cli
swipt sideload install
```

Στη συνέχεια, ακολουθήστε τις οδηγίες που εμφανίζονται για να επιλέξετε τη συσκευή στην οποία θα εγκατασταθεί το Swipt και την ομάδα που θα χρησιμοποιηθεί για την υπογραφή.

Το Swipt ολοκληρώνει αυτόματα σχεδόν όλη την αρχική ρύθμιση, αλλά πρέπει ακόμη να ξεκινήσετε το VPN loopback. Δείτε την ενότητα [Αρχική ρύθμιση](./setup.mdx).

```shell
swipt sideload update # Ενημέρωση του Swipt ή παράταση της ισχύος του
swipt sideload uninstall # Απεγκατάσταση του Swipt
```
