## Jumelage avec votre appareil

L’app Swipt doit être jumelée avec votre appareil pour se connecter à ses services de développeur.

Si vous avez installé l’app Swipt par chargement latéral avec Swipt CLI, le jumelage est configuré automatiquement. Sinon, suivez les instructions pour effectuer le jumelage :

Si vous utilisez iOS/iPadOS 27, vous pouvez effectuer le jumelage sur l’appareil en suivant les instructions dans l’app :

Si le jumelage sur l’appareil échoue, veuillez ouvrir un ticket.

Si vous utilisez une version antérieure d’iOS et que vous avez un Mac, vous pouvez quand même utiliser `swipt sideload setup` pour configurer le jumelage après avoir fait le chargement latéral manuellement. Sinon, vous devez effectuer le jumelage avec un autre logiciel.

Vous pouvez importer des fichiers de jumelage créés par presque n’importe quel autre logiciel, notamment :

- [Jitterbug](https://github.com/osy/Jitterbug) : `.mobiledevicepairing`
- [idevice](https://github.com/jkcoxson/idevice) : `ios_pairing_file.plist`
- [go-ios](https://github.com/danielpaulus/go-ios) : `selfIdentity.plist`

Voici la façon la plus courante d’obtenir un fichier de jumelage :

1. Téléchargez et installez [iloader](https://iloader.app). Sous Windows, installez d’abord [iTunes](https://www.apple.com/itunes/download/win64). Sous Linux, installez `usbmuxd` s’il n’est pas déjà installé.
2. Connectez votre iPhone ou iPad à votre ordinateur avec un câble USB. Si on vous le demande, faites confiance à l’ordinateur et entrez votre code d’accès.
3. Ouvrez iloader et sélectionnez votre iPhone ou iPad.
4. Sélectionnez « Manage Pairing File ».
5. Sélectionnez « Export (Not Recommended) », puis « Confirm », et enregistrez le fichier de jumelage.
6. Transférez le fichier de jumelage sur votre iPhone ou iPad, par exemple avec AirDrop ou iCloud Drive.

Si vous avez déjà installé SideStore, vous avez fort probablement déjà un fichier de jumelage!

## VPN de bouclage

L’app Swipt a besoin d’un VPN de bouclage pour se connecter aux services de développeur. Les logiciels suivants sont pris en charge :

#### LocalDevVPN

Installez l’app à partir de l’[App Store](https://apps.apple.com/app/id6755608044) et activez le VPN.

#### sing-box

Installez l’app à partir de l’[App Store](https://apps.apple.com/app/id6785326793), rédigez une configuration correcte et activez le VPN.

Vous devez configurer `tun.loopback_address` et `tun.route_address`.

Exemple de configuration :

```json
{
  "inbounds": [
    {
      "type": "tun",
      "address": "172.19.0.1/30",
      "auto_route": true,
      "loopback_address": "10.7.0.1",
      "route_address": "10.7.0.1/32"
    }
  ],
  "route": {
    "auto_detect_interface": true
  }
}
```

Déployé sur une passerelle, comme un routeur, sing-box fonctionne pour l’ensemble du réseau local.

#### Clash

Installez l’app à partir de l’[App Store](https://apps.apple.com/app/id6794257189), rédigez une configuration correcte et activez le VPN.

Vous devez configurer `tun.loopback-address` :

```yaml
tun:
  loopback-address:
    - 10.7.0.1
```

#### Logiciels à code source fermé

Si vous avez un abonnement à Surge et que vous l’utilisez, vous devez configurer `General.tun-included-routes` et `IP Rewrite` :

```ini
[General]
tun-included-routes = %INSERT% 10.7.0.1/32

[IP Rewrite]
10.7.0.1 = reflect
```

L’app Swipt n’a pas besoin de `ipv6-vif = disabled`.

Pour les autres apps semblables à Surge qui n’ont pas de documentation publique, demandez à leurs développeurs comment les configurer.

## Déverrouillage automatique

Enregistrez votre code pour que l’app Swipt puisse déverrouiller automatiquement votre appareil lorsqu’il est verrouillé.

Plus précisément, Swipt CLI peut déverrouiller votre appareil pour démarrer Swipt API/MCP, et Swipt CLI, MCP et les Swiplets installés peuvent déverrouiller votre appareil pour l’utiliser.
