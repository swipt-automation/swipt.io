## Jumelage avec votre appareil

L’app Swipt doit être jumelée avec votre appareil pour se connecter à ses services de développeur.

Si vous avez installé l’app Swipt par chargement latéral avec Swipt CLI, le jumelage est configuré automatiquement. Sinon, suivez les instructions dans l’app pour effectuer le jumelage :

Si le jumelage ne peut pas être effectué, veuillez nous signaler le problème. Vous pouvez aussi importer un fichier de jumelage provenant d’un autre logiciel, notamment :

- [Jitterbug](https://github.com/osy/Jitterbug) : `.mobiledevicepairing`
- [idevice](https://github.com/jkcoxson/idevice) : `ios_pairing_file.plist`
- [go-ios](https://github.com/danielpaulus/go-ios) : `selfIdentity.plist`

## VPN de bouclage

L’app Swipt a besoin d’un VPN de bouclage pour se connecter aux services de développeur. Suivez les instructions dans l’app pour télécharger et activer [LocalDevVPN](https://apps.apple.com/app/id6755608044) ou [sing-box](https://sing-box.sagernet.org). Pour sing-box, vous devez importer le [profil d’exemple](/setup/LocalDevVPN.json).

## Déverrouillage automatique

Enregistrez votre code pour que l’app Swipt puisse déverrouiller automatiquement votre appareil lorsqu’il est verrouillé.

Plus précisément, Swipt CLI peut déverrouiller votre appareil pour démarrer Swipt API/MCP, et Swipt CLI, MCP et les Swiplets installés peuvent déverrouiller votre appareil pour l’utiliser.
