## 기기와 페어링

기기의 개발자 서비스에 연결하려면 Swipt가 기기와 페어링해야 합니다.

Swipt CLI로 Swipt를 사이드로드한 경우 페어링이 자동으로 설정됩니다. 그렇지 않은 경우 안내에 따라 페어링하십시오.

iOS/iPadOS 27을 사용하는 경우 앱 내 안내에 따라 기기에서 페어링할 수 있습니다.

기기에서 페어링하지 못한 경우 이슈를 등록해 주십시오.

이전 버전의 iOS를 사용하고 있고 Mac이 있다면, 수동으로 사이드로드한 후에도 `swipt sideload setup`을 사용하여 페어링을 설정할 수 있습니다. 그렇지 않은 경우 다른 소프트웨어로 페어링해야 합니다.

다음을 포함하여 거의 모든 다른 소프트웨어에서 생성한 페어링 파일을 가져올 수 있습니다.

- [Jitterbug](https://github.com/osy/Jitterbug): `.mobiledevicepairing`
- [idevice](https://github.com/jkcoxson/idevice): `ios_pairing_file.plist`
- [go-ios](https://github.com/danielpaulus/go-ios): `selfIdentity.plist`

페어링 파일을 얻는 가장 일반적인 방법은 다음과 같습니다.

1. [iloader](https://iloader.app)를 다운로드하여 설치하십시오. Windows에서는 먼저 [iTunes](https://www.apple.com/itunes/download/win64)를 설치하십시오. Linux에서는 `usbmuxd`가 사전 설치되어 있지 않은 경우 설치하십시오.
2. USB 케이블로 iPhone 또는 iPad를 컴퓨터에 연결하십시오. 메시지가 표시되면 컴퓨터를 신뢰하고 암호를 입력하십시오.
3. iloader를 열고 iPhone 또는 iPad를 선택하십시오.
4. ‘Manage Pairing File’을 선택하십시오.
5. ‘Export (Not Recommended)’를 선택한 다음 ‘Confirm’을 선택하고 페어링 파일을 저장하십시오.
6. AirDrop 또는 iCloud Drive 등을 사용하여 페어링 파일을 iPhone 또는 iPad로 전송하십시오.

이전에 SideStore를 설치한 적이 있다면 이미 페어링 파일이 있을 가능성이 높습니다!

## 루프백 VPN

개발자 서비스에 연결하려면 Swipt에 루프백 VPN이 필요합니다. 다음 소프트웨어가 지원됩니다.

#### LocalDevVPN

[App Store](https://apps.apple.com/app/id6755608044)에서 설치하고 VPN을 켜십시오.

#### sing-box

[App Store](https://apps.apple.com/app/id6785326793)에서 설치하고 올바른 구성을 작성한 다음 VPN을 켜십시오.

`tun.loopback_address` 및 `tun.route_address`를 설정해야 합니다.

구성 예:

```json
{
  "inbounds": [
    {
      "type": "tun",
      "address": "172.19.0.1/30",
      "auto_route": true,
      "loopback_address": "10.7.0.1",
      "route_address": "10.7.0.1/32"
    }
  ],
  "route": {
    "auto_detect_interface": true
  }
}
```

라우터 등의 게이트웨이에 배포하면 전체 로컬 네트워크에서 작동합니다.

#### Clash

[App Store](https://apps.apple.com/app/id6794257189)에서 설치하고 올바른 구성을 작성한 다음 VPN을 켜십시오.

`tun.loopback-address`를 설정해야 합니다.

```yaml
tun:
  loopback-address:
    - 10.7.0.1
```

#### 클로즈드 소스 소프트웨어

Shadowrocket을 사용하는 경우 ‘설정’에서 **Include Route 10.7.0.1/32**를 켠 다음 VPN을 다시 연결하십시오. 이 옵션이 보이지 않으면 Shadowrocket을 업데이트하십시오.

Surge를 구독하여 사용하는 경우 `General.tun-included-routes` 및 `IP Rewrite`를 설정해야 합니다.

```ini
[General]
tun-included-routes = %INSERT% 10.7.0.1/32

[IP Rewrite]
10.7.0.1 = reflect
```

Swipt에는 `ipv6-vif = disabled`가 필요하지 않습니다.

Surge와 유사한 다른 앱 중 공개 문서가 없는 앱은 해당 앱 개발자에게 설정 방법을 문의하십시오.

## 자동 잠금 해제

암호를 저장하면 기기가 잠겨 있을 때 Swipt가 자동으로 잠금을 해제할 수 있습니다.

구체적으로, Swipt CLI는 Swipt API/MCP를 시작하기 위해 기기의 잠금을 해제할 수 있으며, Swipt CLI, MCP 및 설치된 Swiplet은 기기를 조작하기 위해 잠금을 해제할 수 있습니다.
