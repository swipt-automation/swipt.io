## மேலோட்டம்

Swipt என்பது தானியக்கத் தளமாகும்.

## தேவைகள்

- சைடுலோடு செய்தல்
- iOS 27 (முதல்நிலை ஆதரவு)
- iOS 17.4–26 (இணைசேர்ப்புக் கோப்பை உருவாக்க கூடுதலாக ஒரு Mac, Windows அல்லது Linux சாதனம் தேவை. சோதிப்பதற்கான சாதனங்கள் என் கைவசம் இல்லை. எனவே இதற்கான ஆதரவு பெரும்பாலும் வெளிப் பங்களிப்புகளையே சார்ந்திருக்கும்.)

## Mac மூலம் சைடுலோடு செய்தல்

தனித்தியங்கும் சைடுலோடு கட்டமைப்பை நிறுவ விரும்பவில்லை எனில் Swipt CLIஇல் உள்ளிணைந்த `sideload` கருவியைப் பரிந்துரைக்கிறோம்.

இது Xcodeஐப் பயன்படுத்தி Swiptஐக் கையொப்பமிட்டு நிறுவுகிறது. எனவே இந்தக் கருவியால்:

- மீண்டும் உள்நுழையுமாறு கேட்காமல் நீங்கள் ஏற்கெனவே உள்நுழைந்துள்ள Apple கணக்கைப் பயன்படுத்த முடியும்.
- சாதனத்தில் மீண்டும் இணைசேர்க்காமல் உங்கள் Macக்கும் சாதனத்திற்கும் இடையே ஏற்கெனவே உள்ள இணைசேர்ப்பைப் பயன்படுத்துமாறு Swiptஐ உள்ளமைக்க முடியும்.
- உங்கள் சாதனத்தில் இலவச டெவலப்பர் சான்றிதழை நம்பகமானதாக அமைப்பதுடன் முதல்முறைக்கான பிற உள்ளமைவுகளையும் செய்ய முடியும்.

Terminalஇல் பின்வரும் கட்டளைகளை இயக்கவும்:

```shell
npm install -g @swipt/cli
swipt sideload install
```

பிறகு திரையில் தோன்றும் வழிமுறைகளைப் பின்பற்றி நிறுவ வேண்டிய சாதனத்தையும் கையொப்பமிடுவதற்கான குழுவையும் தேர்வுசெய்யவும்.

Swipt கிட்டத்தட்ட எல்லா அமைவுப் பணிகளையும் தானாகவே நிறைவுசெய்யும். இருப்பினும் லூப்பேக் VPNஐ நீங்கள் தொடங்க வேண்டும். [அமைவு](./setup.mdx) பகுதியைப் பார்க்கவும்.

```shell
swipt sideload update # Swiptஐப் புதுப்பித்தல் அல்லது அதன் செல்லுபடிக் காலத்தை நீட்டித்தல்
swipt sideload uninstall # Swiptஐ நிறுவல் நீக்குதல்
```
