## உங்கள் சாதனத்துடன் இணைசேர்த்தல்

சாதனத்தின் டெவலப்பர் சேவைகளுடன் இணைய, Swipt உங்கள் சாதனத்துடன் இணைசேர வேண்டும்.

Swipt CLI மூலம் Swiptஐ சைடுலோடு செய்திருந்தால் இணைசேர்ப்பு தானாகவே அமைக்கப்படும். இல்லையெனில் இணைசேர்க்க ஆப்பில் உள்ள வழிமுறைகளைப் பின்பற்றவும்:

இணைசேர்ப்பை நிறைவுசெய்ய முடியவில்லை எனில் சிக்கலை எங்களிடம் தெரிவிக்கவும். மாற்றாக பிற மென்பொருட்களிலிருந்து இணைசேர்ப்புக் கோப்பை இம்போர்ட் செய்யலாம், எடுத்துக்காட்டாக:

- [Jitterbug](https://github.com/osy/Jitterbug): `.mobiledevicepairing`
- [idevice](https://github.com/jkcoxson/idevice): `ios_pairing_file.plist`
- [go-ios](https://github.com/danielpaulus/go-ios): `selfIdentity.plist`

## லூப்பேக் VPN

டெவலப்பர் சேவைகளுடன் இணைய Swiptக்கு லூப்பேக் VPN தேவை. பின்வரும் மென்பொருட்கள் ஆதரிக்கப்படுகின்றன:

#### LocalDevVPN

[App Storeஇலிருந்து](https://apps.apple.com/app/id6755608044) நிறுவி VPNஐ ஆன் செய்யவும்.

#### sing-box

[App Storeஇலிருந்து](https://apps.apple.com/app/id6785326793) நிறுவி, சரியான உள்ளமைவை எழுதி, VPNஐ ஆன் செய்யவும்.

`tun.loopback_address`, `tun.route_address` ஆகியவற்றை அமைக்க வேண்டும்.

மாதிரி உள்ளமைவு:

```json
{
  "inbounds": [
    {
      "type": "tun",
      "address": "172.19.0.1/30",
      "auto_route": true,
      "loopback_address": "10.7.0.1",
      "route_address": "10.7.0.1/32"
    }
  ],
  "route": {
    "auto_detect_interface": true
  }
}
```

ரூட்டர் போன்ற கேட்வேயில் இதை இயக்கினால், முழு உள்ளூர் நெட்வொர்க்கிற்கும் இது செயல்படும்.

#### Clash

[App Storeஇலிருந்து](https://apps.apple.com/app/id6794257189) நிறுவி, சரியான உள்ளமைவை எழுதி, VPNஐ ஆன் செய்யவும்.

`tun.loopback-address`ஐ அமைக்க வேண்டும்:

```yaml
tun:
  loopback-address:
    - 10.7.0.1
```

#### மூடிய மூல மென்பொருட்கள்

சந்தாவுடன் Surgeஐப் பயன்படுத்தினால், `General.tun-included-routes`, `IP Rewrite` ஆகியவற்றை அமைக்க வேண்டும்:

```ini
[General]
tun-included-routes = %INSERT% 10.7.0.1/32

[IP Rewrite]
10.7.0.1 = reflect
```

Swiptக்கு `ipv6-vif = disabled` தேவையில்லை.

பொது ஆவணம் இல்லாத Surgeஐ ஒத்த பிற ஆப்களை எப்படி அமைப்பது என்பதை அவற்றின் டெவலப்பர்களிடம் கேட்கவும்.

## தானியங்கு அன்லாக்

உங்கள் பாஸ்கோடைச் சேமிக்கவும். சாதனம் பூட்டப்பட்டிருக்கும்போது அதை Swipt தானாகவே அன்லாக் செய்ய இது உதவும்.

குறிப்பாக Swipt API/MCPஐத் தொடங்க Swipt CLI உங்கள் சாதனத்தை அன்லாக் செய்யலாம். சாதனத்தை இயக்க Swipt CLI, MCP, நிறுவப்பட்ட Swipletகள் ஆகியவை உங்கள் சாதனத்தை அன்லாக் செய்யலாம்.
