## Omówienie

Swipt to platforma do automatyzacji.

## Wymagania

- Sideloading
- iOS 27 (obsługa priorytetowa)
- iOS 17.4–26 (Wymaga dodatkowego Maca lub urządzenia z systemem Windows albo Linux do utworzenia pliku parowania. Nie mam fizycznych urządzeń do testowania, więc obsługa będzie w dużej mierze zależeć od zewnętrznego wkładu.)

## Sideloading za pomocą Maca

Jeśli nie chcesz instalować osobnego narzędzia do sideloadingu, zalecamy narzędzie `sideload` wbudowane w Swipt CLI.

Aplikację Swipt podpisuje i instaluje za pomocą aplikacji Xcode, dzięki czemu może:

- korzystać z już zalogowanego konta Apple bez konieczności ponownego logowania;
- skonfigurować aplikację Swipt tak, aby korzystała z istniejącego parowania Maca z urządzeniem, bez ponownego parowania na urządzeniu;
- zaufać bezpłatnemu certyfikatowi dewelopera i wykonać inne czynności wstępnej konfiguracji na urządzeniu.

W aplikacji Terminal wykonaj polecenia:

```shell
npm install -g @swipt/cli
swipt sideload install
```

Następnie postępuj zgodnie z wyświetlanymi instrukcjami, aby wybrać urządzenie, na którym ma zostać zainstalowana aplikacja, oraz zespół do jej podpisania.

Aplikacja Swipt automatycznie wykonuje niemal całą konfigurację, ale nadal musisz uruchomić VPN pętli zwrotnej. Zobacz sekcję [Konfiguracja](./setup.mdx).

```shell
swipt sideload update # Uaktualnij aplikację Swipt lub przedłuż jej ważność
swipt sideload uninstall # Odinstaluj aplikację Swipt
```
