## अपने डिवाइस के साथ पेयर करें

डिवाइस की डेवलपर सेवाओं से कनेक्ट होने के लिए Swipt को आपके डिवाइस के साथ पेयर करना होगा।

अगर आपने Swipt CLI से Swipt को साइडलोड किया है, तो पेयरिंग अपने आप सेट अप हो जाती है। अन्यथा, पेयर करने के लिए निर्देशों का पालन करें :

अगर आप iOS/iPadOS 27 इस्तेमाल कर रहे हैं, तो ऐप में दिए गए निर्देशों का पालन करके आप डिवाइस पर ही पेयर कर सकते हैं :

अगर डिवाइस पर पेयरिंग विफल हो जाती है, तो कृपया एक इशू खोलें।

अगर आप iOS का पुराना वर्शन इस्तेमाल कर रहे हैं और आपके पास Mac है, तो मैन्युअल रूप से साइडलोड करने के बाद पेयरिंग सेट अप करने के लिए आप अब भी `swipt sideload setup` का इस्तेमाल कर सकते हैं। अन्यथा, आपको अन्य सॉफ़्टवेयर से पेयर करना होगा।

आप लगभग किसी भी अन्य सॉफ़्टवेयर से बनाई गई पेयरिंग फ़ाइलें इंपोर्ट कर सकते हैं, जैसे :

- [Jitterbug](https://github.com/osy/Jitterbug) : `.mobiledevicepairing`
- [idevice](https://github.com/jkcoxson/idevice) : `ios_pairing_file.plist`
- [go-ios](https://github.com/danielpaulus/go-ios) : `selfIdentity.plist`

पेयरिंग फ़ाइल पाने का सबसे आम तरीका यह है :

1. [iloader](https://iloader.app) डाउनलोड और इंस्टॉल करें। Windows पर, पहले [iTunes](https://www.apple.com/itunes/download/win64) इंस्टॉल करें। Linux पर, अगर `usbmuxd` पहले से इंस्टॉल नहीं है, तो उसे इंस्टॉल करें।
2. USB केबल से अपने iPhone या iPad को अपने कंप्यूटर से कनेक्ट करें। अगर आपसे पूछा जाए, तो कंप्यूटर पर भरोसा करें और अपना पासकोड डालें।
3. iloader खोलें और अपना iPhone या iPad चुनें।
4. “Manage Pairing File” चुनें।
5. “Export (Not Recommended)” चुनें, फिर “Confirm” चुनें और पेयरिंग फ़ाइल सेव करें।
6. पेयरिंग फ़ाइल को अपने iPhone या iPad पर ट्रांसफ़र करें, जैसे AirDrop या iCloud Drive से।

अगर आपने पहले SideStore इंस्टॉल किया है, तो बहुत संभव है कि आपके पास पहले से ही पेयरिंग फ़ाइल हो!

## लूपबैक VPN

डेवलपर सेवाओं से कनेक्ट होने के लिए Swipt को लूपबैक VPN की ज़रूरत है। नीचे दिए गए सॉफ़्टवेयर समर्थित हैं :

#### LocalDevVPN

[App Store](https://apps.apple.com/app/id6755608044) से इंस्टॉल करें और VPN चालू करें।

#### sing-box

[App Store](https://apps.apple.com/app/id6785326793) से इंस्टॉल करें, सही कॉन्फ़िगरेशन लिखें और VPN चालू करें।

आपको `tun.loopback_address` और `tun.route_address` कॉन्फ़िगर करने होंगे।

उदाहरण कॉन्फ़िगरेशन :

```json
{
  "inbounds": [
    {
      "type": "tun",
      "address": "172.19.0.1/30",
      "auto_route": true,
      "loopback_address": "10.7.0.1",
      "route_address": "10.7.0.1/32"
    }
  ],
  "route": {
    "auto_detect_interface": true
  }
}
```

राउटर जैसे किसी गेटवे पर इसे डिप्लॉय करने से यह पूरे लोकल नेटवर्क के लिए काम करता है।

#### Clash

[App Store](https://apps.apple.com/app/id6794257189) से इंस्टॉल करें, सही कॉन्फ़िगरेशन लिखें और VPN चालू करें।

आपको `tun.loopback-address` कॉन्फ़िगर करना होगा :

```yaml
tun:
  loopback-address:
    - 10.7.0.1
```

#### क्लोज़्ड-सोर्स सॉफ़्टवेयर

अगर आपके पास Surge का सब्सक्रिप्शन है और आप उसका इस्तेमाल करते हैं, तो आपको `General.tun-included-routes` और `IP Rewrite` कॉन्फ़िगर करने होंगे :

```ini
[General]
tun-included-routes = %INSERT% 10.7.0.1/32

[IP Rewrite]
10.7.0.1 = reflect
```

Swipt के लिए `ipv6-vif = disabled` ज़रूरी नहीं है।

अगर Surge जैसे अन्य ऐप के सार्वजनिक दस्तावेज़ उपलब्ध नहीं हैं, तो उन्हें कॉन्फ़िगर करने का तरीका उनके डेवलपर से पूछें।

## स्वचालित अनलॉक

अपना पासकोड सहेजें, ताकि डिवाइस लॉक होने पर Swipt उसे अपने आप अनलॉक कर सके।

ख़ास तौर पर, Swipt CLI आपके डिवाइस को अनलॉक करके Swipt API/MCP शुरू कर सकता है, और Swipt CLI, MCP और इंस्टॉल किए गए Swiplet आपके डिवाइस को अनलॉक करके उसे ऑपरेट कर सकते हैं।
