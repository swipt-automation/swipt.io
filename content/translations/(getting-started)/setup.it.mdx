## Abbinamento con il dispositivo

Swipt deve essere abbinato al dispositivo per connettersi ai suoi servizi per sviluppatori.

Se hai eseguito il sideloading di Swipt con Swipt CLI, l’abbinamento viene configurato automaticamente. In caso contrario, segui le istruzioni per eseguire l’abbinamento:

Se usi iOS/iPadOS 27, puoi eseguire l’abbinamento direttamente sul dispositivo seguendo le istruzioni nell’app:

Se l’abbinamento sul dispositivo non riesce, apri una segnalazione.

Se usi una versione precedente di iOS e hai un Mac, puoi comunque usare `swipt sideload setup` per configurare l’abbinamento dopo aver eseguito manualmente il sideloading. In caso contrario, devi eseguire l’abbinamento con un altro software.

Puoi importare file di abbinamento creati da quasi qualsiasi altro software, tra cui:

- [Jitterbug](https://github.com/osy/Jitterbug): `.mobiledevicepairing`
- [idevice](https://github.com/jkcoxson/idevice): `ios_pairing_file.plist`
- [go-ios](https://github.com/danielpaulus/go-ios): `selfIdentity.plist`

Ecco il modo più comune per ottenere un file di abbinamento:

1. Scarica e installa [iloader](https://iloader.app). Su Windows, installa prima [iTunes](https://www.apple.com/itunes/download/win64). Su Linux, installa `usbmuxd` se non è preinstallato.
2. Collega iPhone o iPad al computer con un cavo USB. Se richiesto, autorizza il computer e inserisci il codice.
3. Apri iloader e seleziona il tuo iPhone o iPad.
4. Seleziona “Manage Pairing File”.
5. Seleziona “Export (Not Recommended)”, poi seleziona “Confirm” e salva il file di abbinamento.
6. Trasferisci il file di abbinamento su iPhone o iPad, ad esempio con AirDrop o iCloud Drive.

Se in passato hai installato SideStore, molto probabilmente hai già un file di abbinamento!

## VPN di loopback

Swipt ha bisogno di una VPN di loopback per connettersi ai servizi per sviluppatori. Sono supportati i seguenti software:

#### LocalDevVPN

Installa l’app da [App Store](https://apps.apple.com/app/id6755608044) e attiva la VPN.

#### sing-box

Installa l’app da [App Store](https://apps.apple.com/app/id6785326793), scrivi una configurazione corretta e attiva la VPN.

Devi configurare `tun.loopback_address` e `tun.route_address`.

Configurazione di esempio:

```json
{
  "inbounds": [
    {
      "type": "tun",
      "address": "172.19.0.1/30",
      "auto_route": true,
      "loopback_address": "10.7.0.1",
      "route_address": "10.7.0.1/32"
    }
  ],
  "route": {
    "auto_detect_interface": true
  }
}
```

Se installi sing-box su un gateway, ad esempio un router, funzionerà per l’intera rete locale.

#### Clash

Installa l’app da [App Store](https://apps.apple.com/app/id6794257189), scrivi una configurazione corretta e attiva la VPN.

Devi configurare `tun.loopback-address`:

```yaml
tun:
  loopback-address:
    - 10.7.0.1
```

#### Software a codice chiuso

Se usi Shadowrocket, attiva **Include Route 10.7.0.1/32** in Impostazioni, poi riconnetti la VPN. Se non vedi questa opzione, aggiorna Shadowrocket.

Se hai un abbonamento a Surge e lo utilizzi, devi configurare `General.tun-included-routes` e `IP Rewrite`:

```ini
[General]
tun-included-routes = %INSERT% 10.7.0.1/32

[IP Rewrite]
10.7.0.1 = reflect
```

`ipv6-vif = disabled` non è necessario per Swipt.

Per altre app simili a Surge prive di documentazione pubblica, chiedi ai rispettivi sviluppatori come configurarle.

## Sblocco automatico

Salva il codice per consentire a Swipt di sbloccare automaticamente il dispositivo quando è bloccato.

Nello specifico, Swipt CLI può sbloccare il dispositivo per avviare Swipt API/MCP, mentre Swipt CLI, MCP e gli Swiplet installati possono sbloccare il dispositivo per utilizzarlo.
