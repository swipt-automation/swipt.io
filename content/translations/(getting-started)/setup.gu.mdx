## તમારા ડિવાઇસ સાથે પેર કરો

ડિવાઇસની ડેવલપર સેવાઓ સાથે કનેક્ટ થવા માટે Swiptને તમારા ડિવાઇસ સાથે પેર કરવાની જરૂર છે.

જો તમે Swipt CLI દ્વારા Swiptને સાઇડલોડ કર્યું હોય, તો પેરિંગ આપમેળે સેટ અપ થાય છે. અન્યથા, પેર કરવા માટે સૂચનાઓને અનુસરો :

જો તમે iOS/iPadOS 27નો ઉપયોગ કરી રહ્યા હો, તો ઍપમાં આપેલી સૂચનાઓને અનુસરીને તમે ડિવાઇસ પર જ પેર કરી શકો છો :

જો ડિવાઇસ પર પેરિંગ નિષ્ફળ જાય, તો કૃપા કરીને એક ઇશ્યૂ ખોલો.

જો તમે iOSના અગાઉના વર્ઝનનો ઉપયોગ કરી રહ્યા હો અને તમારી પાસે Mac હોય, તો મૅન્યુઅલી સાઇડલોડ કર્યા પછી પેરિંગ સેટ અપ કરવા માટે તમે હજી પણ `swipt sideload setup`નો ઉપયોગ કરી શકો છો. અન્યથા, તમારે અન્ય સૉફ્ટવેર વડે પેર કરવું પડશે.

તમે લગભગ કોઈ પણ અન્ય સૉફ્ટવેર દ્વારા બનાવેલી પેરિંગ ફાઇલો ઇંપોર્ટ કરી શકો છો, જેમ કે :

- [Jitterbug](https://github.com/osy/Jitterbug) : `.mobiledevicepairing`
- [idevice](https://github.com/jkcoxson/idevice) : `ios_pairing_file.plist`
- [go-ios](https://github.com/danielpaulus/go-ios) : `selfIdentity.plist`

પેરિંગ ફાઇલ મેળવવાની સૌથી સામાન્ય રીત આ છે :

1. [iloader](https://iloader.app) ડાઉનલોડ કરીને ઇન્સ્ટૉલ કરો. Windows પર, પહેલાં [iTunes](https://www.apple.com/itunes/download/win64) ઇન્સ્ટૉલ કરો. Linux પર, જો `usbmuxd` પહેલેથી ઇન્સ્ટૉલ કરેલું ન હોય, તો તેને ઇન્સ્ટૉલ કરો.
2. USB કેબલ વડે તમારા iPhone અથવા iPadને તમારા કમ્પ્યૂટર સાથે કનેક્ટ કરો. જો તમને પૂછવામાં આવે, તો કમ્પ્યૂટર પર વિશ્વાસ કરો અને તમારો પાસકોડ દાખલ કરો.
3. iloader ખોલો અને તમારો iPhone અથવા iPad પસંદ કરો.
4. “Manage Pairing File” પસંદ કરો.
5. “Export (Not Recommended)” પસંદ કરો, પછી “Confirm” પસંદ કરો અને પેરિંગ ફાઇલ સેવ કરો.
6. ઉદાહરણ તરીકે AirDrop અથવા iCloud Drive દ્વારા, પેરિંગ ફાઇલને તમારા iPhone અથવા iPad પર ટ્રાન્સફર કરો.

જો તમે અગાઉ SideStore ઇન્સ્ટૉલ કર્યું હોય, તો સંભવતઃ તમારી પાસે પહેલેથી જ પેરિંગ ફાઇલ છે!

## લૂપબૅક VPN

ડેવલપર સેવાઓ સાથે કનેક્ટ થવા માટે Swiptને લૂપબૅક VPNની જરૂર છે. નીચેના સૉફ્ટવેર સપોર્ટેડ છે :

#### LocalDevVPN

[App Store](https://apps.apple.com/app/id6755608044) પરથી ઇન્સ્ટૉલ કરો અને VPN ચાલુ કરો.

#### sing-box

[App Store](https://apps.apple.com/app/id6785326793) પરથી ઇન્સ્ટૉલ કરો, યોગ્ય કન્ફિગરેશન લખો અને VPN ચાલુ કરો.

તમારે `tun.loopback_address` અને `tun.route_address` કન્ફિગર કરવાની જરૂર છે.

ઉદાહરણ કન્ફિગરેશન :

```json
{
  "inbounds": [
    {
      "type": "tun",
      "address": "172.19.0.1/30",
      "auto_route": true,
      "loopback_address": "10.7.0.1",
      "route_address": "10.7.0.1/32"
    }
  ],
  "route": {
    "auto_detect_interface": true
  }
}
```

રાઉટર જેવા ગેટવે પર તેને ડિપ્લૉય કરવાથી તે સમગ્ર લોકલ નેટવર્ક માટે કામ કરે છે.

#### Clash

[App Store](https://apps.apple.com/app/id6794257189) પરથી ઇન્સ્ટૉલ કરો, યોગ્ય કન્ફિગરેશન લખો અને VPN ચાલુ કરો.

તમારે `tun.loopback-address` કન્ફિગર કરવાની જરૂર છે :

```yaml
tun:
  loopback-address:
    - 10.7.0.1
```

#### ક્લોઝ્ડ-સોર્સ સૉફ્ટવેર

જો તમે Shadowrocketનો ઉપયોગ કરતા હો, તો “સેટિંગ્સ”માં **Include Route 10.7.0.1/32** ચાલુ કરો, પછી VPN ફરીથી કનેક્ટ કરો. જો તમને આ વિકલ્પ ન દેખાય, તો Shadowrocket અપડેટ કરો.

જો તમે સબ્સ્ક્રિપ્શન લઈને Surgeનો ઉપયોગ કરતા હો, તો તમારે `General.tun-included-routes` અને `IP Rewrite` કન્ફિગર કરવાની જરૂર છે :

```ini
[General]
tun-included-routes = %INSERT% 10.7.0.1/32

[IP Rewrite]
10.7.0.1 = reflect
```

Swipt માટે `ipv6-vif = disabled` જરૂરી નથી.

જો Surge જેવી અન્ય ઍપનું જાહેર દસ્તાવેજીકરણ ઉપલબ્ધ ન હોય, તો તેને કેવી રીતે કન્ફિગર કરવી તે તેના ડેવલપરને પૂછો.

## ઑટોમેટિક અનલૉક

તમારો પાસકોડ સેવ કરો, જેથી ડિવાઇસ લૉક હોય ત્યારે Swipt તેને આપમેળે અનલૉક કરી શકે.

ખાસ કરીને, Swipt API/MCP શરૂ કરવા માટે Swipt CLI તમારા ડિવાઇસને અનલૉક કરી શકે છે, અને ડિવાઇસનું સંચાલન કરવા માટે Swipt CLI, MCP અને ઇન્સ્ટૉલ કરેલા Swiplet તમારા ડિવાઇસને અનલૉક કરી શકે છે.
