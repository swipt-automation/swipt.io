## ಅವಲೋಕನ

Swipt ಸ್ವಯಂಚಾಲನಾ ಪ್ಲಾಟ್‌ಫಾರ್ಮ್ ಆಗಿದೆ.

ಇದು ಪ್ರಸ್ತುತ **iOS 27** ಅಥವಾ ನಂತರದ ಆವೃತ್ತಿಯಲ್ಲಿ ಚಾಲನೆಯಲ್ಲಿರುವ iPhone ಮತ್ತು iPadಗಳನ್ನು ಮಾತ್ರ ಬೆಂಬಲಿಸುತ್ತದೆ ಮತ್ತು ಇದನ್ನು ಸೈಡ್‌ಲೋಡ್ ಮಾಡಬೇಕು.

## Mac ಬಳಸಿ ಸೈಡ್‌ಲೋಡ್ ಮಾಡುವುದು

ಪ್ರತ್ಯೇಕ ಸೈಡ್‌ಲೋಡಿಂಗ್ ಫ್ರೇಮ್‌ವರ್ಕ್ ಅನ್ನು ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡಲು ನೀವು ಬಯಸದಿದ್ದರೆ, Swipt CLIಯ ಅಂತರ್ನಿರ್ಮಿತ `sideload` ಟೂಲ್ ಅನ್ನು ಬಳಸುವಂತೆ ನಾವು ಶಿಫಾರಸು ಮಾಡುತ್ತೇವೆ.

ಇದು Xcode ಬಳಸಿ Swipt ಆ್ಯಪ್ ಅನ್ನು ಸೈನ್ ಮಾಡಿ ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡುತ್ತದೆ, ಹಾಗಾಗಿ ಇದು ಹೀಗೆ ಮಾಡಬಲ್ಲದು:

- ನೀವು ಈಗಾಗಲೇ ಸೈನ್ ಇನ್ ಮಾಡಿರುವ Apple ಖಾತೆಯನ್ನು ಬಳಸಬಲ್ಲದು, ಮತ್ತೆ ಸೈನ್ ಇನ್ ಮಾಡುವಂತೆ ಕೇಳುವುದಿಲ್ಲ.
- ಸಾಧನದೊಂದಿಗೆ ನಿಮ್ಮ Mac ಈಗಾಗಲೇ ಹೊಂದಿರುವ ಪೇರಿಂಗ್ ಅನ್ನು ಬಳಸುವಂತೆ Swipt ಆ್ಯಪ್ ಅನ್ನು ಕಾನ್ಫಿಗರ್ ಮಾಡಬಲ್ಲದು, ಸಾಧನದಲ್ಲಿ ಮತ್ತೆ ಪೇರ್ ಮಾಡುವ ಅಗತ್ಯವಿಲ್ಲ.
- ನಿಮ್ಮ ಸಾಧನದಲ್ಲಿ ಉಚಿತ ಡೆವಲಪರ್ ಪ್ರಮಾಣಪತ್ರದ ಮೇಲೆ ವಿಶ್ವಾಸವಿಡಬಲ್ಲದು ಮತ್ತು ಮೊದಲ ಬಾರಿಗೆ ಮಾಡಬೇಕಾದ ಇತರ ಕಾನ್ಫಿಗರೇಶನ್ ಅನ್ನು ಪೂರ್ಣಗೊಳಿಸಬಲ್ಲದು.

Terminal ಆ್ಯಪ್‌ನಲ್ಲಿ, ಇದನ್ನು ರನ್ ಮಾಡಿ:

```shell
npm install -g @swipt/cli
swipt sideload install
```

ನಂತರ, ಪ್ರಾಂಪ್ಟ್‌ಗಳನ್ನು ಅನುಸರಿಸಿ ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡಬೇಕಾದ ಸಾಧನವನ್ನು ಮತ್ತು ಸೈನ್ ಮಾಡಲು ಬಳಸುವ ಟೀಮ್ ಅನ್ನು ಆಯ್ಕೆ ಮಾಡಿ.

Swipt ಆ್ಯಪ್ ಬಹುತೇಕ ಎಲ್ಲಾ ಸೆಟಪ್ ಅನ್ನು ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಪೂರ್ಣಗೊಳಿಸುತ್ತದೆ, ಆದರೆ ಲೂಪ್‌ಬ್ಯಾಕ್ VPN ಅನ್ನು ನೀವೇ ಪ್ರಾರಂಭಿಸಬೇಕು. [ಸೆಟಪ್](./setup.mdx) ವಿಭಾಗವನ್ನು ನೋಡಿ.

```shell
swipt sideload update # Swipt ಆ್ಯಪ್ ಅನ್ನು ಅಪ್‌ಡೇಟ್ ಮಾಡಿ ಅಥವಾ ಅದರ ಮುಕ್ತಾಯ ಅವಧಿಯನ್ನು ವಿಸ್ತರಿಸಿ
swipt sideload uninstall # Swipt ಆ್ಯಪ್ ಅನ್ನು ಅನ್‌ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡಿ
```
