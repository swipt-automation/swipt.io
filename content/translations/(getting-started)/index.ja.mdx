## 概要

Swiptは自動化プラットフォームです。

## 要件

- サイドロード
- iOS 27（最優先でサポート）
- iOS 17.4〜26（ペアリングファイルを作成するために、別途Mac、Windows、またはLinuxデバイスが必要です。私はテスト用の実機を持っていないため、サポートは外部からの貢献に大きく依存します。）

## Macでサイドロード

独立したサイドロードフレームワークをインストールしたくない場合は、Swipt CLIに組み込まれている`sideload`ツールをおすすめします。

XcodeでSwiptに署名してインストールするため、次のことが可能です:

- サインイン済みのApple Accountをそのまま使用でき、再度サインインする必要はありません。
- Macとデバイスの既存のペアリングを使用するようにSwiptを構成でき、デバイス上で再度ペアリングする必要はありません。
- デバイス上で無料のデベロッパ証明書を信頼し、その他の初期設定も行えます。

“ターミナル”で次のコマンドを実行します:

```shell
npm install -g @swipt/cli
swipt sideload install
```

その後、表示される指示に従って、インストール先のデバイスと署名に使用するチームを選択します。

Swiptのセットアップはほぼすべて自動で完了しますが、ループバックVPNは自分で起動する必要があります。詳しくは、[セットアップ](./setup.mdx)を参照してください。

```shell
swipt sideload update # Swiptをアップデート、または有効期限を延長
swipt sideload uninstall # Swiptをアンインストール
```
