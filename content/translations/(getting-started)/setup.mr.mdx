## तुमच्या डिव्हाइसशी पेअर करा

डिव्हाइसच्या डेव्हलपर सेवांशी कनेक्ट होण्यासाठी Swipt ला तुमच्या डिव्हाइसशी पेअर करणे आवश्यक आहे.

तुम्ही Swipt CLI वापरून Swipt साइडलोड केले असल्यास, पेअरिंग आपोआप सेट केले जाते. अन्यथा, पेअर करण्यासाठी सूचनांचे पालन करा :

तुम्ही iOS/iPadOS 27 वापरत असल्यास, ॲपमधील सूचनांचे पालन करून तुम्ही डिव्हाइसवरच पेअर करू शकता :

डिव्हाइसवरील पेअरिंग अयशस्वी झाल्यास, कृपया एक इश्यू उघडा.

तुम्ही iOS ची जुनी आवृत्ती वापरत असल्यास आणि तुमच्याकडे Mac असल्यास, मॅन्युअली साइडलोड केल्यानंतरही पेअरिंग सेट करण्यासाठी तुम्ही `swipt sideload setup` वापरू शकता. अन्यथा, तुम्हाला इतर सॉफ्टवेअरद्वारे पेअर करावे लागेल.

तुम्ही जवळजवळ कोणत्याही इतर सॉफ्टवेअरने तयार केलेल्या पेअरिंग फाइल इंपोर्ट करू शकता, जसे की :

- [Jitterbug](https://github.com/osy/Jitterbug) : `.mobiledevicepairing`
- [idevice](https://github.com/jkcoxson/idevice) : `ios_pairing_file.plist`
- [go-ios](https://github.com/danielpaulus/go-ios) : `selfIdentity.plist`

पेअरिंग फाइल मिळवण्याचा सर्वात सामान्य मार्ग पुढीलप्रमाणे आहे :

1. [iloader](https://iloader.app) डाउनलोड करून इंस्टॉल करा. Windows वर, आधी [iTunes](https://www.apple.com/itunes/download/win64) इंस्टॉल करा. Linux वर, `usbmuxd` आधीपासून इंस्टॉल नसल्यास ते इंस्टॉल करा.
2. USB केबलद्वारे तुमचा iPhone किंवा iPad कॉम्प्युटरला कनेक्ट करा. विचारले गेल्यास, कॉम्प्युटरवर विश्वास ठेवा आणि तुमचा पासकोड एंटर करा.
3. iloader उघडा आणि तुमचा iPhone किंवा iPad निवडा.
4. ‘Manage Pairing File’ निवडा.
5. ‘Export (Not Recommended)’ निवडा, नंतर ‘Confirm’ निवडा आणि पेअरिंग फाइल सेव्ह करा.
6. उदाहरणार्थ AirDrop किंवा iCloud Drive वापरून, पेअरिंग फाइल तुमच्या iPhone किंवा iPad वर ट्रान्सफर करा.

तुम्ही यापूर्वी SideStore इंस्टॉल केले असल्यास, तुमच्याकडे बहुधा आधीच पेअरिंग फाइल असेल!

## लूपबॅक VPN

डेव्हलपर सेवांशी कनेक्ट होण्यासाठी Swipt ला लूपबॅक VPN ची आवश्यकता आहे. पुढील सॉफ्टवेअर समर्थित आहेत :

#### LocalDevVPN

[App Store](https://apps.apple.com/app/id6755608044) वरून इंस्टॉल करा आणि VPN सुरू करा.

#### sing-box

[App Store](https://apps.apple.com/app/id6785326793) वरून इंस्टॉल करा, योग्य कॉन्फिगरेशन लिहा आणि VPN सुरू करा.

तुम्हाला `tun.loopback_address` आणि `tun.route_address` कॉन्फिगर करावे लागतील.

उदाहरण कॉन्फिगरेशन :

```json
{
  "inbounds": [
    {
      "type": "tun",
      "address": "172.19.0.1/30",
      "auto_route": true,
      "loopback_address": "10.7.0.1",
      "route_address": "10.7.0.1/32"
    }
  ],
  "route": {
    "auto_detect_interface": true
  }
}
```

राउटरसारख्या गेटवेवर हे डिप्लॉय केल्यास, ते संपूर्ण लोकल नेटवर्कसाठी काम करते.

#### Clash

[App Store](https://apps.apple.com/app/id6794257189) वरून इंस्टॉल करा, योग्य कॉन्फिगरेशन लिहा आणि VPN सुरू करा.

तुम्हाला `tun.loopback-address` कॉन्फिगर करावे लागेल :

```yaml
tun:
  loopback-address:
    - 10.7.0.1
```

#### क्लोज्ड-सोर्स सॉफ्टवेअर

तुम्ही Shadowrocket वापरत असल्यास, ‘सेटिंग्ज’ मध्ये **Include Route 10.7.0.1/32** सुरू करा, नंतर VPN पुन्हा कनेक्ट करा. हा पर्याय दिसत नसल्यास, Shadowrocket अपडेट करा.

तुम्ही सबस्क्रिप्शन घेऊन Surge वापरत असल्यास, तुम्हाला `General.tun-included-routes` आणि `IP Rewrite` कॉन्फिगर करावे लागतील :

```ini
[General]
tun-included-routes = %INSERT% 10.7.0.1/32

[IP Rewrite]
10.7.0.1 = reflect
```

Swipt साठी `ipv6-vif = disabled` आवश्यक नाही.

सार्वजनिक दस्तऐवजीकरण उपलब्ध नसलेल्या Surge सारख्या इतर ॲप्ससाठी, कॉन्फिगरेशन कसे करायचे हे त्यांच्या डेव्हलपर्सना विचारा.

## स्वयंचलित अनलॉक

तुमचा पासकोड जतन करा, जेणेकरून डिव्हाइस लॉक असताना Swipt ते आपोआप अनलॉक करू शकेल.

विशेषतः, Swipt API/MCP सुरू करण्यासाठी Swipt CLI तुमचे डिव्हाइस अनलॉक करू शकते आणि डिव्हाइस ऑपरेट करण्यासाठी Swipt CLI, MCP आणि इंस्टॉल केलेले Swiplet तुमचे डिव्हाइस अनलॉक करू शकतात.
