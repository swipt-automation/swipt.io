## Áttekintés

A Swipt automatizálási platform.

## Követelmények

- Oldalról telepítés
- iOS 27 (elsődleges támogatás)
- iOS 17.4–26 (A párosítási fájl létrehozásához egy további Mac-, Windows- vagy Linux-eszköz szükséges. Nincsenek fizikai eszközeim a teszteléshez, ezért a támogatás nagymértékben külső hozzájárulásokon fog alapulni.)

## Oldalról telepítés Mackel

Ha nem szeretne önálló, oldalról telepítésre szolgáló keretrendszert telepíteni, a Swipt CLI beépített `sideload` segédprogramját javasoljuk.

Ez a segédprogram az Xcode-dal írja alá és telepíti a Swipt appot, így:

- Azt az Apple-fiókot használja, amelybe már bejelentkezett, és nem kéri az újbóli bejelentkezést.
- Beállítja, hogy a Swipt app a Mac és az eszköz közötti meglévő párosítást használja, így az eszközön nem kell újra párosítania.
- Az eszközön megbízhatónak jelöli az ingyenes fejlesztői tanúsítványt, és elvégzi az első használathoz szükséges többi beállítást.

A Terminál appban futtassa a következő parancsokat:

```shell
npm install -g @swipt/cli
swipt sideload install
```

Ezután a megjelenő utasításokat követve válassza ki az eszközt, amelyre telepíteni szeretne, és az aláíráshoz használni kívánt fejlesztői csapatot.

A Swipt szinte a teljes beállítást automatikusan elvégzi, de a visszacsatolási VPN-t továbbra is Önnek kell elindítania. Lásd a [Kezdeti beállítás](./setup.mdx) című részt.

```shell
swipt sideload update # A Swipt app frissítése vagy lejáratának meghosszabbítása
swipt sideload uninstall # A Swipt app eltávolítása
```
