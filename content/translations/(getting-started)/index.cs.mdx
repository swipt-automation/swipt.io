## Přehled

Swipt je platforma pro automatizaci.

V současnosti podporuje pouze iPhony a iPady se systémem **iOS 27** nebo novějším a je nutné ji nainstalovat pomocí sideloadingu.

## Sideloading pomocí Macu

Pokud nechcete instalovat samostatný nástroj pro sideloading, doporučujeme nástroj `sideload`, který je součástí Swipt CLI.

Aplikaci Swipt podepisuje a instaluje pomocí Xcode, takže dokáže:

- Použít účet Apple, ke kterému jste již přihlášeni, aniž byste se museli znovu přihlašovat.
- Nastavit aplikaci Swipt tak, aby používala stávající párování vašeho Macu se zařízením, aniž byste museli párování na zařízení opakovat.
- Důvěřovat bezplatnému vývojářskému certifikátu a provést na zařízení další počáteční nastavení.

V aplikaci Terminál spusťte následující příkazy:

```shell
npm install -g @swipt/cli
swipt sideload install
```

Poté podle pokynů vyberte zařízení pro instalaci a tým pro podepsání.

Aplikace Swipt provede téměř celé nastavení automaticky, ale ještě musíte spustit VPN se zpětnou smyčkou. Viz část [Počáteční nastavení](./setup.mdx).

```shell
swipt sideload update # Aktualizovat aplikaci Swipt nebo prodloužit její platnost
swipt sideload uninstall # Odinstalovat aplikaci Swipt
```
