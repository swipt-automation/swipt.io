## デバイスとのペアリング

デバイスのデベロッパサービスに接続するには、Swiptをデバイスとペアリングする必要があります。

Swipt CLIを使ってSwiptをサイドロードした場合、ペアリングは自動的に設定されます。それ以外の場合は、次の手順に従ってペアリングしてください:

iOS/iPadOS 27を使用している場合は、アプリ内の指示に従ってデバイス上でペアリングできます:

デバイス上でのペアリングに失敗した場合は、Issueを作成してください。

それより前のバージョンのiOSを使用していてMacをお持ちの場合は、手動でサイドロードした後でも`swipt sideload setup`を使ってペアリングを設定できます。それ以外の場合は、他のソフトウェアでペアリングする必要があります。

他のほとんどのソフトウェアで作成されたペアリングファイルを読み込むことができます。次のようなものがあります:

- [Jitterbug](https://github.com/osy/Jitterbug): `.mobiledevicepairing`
- [idevice](https://github.com/jkcoxson/idevice): `ios_pairing_file.plist`
- [go-ios](https://github.com/danielpaulus/go-ios): `selfIdentity.plist`

ペアリングファイルを入手する最も一般的な方法は次のとおりです:

1. [iloader](https://iloader.app)をダウンロードしてインストールします。Windowsでは、先に[iTunes](https://www.apple.com/itunes/download/win64)をインストールしてください。Linuxでは、`usbmuxd`がプリインストールされていない場合はインストールしてください。
2. USBケーブルでiPhoneまたはiPadをコンピュータに接続します。求められた場合は、コンピュータを信頼してパスコードを入力します。
3. iloaderを開き、iPhoneまたはiPadを選択します。
4. “Manage Pairing File”を選択します。
5. “Export (Not Recommended)”を選択し、“Confirm”を選択してペアリングファイルを保存します。
6. AirDropやiCloud Driveなどを使って、ペアリングファイルをiPhoneまたはiPadに転送します。

以前にSideStoreをインストールしたことがある場合は、すでにペアリングファイルを持っている可能性が高いです！

## ループバックVPN

デベロッパサービスに接続するには、SwiptにループバックVPNが必要です。次のソフトウェアに対応しています:

#### LocalDevVPN

[App Store](https://apps.apple.com/app/id6755608044)からインストールし、VPNをオンにしてください。

#### sing-box

[App Store](https://apps.apple.com/app/id6785326793)からインストールし、正しい構成を記述して、VPNをオンにしてください。

`tun.loopback_address`と`tun.route_address`を設定する必要があります。

構成例:

```json
{
  "inbounds": [
    {
      "type": "tun",
      "address": "172.19.0.1/30",
      "auto_route": true,
      "loopback_address": "10.7.0.1",
      "route_address": "10.7.0.1/32"
    }
  ],
  "route": {
    "auto_detect_interface": true
  }
}
```

ルーターなどのゲートウェイにデプロイすると、ローカルネットワーク全体で機能します。

#### Clash

[App Store](https://apps.apple.com/app/id6794257189)からインストールし、正しい構成を記述して、VPNをオンにしてください。

`tun.loopback-address`を設定する必要があります:

```yaml
tun:
  loopback-address:
    - 10.7.0.1
```

#### クローズドソースソフトウェア

Shadowrocketを使用している場合は、“設定”で**Include Route 10.7.0.1/32**をオンにしてから、VPNに再接続してください。このオプションが表示されない場合は、Shadowrocketをアップデートしてください。

Surgeのサブスクリプションに登録して使用している場合は、`General.tun-included-routes`と`IP Rewrite`を設定する必要があります:

```ini
[General]
tun-included-routes = %INSERT% 10.7.0.1/32

[IP Rewrite]
10.7.0.1 = reflect
```

Swiptでは`ipv6-vif = disabled`は必要ありません。

Surgeに似たその他のアプリで公開ドキュメントがないものについては、設定方法を各アプリのデベロッパにお問い合わせください。

## 自動ロック解除

パスコードを保存すると、デバイスがロックされているときにSwiptが自動的にロックを解除できます。

具体的には、Swipt CLIはSwipt API/MCPを起動するためにデバイスのロックを解除でき、Swipt CLI、MCP、およびインストール済みのSwipletはデバイスを操作するためにロックを解除できます。
