## デバイスとのペアリング

デバイスのデベロッパサービスに接続するには、Swiptをデバイスとペアリングする必要があります。

Swipt CLIを使ってSwiptをサイドロードした場合、ペアリングは自動的に設定されます。それ以外の場合は、アプリ内の指示に従ってペアリングしてください:

ペアリングを完了できない場合は、問題をご報告ください。または、次のような他のソフトウェアのペアリングファイルを読み込むこともできます:

- [Jitterbug](https://github.com/osy/Jitterbug): `.mobiledevicepairing`
- [idevice](https://github.com/jkcoxson/idevice): `ios_pairing_file.plist`
- [go-ios](https://github.com/danielpaulus/go-ios): `selfIdentity.plist`

## ループバックVPN

デベロッパサービスに接続するには、SwiptにループバックVPNが必要です。次のソフトウェアに対応しています:

#### LocalDevVPN

[App Store](https://apps.apple.com/app/id6755608044)からインストールし、VPNをオンにしてください。

#### sing-box

[App Store](https://apps.apple.com/app/id6785326793)からインストールし、正しい構成を記述して、VPNをオンにしてください。

`tun.loopback_address`と`tun.route_address`を設定する必要があります。

構成例:

```json
{
  "inbounds": [
    {
      "type": "tun",
      "address": "172.19.0.1/30",
      "auto_route": true,
      "loopback_address": "10.7.0.1",
      "route_address": "10.7.0.1/32"
    }
  ],
  "route": {
    "auto_detect_interface": true
  }
}
```

ルーターなどのゲートウェイにデプロイすると、ローカルネットワーク全体で機能します。

#### Clash

[App Store](https://apps.apple.com/app/id6794257189)からインストールし、正しい構成を記述して、VPNをオンにしてください。

`tun.loopback-address`を設定する必要があります:

```yaml
tun:
  loopback-address:
    - 10.7.0.1
```

#### クローズドソースソフトウェア

Surgeのサブスクリプションに登録して使用している場合は、`General.tun-included-routes`と`IP Rewrite`を設定する必要があります:

```ini
[General]
tun-included-routes = %INSERT% 10.7.0.1/32

[IP Rewrite]
10.7.0.1 = reflect
```

Swiptでは`ipv6-vif = disabled`は必要ありません。

Surgeに似たその他のアプリで公開ドキュメントがないものについては、設定方法を各アプリのデベロッパにお問い合わせください。

## 自動ロック解除

パスコードを保存すると、デバイスがロックされているときにSwiptが自動的にロックを解除できます。

具体的には、Swipt CLIはSwipt API/MCPを起動するためにデバイスのロックを解除でき、Swipt CLI、MCP、およびインストール済みのSwipletはデバイスを操作するためにロックを解除できます。
