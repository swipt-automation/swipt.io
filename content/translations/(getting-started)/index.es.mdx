## Descripción general

Swipt es una plataforma de automatización.

## Requisitos

- Carga lateral
- iOS 27 (Compatibilidad de primer nivel)
- iOS 17.4–26 (Requiere un dispositivo Mac, Windows o Linux adicional para crear un archivo de enlace. No tengo dispositivos físicos para hacer pruebas, así que la compatibilidad dependerá en gran medida de las contribuciones externas.)

## Carga lateral con un Mac

Si no quieres instalar una herramienta independiente de carga lateral, te recomendamos el comando `sideload` integrado en Swipt CLI.

Firma e instala Swipt con Xcode, por lo que puede:

- usar la cuenta de Apple con la que ya has iniciado sesión, sin pedirte que vuelvas a hacerlo;
- configurar Swipt para que use el enlace que ya existe entre el Mac y el dispositivo, sin tener que repetir el enlace en el dispositivo;
- confiar en el certificado gratuito de desarrollador y realizar otras tareas de configuración inicial en el dispositivo.

En Terminal, ejecuta:

```shell
npm install -g @swipt/cli
swipt sideload install
```

A continuación, sigue las indicaciones para elegir en qué dispositivo instalar Swipt y con qué equipo firmarlo.

Swipt completa casi toda la configuración de forma automática, pero aún tienes que iniciar la VPN de bucle invertido. Consulta la sección [Configuración inicial](./setup.mdx).

```shell
swipt sideload update # Actualizar Swipt o ampliar su fecha de caducidad
swipt sideload uninstall # Desinstalar Swipt
```
