## 安装 Skills

#### Claude Code

在 Claude Code 中：

```shell
/plugin marketplace add swipt-automation/skills
/plugin install swipt@swipt-skills
```

使用 Claude Code CLI：

```shell
claude plugin marketplace add swipt-automation/skills
claude plugin install swipt@swipt-skills
```

#### Claude

在“设置”>“插件”中：

- 选择“添加”>“添加市场”>“从仓库添加”，然后输入 `https://github.com/swipt-automation/skills`。
- 切换到“发现”，搜索 Swipt，然后选择“添加”。

#### 其他环境

```shell
npx skills add swipt-automation/skills
```

## 使用 CLI 和 MCP

如果使用 `swipt sideload install` 安装了 Swipt，本地 API 已经自动启用，局域网中的 Agent 已经可以使用你的设备。

如需在 Claude 或 ChatGPT 等仅支持 MCP 的 App 中使用，可以在 Swipt 的“开发者”>“API”>“Cloudflare”中选择 Quick Tunnel，无需登录即可发布公开的 MCP 服务器。
