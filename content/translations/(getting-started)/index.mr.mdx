## आढावा

Swipt हे स्वयंचलन प्लॅटफॉर्म आहे.

## आवश्यकता

- साइडलोडिंग
- iOS 27 (प्रथम श्रेणीचा सपोर्ट)
- iOS 17.4–26 (पेअरिंग फाइल तयार करण्यासाठी अतिरिक्त Mac, Windows किंवा Linux डिव्हाइस आवश्यक आहे. माझ्याकडे चाचणीसाठी प्रत्यक्ष डिव्हाइस नाहीत, त्यामुळे सपोर्ट मोठ्या प्रमाणात बाह्य योगदानांवर अवलंबून असेल.)

## Mac वापरून साइडलोड करा

तुम्हाला स्वतंत्र साइडलोडिंग फ्रेमवर्क इंस्टॉल करायचे नसेल, तर आम्ही Swipt CLI मध्ये अंगभूत असलेले `sideload` टूल वापरण्याची शिफारस करतो.

ते Xcode वापरून Swipt साइन आणि इंस्टॉल करते, त्यामुळे ते पुढील गोष्टी करू शकते :

- तुम्हाला पुन्हा साइन इन करायला न सांगता, तुम्ही आधीच साइन इन केलेले Apple अकाउंट वापरणे.
- डिव्हाइसवर पुन्हा पेअर न करता, तुमचा Mac आणि डिव्हाइस यांच्यातील सध्याचे पेअरिंग वापरण्यासाठी Swipt कॉंफिगर करणे.
- विनामूल्य डेव्हलपर प्रमाणपत्रावर विश्वास ठेवणे आणि तुमच्या डिव्हाइसवर सुरुवातीचे इतर कॉंफिगरेशन पूर्ण करणे.

Terminal मध्ये पुढील कमांड चालवा :

```shell
npm install -g @swipt/cli
swipt sideload install
```

त्यानंतर सूचनांचे पालन करून, ज्या डिव्हाइसवर इंस्टॉल करायचे आहे ते डिव्हाइस आणि साइन करण्यासाठी वापरायची टीम निवडा.

Swipt जवळपास सर्व सेटअप आपोआप पूर्ण करते, पण तरीही तुम्हाला लूपबॅक VPN सुरू करावे लागेल. [सेटअप](./setup.mdx) विभाग पहा.

```shell
swipt sideload update # Swipt अपडेट करा किंवा त्याची मुदत वाढवा
swipt sideload uninstall # Swipt अनइंस्टॉल करा
```
