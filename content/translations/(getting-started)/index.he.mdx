## סקירה כללית

Swipt הוא פלטפורמת אוטומציה.

נכון לעכשיו הוא תומך רק במכשירי iPhone ו-iPad עם **iOS 27** ואילך, וניתן להתקין אותו רק בהתקנה צדדית.

## התקנה צדדית באמצעות Mac

אם לא רוצים להתקין כלי נפרד להתקנה צדדית, מומלץ להשתמש בכלי `sideload` המובנה ב-Swipt CLI.

הכלי חותם על Swipt ומתקין אותו באמצעות Xcode, ולכן הוא יכול:

- להשתמש בחשבון Apple שכבר התחברת אליו, בלי לבקש ממך להתחבר שוב.
- להגדיר את Swipt כך שישתמש בקישור הקיים בין ה-Mac למכשיר, בלי לבצע קישור מחדש במכשיר.
- לתת במכשיר אמון באישור המפתחים החינמי ולבצע בו הגדרות ראשוניות נוספות.

ביישום ״המסוף״ יש להריץ:

```shell
npm install -g @swipt/cli
swipt sideload install
```

לאחר מכן יש לפעול לפי ההנחיות ולבחור את המכשיר להתקנה ואת הצוות לחתימה.

Swipt משלים באופן אוטומטי כמעט את כל ההגדרה הראשונית, אבל עדיין יש להפעיל את ה-VPN מסוג לולאה חוזרת. לפרטים, יש לעיין בדף [הגדרה ראשונית](./setup.mdx).

```shell
swipt sideload update # עדכון Swipt או הארכת התוקף שלו
swipt sideload uninstall # הסרת Swipt
```
