## ਤੁਹਾਡੇ ਡਿਵਾਈਸ ਨਾਲ ਜੋੜਾਬੱਧ ਕਰਨਾ

ਡਿਵਾਈਸ ਦੀਆਂ ਡਿਵੈਲਪਰ ਸੇਵਾਵਾਂ ਨਾਲ ਕਨੈਕਟ ਕਰਨ ਲਈ Swipt ਦਾ ਤੁਹਾਡੇ ਡਿਵਾਈਸ ਨਾਲ ਜੋੜਾਬੱਧ ਹੋਣਾ ਲੋੜੀਂਦਾ ਹੈ।

ਜੇਕਰ ਤੁਸੀਂ Swipt CLI ਨਾਲ Swipt ਨੂੰ ਸਾਈਡਲੋਡ ਕੀਤਾ ਹੈ, ਤਾਂ ਜੋੜਾਬੱਧ ਕਰਨਾ ਸਵੈਚਲਿਤ ਤੌਰ 'ਤੇ ਸੈੱਟਅੱਪ ਹੋ ਜਾਂਦਾ ਹੈ। ਨਹੀਂ ਤਾਂ, ਜੋੜਾਬੱਧ ਕਰਨ ਲਈ ਨਿਰਦੇਸ਼ਾਂ ਦੀ ਪਾਲਣਾ ਕਰੋ:

ਜੇਕਰ ਤੁਸੀਂ iOS/iPadOS 27 ਵਰਤ ਰਹੇ ਹੋ, ਤਾਂ ਤੁਸੀਂ ਐਪ ਵਿੱਚ ਦਿੱਤੇ ਨਿਰਦੇਸ਼ਾਂ ਦੀ ਪਾਲਣਾ ਕਰਕੇ ਡਿਵਾਈਸ 'ਤੇ ਹੀ ਜੋੜਾਬੱਧ ਕਰ ਸਕਦੇ ਹੋ:

ਜੇਕਰ ਡਿਵਾਈਸ 'ਤੇ ਜੋੜਾਬੱਧ ਕਰਨਾ ਅਸਫਲ ਹੋ ਜਾਂਦਾ ਹੈ, ਤਾਂ ਕਿਰਪਾ ਕਰਕੇ ਇੱਕ ਇਸ਼ੂ ਖੋਲ੍ਹੋ।

ਜੇਕਰ ਤੁਸੀਂ iOS ਦਾ ਪਹਿਲਾਂ ਵਾਲਾ ਵਰਜਨ ਵਰਤ ਰਹੇ ਹੋ ਅਤੇ ਤੁਹਾਡੇ ਕੋਲ Mac ਹੈ, ਤਾਂ ਤੁਸੀਂ ਮੈਨੁਅਲ ਤਰੀਕੇ ਨਾਲ ਸਾਈਡਲੋਡ ਕਰਨ ਤੋਂ ਬਾਅਦ ਜੋੜਾਬੱਧ ਕਰਨਾ ਸੈੱਟਅੱਪ ਕਰਨ ਲਈ ਅਜੇ ਵੀ `swipt sideload setup` ਵਰਤ ਸਕਦੇ ਹੋ। ਨਹੀਂ ਤਾਂ, ਤੁਹਾਨੂੰ ਹੋਰ ਸਾਫ਼ਟਵੇਅਰ ਨਾਲ ਜੋੜਾਬੱਧ ਕਰਨਾ ਪਵੇਗਾ।

ਤੁਸੀਂ ਲਗਭਗ ਕਿਸੇ ਵੀ ਹੋਰ ਸਾਫ਼ਟਵੇਅਰ ਦੁਆਰਾ ਬਣਾਈਆਂ ਜੋੜਾਬੱਧ ਕਰਨ ਦੀਆਂ ਫ਼ਾਈਲਾਂ ਇੰਪੋਰਟ ਕਰ ਸਕਦੇ ਹੋ, ਜਿਵੇਂ ਕਿ:

- [Jitterbug](https://github.com/osy/Jitterbug): `.mobiledevicepairing`
- [idevice](https://github.com/jkcoxson/idevice): `ios_pairing_file.plist`
- [go-ios](https://github.com/danielpaulus/go-ios): `selfIdentity.plist`

ਜੋੜਾਬੱਧ ਕਰਨ ਦੀ ਫ਼ਾਈਲ ਪ੍ਰਾਪਤ ਕਰਨ ਦਾ ਸਭ ਤੋਂ ਆਮ ਤਰੀਕਾ ਇਹ ਹੈ:

1. [iloader](https://iloader.app) ਡਾਊਨਲੋਡ ਅਤੇ ਇੰਸਟਾਲ ਕਰੋ। Windows 'ਤੇ, ਪਹਿਲਾਂ [iTunes](https://www.apple.com/itunes/download/win64) ਇੰਸਟਾਲ ਕਰੋ। Linux 'ਤੇ, ਜੇਕਰ `usbmuxd` ਪਹਿਲਾਂ ਤੋਂ ਇੰਸਟਾਲ ਨਹੀਂ ਹੈ, ਤਾਂ ਇਸਨੂੰ ਇੰਸਟਾਲ ਕਰੋ।
2. USB ਕੇਬਲ ਰਾਹੀਂ ਆਪਣੇ iPhone ਜਾਂ iPad ਨੂੰ ਆਪਣੇ ਕੰਪਿਊਟਰ ਨਾਲ ਕਨੈਕਟ ਕਰੋ। ਜੇਕਰ ਤੁਹਾਨੂੰ ਪੁੱਛਿਆ ਜਾਂਦਾ ਹੈ, ਤਾਂ ਕੰਪਿਊਟਰ 'ਤੇ ਭਰੋਸਾ ਕਰੋ ਅਤੇ ਆਪਣਾ ਪਾਸਕੋਡ ਦਾਖ਼ਲ ਕਰੋ।
3. iloader ਖੋਲ੍ਹੋ ਅਤੇ ਆਪਣਾ iPhone ਜਾਂ iPad ਚੁਣੋ।
4. “Manage Pairing File” ਚੁਣੋ।
5. “Export (Not Recommended)” ਚੁਣੋ, ਫਿਰ “Confirm” ਚੁਣੋ ਅਤੇ ਜੋੜਾਬੱਧ ਕਰਨ ਦੀ ਫ਼ਾਈਲ ਰੱਖਿਅਤ ਕਰੋ।
6. ਜੋੜਾਬੱਧ ਕਰਨ ਦੀ ਫ਼ਾਈਲ ਨੂੰ ਆਪਣੇ iPhone ਜਾਂ iPad 'ਤੇ ਟ੍ਰਾਂਸਫ਼ਰ ਕਰੋ, ਉਦਾਹਰਨ ਲਈ AirDrop ਜਾਂ iCloud Drive ਨਾਲ।

ਜੇਕਰ ਤੁਸੀਂ ਪਹਿਲਾਂ SideStore ਇੰਸਟਾਲ ਕੀਤਾ ਹੈ, ਤਾਂ ਬਹੁਤ ਸੰਭਾਵਨਾ ਹੈ ਕਿ ਤੁਹਾਡੇ ਕੋਲ ਪਹਿਲਾਂ ਹੀ ਜੋੜਾਬੱਧ ਕਰਨ ਦੀ ਫ਼ਾਈਲ ਹੈ!

## ਲੂਪਬੈਕ VPN

ਡਿਵੈਲਪਰ ਸੇਵਾਵਾਂ ਨਾਲ ਕਨੈਕਟ ਕਰਨ ਲਈ Swipt ਨੂੰ ਲੂਪਬੈਕ VPN ਦੀ ਲੋੜ ਹੈ। ਹੇਠਾਂ ਦਿੱਤੇ ਸਾਫ਼ਟਵੇਅਰ ਸਮਰਥਿਤ ਹਨ:

#### LocalDevVPN

[App Store](https://apps.apple.com/app/id6755608044) ਤੋਂ ਇੰਸਟਾਲ ਕਰੋ ਅਤੇ VPN ਚਾਲੂ ਕਰੋ।

#### sing-box

[App Store](https://apps.apple.com/app/id6785326793) ਤੋਂ ਇੰਸਟਾਲ ਕਰੋ, ਸਹੀ ਕੌਂਫਿਗਰੇਸ਼ਨ ਲਿਖੋ ਅਤੇ VPN ਚਾਲੂ ਕਰੋ।

ਤੁਹਾਨੂੰ `tun.loopback_address` ਅਤੇ `tun.route_address` ਨੂੰ ਕੌਂਫਿਗਰ ਕਰਨਾ ਪਵੇਗਾ।

ਉਦਾਹਰਨ ਕੌਂਫਿਗਰੇਸ਼ਨ:

```json
{
  "inbounds": [
    {
      "type": "tun",
      "address": "172.19.0.1/30",
      "auto_route": true,
      "loopback_address": "10.7.0.1",
      "route_address": "10.7.0.1/32"
    }
  ],
  "route": {
    "auto_detect_interface": true
  }
}
```

ਇਸਨੂੰ ਰਾਊਟਰ ਵਰਗੇ ਕਿਸੇ ਗੇਟਵੇ 'ਤੇ ਚਲਾਉਣ ਨਾਲ ਇਹ ਪੂਰੇ ਸਥਾਨਕ ਨੈੱਟਵਰਕ ਲਈ ਕੰਮ ਕਰਦਾ ਹੈ।

#### Clash

[App Store](https://apps.apple.com/app/id6794257189) ਤੋਂ ਇੰਸਟਾਲ ਕਰੋ, ਸਹੀ ਕੌਂਫਿਗਰੇਸ਼ਨ ਲਿਖੋ ਅਤੇ VPN ਚਾਲੂ ਕਰੋ।

ਤੁਹਾਨੂੰ `tun.loopback-address` ਨੂੰ ਕੌਂਫਿਗਰ ਕਰਨਾ ਪਵੇਗਾ:

```yaml
tun:
  loopback-address:
    - 10.7.0.1
```

#### ਬੰਦ ਸਰੋਤ ਕੋਡ ਵਾਲਾ ਸਾਫ਼ਟਵੇਅਰ

ਜੇਕਰ ਤੁਸੀਂ ਸਬਸਕ੍ਰਿਪਸ਼ਨ ਨਾਲ Surge ਵਰਤਦੇ ਹੋ, ਤਾਂ ਤੁਹਾਨੂੰ `General.tun-included-routes` ਅਤੇ `IP Rewrite` ਨੂੰ ਕੌਂਫਿਗਰ ਕਰਨਾ ਪਵੇਗਾ:

```ini
[General]
tun-included-routes = %INSERT% 10.7.0.1/32

[IP Rewrite]
10.7.0.1 = reflect
```

Swipt ਲਈ `ipv6-vif = disabled` ਲੋੜੀਂਦਾ ਨਹੀਂ ਹੈ।

Surge ਵਰਗੀਆਂ ਜਿਨ੍ਹਾਂ ਹੋਰ ਐਪਾਂ ਦੇ ਜਨਤਕ ਦਸਤਾਵੇਜ਼ ਨਹੀਂ ਹਨ, ਉਨ੍ਹਾਂ ਵਿੱਚ ਇਸਨੂੰ ਕਿਵੇਂ ਸੈੱਟਅੱਪ ਕਰਨਾ ਹੈ, ਇਹ ਸੰਬੰਧਿਤ ਡਿਵੈਲਪਰਾਂ ਤੋਂ ਪੁੱਛੋ।

## ਸਵੈਚਲਿਤ ਅਣਲਾਕ

ਆਪਣਾ ਪਾਸਕੋਡ ਰੱਖਿਅਤ ਕਰੋ, ਤਾਂ ਜੋ ਡਿਵਾਈਸ ਲਾਕ ਹੋਣ 'ਤੇ Swipt ਇਸਨੂੰ ਸਵੈਚਲਿਤ ਤੌਰ 'ਤੇ ਅਣਲਾਕ ਕਰ ਸਕੇ।

ਖ਼ਾਸ ਤੌਰ 'ਤੇ, Swipt CLI ਤੁਹਾਡੇ ਡਿਵਾਈਸ ਨੂੰ ਅਣਲਾਕ ਕਰਕੇ Swipt API/MCP ਸ਼ੁਰੂ ਕਰ ਸਕਦਾ ਹੈ, ਅਤੇ Swipt CLI, MCP ਅਤੇ ਇੰਸਟਾਲ ਕੀਤੇ Swiplet ਤੁਹਾਡੇ ਡਿਵਾਈਸ ਨੂੰ ਅਣਲਾਕ ਕਰਕੇ ਇਸਨੂੰ ਚਲਾ ਸਕਦੇ ਹਨ।
