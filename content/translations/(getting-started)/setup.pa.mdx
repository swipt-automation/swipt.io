## ਤੁਹਾਡੇ ਡਿਵਾਈਸ ਨਾਲ ਜੋੜਾਬੱਧ ਕਰਨਾ

ਡਿਵਾਈਸ ਦੀਆਂ ਡਿਵੈਲਪਰ ਸੇਵਾਵਾਂ ਨਾਲ ਕਨੈਕਟ ਕਰਨ ਲਈ Swipt ਦਾ ਤੁਹਾਡੇ ਡਿਵਾਈਸ ਨਾਲ ਜੋੜਾਬੱਧ ਹੋਣਾ ਲੋੜੀਂਦਾ ਹੈ।

ਜੇਕਰ ਤੁਸੀਂ Swipt CLI ਨਾਲ Swipt ਨੂੰ ਸਾਈਡਲੋਡ ਕੀਤਾ ਹੈ, ਤਾਂ ਜੋੜਾਬੱਧ ਕਰਨਾ ਸਵੈਚਲਿਤ ਤੌਰ 'ਤੇ ਸੈੱਟਅੱਪ ਹੋ ਜਾਂਦਾ ਹੈ। ਨਹੀਂ ਤਾਂ, ਜੋੜਾਬੱਧ ਕਰਨ ਲਈ ਐਪ ਵਿੱਚ ਦਿੱਤੇ ਨਿਰਦੇਸ਼ਾਂ ਦੀ ਪਾਲਣਾ ਕਰੋ:

ਜੇਕਰ ਜੋੜਾਬੱਧ ਕਰਨਾ ਪੂਰਾ ਨਹੀਂ ਹੋ ਸਕਦਾ, ਤਾਂ ਕਿਰਪਾ ਕਰਕੇ ਸਾਨੂੰ ਸਮੱਸਿਆ ਦੀ ਰਿਪੋਰਟ ਕਰੋ। ਵਿਕਲਪਕ ਤੌਰ 'ਤੇ, ਤੁਸੀਂ ਹੋਰ ਸਾਫ਼ਟਵੇਅਰ ਤੋਂ ਜੋੜਾਬੱਧ ਕਰਨ ਦੀ ਫ਼ਾਈਲ ਇੰਪੋਰਟ ਕਰ ਸਕਦੇ ਹੋ, ਜਿਵੇਂ ਕਿ:

- [idevice](https://github.com/jkcoxson/idevice): `ios_pairing_file.plist`
- [go-ios](https://github.com/danielpaulus/go-ios): `selfIdentity.plist`

## ਲੂਪਬੈਕ VPN

ਡਿਵੈਲਪਰ ਸੇਵਾਵਾਂ ਨਾਲ ਕਨੈਕਟ ਕਰਨ ਲਈ Swipt ਨੂੰ ਲੂਪਬੈਕ VPN ਦੀ ਲੋੜ ਹੈ। ਹੇਠਾਂ ਦਿੱਤੇ ਸਾਫ਼ਟਵੇਅਰ ਸਮਰਥਿਤ ਹਨ:

#### LocalDevVPN

[App Store](https://apps.apple.com/app/id6755608044) ਤੋਂ ਇੰਸਟਾਲ ਕਰੋ ਅਤੇ VPN ਚਾਲੂ ਕਰੋ।

#### sing-box

[App Store](https://apps.apple.com/app/id6785326793) ਤੋਂ ਇੰਸਟਾਲ ਕਰੋ, ਸਹੀ ਕੌਂਫਿਗਰੇਸ਼ਨ ਲਿਖੋ ਅਤੇ VPN ਚਾਲੂ ਕਰੋ।

ਤੁਹਾਨੂੰ `tun.loopback_address` ਅਤੇ `tun.route_address` ਨੂੰ ਕੌਂਫਿਗਰ ਕਰਨਾ ਪਵੇਗਾ।

ਉਦਾਹਰਨ ਕੌਂਫਿਗਰੇਸ਼ਨ:

```json
{
  "inbounds": [
    {
      "type": "tun",
      "address": "172.19.0.1/30",
      "auto_route": true,
      "loopback_address": "10.7.0.1",
      "route_address": "10.7.0.1/32"
    }
  ],
  "route": {
    "auto_detect_interface": true
  }
}
```

ਇਸਨੂੰ ਰਾਊਟਰ ਵਰਗੇ ਕਿਸੇ ਗੇਟਵੇ 'ਤੇ ਚਲਾਉਣ ਨਾਲ ਇਹ ਪੂਰੇ ਸਥਾਨਕ ਨੈੱਟਵਰਕ ਲਈ ਕੰਮ ਕਰਦਾ ਹੈ।

#### Clash

[App Store](https://apps.apple.com/app/id6794257189) ਤੋਂ ਇੰਸਟਾਲ ਕਰੋ, ਸਹੀ ਕੌਂਫਿਗਰੇਸ਼ਨ ਲਿਖੋ ਅਤੇ VPN ਚਾਲੂ ਕਰੋ।

ਤੁਹਾਨੂੰ `tun.loopback-address` ਨੂੰ ਕੌਂਫਿਗਰ ਕਰਨਾ ਪਵੇਗਾ:

```yaml
tun:
  loopback-address:
    - 10.7.0.1
```

#### ਬੰਦ ਸਰੋਤ ਕੋਡ ਵਾਲਾ ਸਾਫ਼ਟਵੇਅਰ

ਜੇਕਰ ਤੁਸੀਂ ਸਬਸਕ੍ਰਿਪਸ਼ਨ ਨਾਲ Surge ਵਰਤਦੇ ਹੋ, ਤਾਂ ਤੁਹਾਨੂੰ `General.tun-included-routes` ਅਤੇ `IP Rewrite` ਨੂੰ ਕੌਂਫਿਗਰ ਕਰਨਾ ਪਵੇਗਾ:

```ini
[General]
tun-included-routes = %INSERT% 10.7.0.1/32

[IP Rewrite]
10.7.0.1 = reflect
```

Swipt ਲਈ `ipv6-vif = disabled` ਲੋੜੀਂਦਾ ਨਹੀਂ ਹੈ।

Surge ਵਰਗੀਆਂ ਜਿਨ੍ਹਾਂ ਹੋਰ ਐਪਾਂ ਦੇ ਜਨਤਕ ਦਸਤਾਵੇਜ਼ ਨਹੀਂ ਹਨ, ਉਨ੍ਹਾਂ ਵਿੱਚ ਇਸਨੂੰ ਕਿਵੇਂ ਸੈੱਟਅੱਪ ਕਰਨਾ ਹੈ, ਇਹ ਸੰਬੰਧਿਤ ਡਿਵੈਲਪਰਾਂ ਤੋਂ ਪੁੱਛੋ।

## ਸਵੈਚਲਿਤ ਅਣਲਾਕ

ਆਪਣਾ ਪਾਸਕੋਡ ਰੱਖਿਅਤ ਕਰੋ, ਤਾਂ ਜੋ ਡਿਵਾਈਸ ਲਾਕ ਹੋਣ 'ਤੇ Swipt ਇਸਨੂੰ ਸਵੈਚਲਿਤ ਤੌਰ 'ਤੇ ਅਣਲਾਕ ਕਰ ਸਕੇ।

ਖ਼ਾਸ ਤੌਰ 'ਤੇ, Swipt CLI ਤੁਹਾਡੇ ਡਿਵਾਈਸ ਨੂੰ ਅਣਲਾਕ ਕਰਕੇ Swipt API/MCP ਸ਼ੁਰੂ ਕਰ ਸਕਦਾ ਹੈ, ਅਤੇ Swipt CLI, MCP ਅਤੇ ਇੰਸਟਾਲ ਕੀਤੇ Swiplet ਤੁਹਾਡੇ ਡਿਵਾਈਸ ਨੂੰ ਅਣਲਾਕ ਕਰਕੇ ਇਸਨੂੰ ਚਲਾ ਸਕਦੇ ਹਨ।
