## Berpasangan dengan Peranti Anda

Swipt perlu berpasangan dengan peranti anda untuk menyambung ke perkhidmatan pembangunnya.

Jika anda telah memuat sisi Swipt dengan Swipt CLI, perpasangan disediakan secara automatik. Jika tidak, ikuti arahan dalam app untuk berpasangan:

Jika perpasangan tidak dapat diselesaikan, sila laporkan isu ini kepada kami. Sebagai alternatif, anda boleh mengimport fail pasangan daripada perisian lain, termasuk:

- [Jitterbug](https://github.com/osy/Jitterbug): `.mobiledevicepairing`
- [idevice](https://github.com/jkcoxson/idevice): `ios_pairing_file.plist`
- [go-ios](https://github.com/danielpaulus/go-ios): `selfIdentity.plist`

## VPN Gelung Balik

Swipt memerlukan VPN gelung balik untuk menyambung ke perkhidmatan pembangun. Perisian berikut disokong:

#### LocalDevVPN

Pasang daripada [App Store](https://apps.apple.com/app/id6755608044) dan hidupkan VPN.

#### sing-box

Pasang daripada [App Store](https://apps.apple.com/app/id6785326793), tulis konfigurasi yang betul dan hidupkan VPN.

Anda perlu mengkonfigurasikan `tun.loopback_address` dan `tun.route_address`.

Contoh konfigurasi:

```json
{
  "inbounds": [
    {
      "type": "tun",
      "address": "172.19.0.1/30",
      "auto_route": true,
      "loopback_address": "10.7.0.1",
      "route_address": "10.7.0.1/32"
    }
  ],
  "route": {
    "auto_detect_interface": true
  }
}
```

Jika anda menggunakan sing-box pada get laluan, seperti penghala, ia akan berfungsi untuk seluruh rangkaian setempat.

#### Clash

Pasang daripada [App Store](https://apps.apple.com/app/id6794257189), tulis konfigurasi yang betul dan hidupkan VPN.

Anda perlu mengkonfigurasikan `tun.loopback-address`:

```yaml
tun:
  loopback-address:
    - 10.7.0.1
```

#### Perisian Sumber Tertutup

Jika anda melanggan dan menggunakan Surge, anda perlu mengkonfigurasikan `General.tun-included-routes` dan `IP Rewrite`:

```ini
[General]
tun-included-routes = %INSERT% 10.7.0.1/32

[IP Rewrite]
10.7.0.1 = reflect
```

`ipv6-vif = disabled` tidak diperlukan untuk Swipt.

Bagi app lain yang serupa dengan Surge tetapi tiada dokumentasi awam, tanya pembangunnya cara untuk mengkonfigurasikannya.

## Buka Kunci Automatik

Simpan kod laluan anda supaya Swipt boleh membuka kunci peranti anda secara automatik apabila ia dikunci.

Secara khususnya, Swipt CLI boleh membuka kunci peranti anda untuk memulakan Swipt API/MCP, dan Swipt CLI, MCP serta Swiplet yang dipasang boleh membuka kunci peranti anda untuk mengendalikannya.
