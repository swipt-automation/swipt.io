## 與裝置配對

Swipt 需要與你的裝置配對，才能連線至裝置的開發者服務。

如果你使用 Swipt CLI 側載 Swipt，配對會自動設定完成；否則，請依照指示完成配對：

如果你使用的是 iOS/iPadOS 27，可以依照 App 內的指示直接在裝置上完成配對：

如果在裝置上配對失敗，請開啟 Issue。

如果你使用的是較舊版本的 iOS 且擁有 Mac，仍可在手動側載後使用 `swipt sideload setup` 設定配對；否則，你需要透過其他軟體進行配對。

你可以輸入幾乎任何其他軟體建立的配對檔案，包括：

- [Jitterbug](https://github.com/osy/Jitterbug)：`.mobiledevicepairing`
- [idevice](https://github.com/jkcoxson/idevice)：`ios_pairing_file.plist`
- [go-ios](https://github.com/danielpaulus/go-ios)：`selfIdentity.plist`

以下是取得配對檔案最常見的方式：

1. 下載並安裝 [iloader](https://iloader.app)。在 Windows 上，請先安裝 [iTunes](https://www.apple.com/itunes/download/win64)；在 Linux 上，如果系統未預先安裝 `usbmuxd`，請安裝它。
2. 使用 USB 連接線將 iPhone 或 iPad 連接至電腦。如果出現提示，請信任這部電腦並輸入密碼。
3. 開啟 iloader 並選擇你的 iPhone 或 iPad。
4. 選擇「Manage Pairing File」。
5. 選擇「Export (Not Recommended)」，然後選擇「Confirm」並儲存配對檔案。
6. 將配對檔案傳送到 iPhone 或 iPad，例如使用 AirDrop 或 iCloud Drive。

如果你之前安裝過 SideStore，你很可能已經有配對檔案了！

## 回送 VPN

Swipt 需要回送 VPN 才能連線至開發者服務。支援以下軟體：

#### LocalDevVPN

從 [App Store](https://apps.apple.com/app/id6755608044) 安裝並開啟 VPN。

#### sing-box

從 [App Store](https://apps.apple.com/app/id6785326793) 安裝，撰寫正確的設定，然後開啟 VPN。

你需要設定 `tun.loopback_address` 和 `tun.route_address`。

設定範例：

```json
{
  "inbounds": [
    {
      "type": "tun",
      "address": "172.19.0.1/30",
      "auto_route": true,
      "loopback_address": "10.7.0.1",
      "route_address": "10.7.0.1/32"
    }
  ],
  "route": {
    "auto_detect_interface": true
  }
}
```

將其部署在路由器等閘道上，即可在整個區域網路中生效。

#### Clash

從 [App Store](https://apps.apple.com/app/id6794257189) 安裝，撰寫正確的設定，然後開啟 VPN。

你需要設定 `tun.loopback-address`：

```yaml
tun:
  loopback-address:
    - 10.7.0.1
```

#### 閉源軟體

如果你訂閱並使用 Surge，需要設定 `General.tun-included-routes` 和 `IP Rewrite`：

```ini
[General]
tun-included-routes = %INSERT% 10.7.0.1/32

[IP Rewrite]
10.7.0.1 = reflect
```

Swipt 不需要 `ipv6-vif = disabled`。

至於其他沒有公開說明文件、類似 Surge 的 App，請向其開發者詢問設定方式。

## 自動解鎖

儲存你的密碼，讓 Swipt 能在裝置鎖定時自動解鎖。

具體來說，Swipt CLI 可以解鎖裝置以啟動 Swipt API/MCP；Swipt CLI、MCP 和已安裝的 Swiplet 可以解鎖裝置以進行操作。
