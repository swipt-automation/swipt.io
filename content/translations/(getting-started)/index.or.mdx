## ସଂକ୍ଷିପ୍ତ ବିବରଣୀ

Swipt ଏକ ସ୍ୱୟଂଚାଳନ ପ୍ଲାଟ୍‌ଫର୍ମ୍।

## ଆବଶ୍ୟକତା

- ସାଇଡ୍‌ଲୋଡିଂ
- iOS 27 (ପ୍ରଥମ-ସ୍ତରୀୟ ସମର୍ଥନ)
- iOS 17.4–26 (ଏକ ପେୟାରିଂ ଫାଇଲ୍ ତିଆରି କରିବା ପାଇଁ ଏକ ଅତିରିକ୍ତ Mac, Windows କିମ୍ବା Linux ଡିଭାଇସ୍ ଆବଶ୍ୟକ। ପରୀକ୍ଷା କରିବା ପାଇଁ ମୋ ପାଖରେ ଭୌତିକ ଡିଭାଇସ୍ ନାହିଁ, ତେଣୁ ସମର୍ଥନ ମୁଖ୍ୟତଃ ବାହ୍ୟ ଅବଦାନ ଉପରେ ନିର୍ଭର କରିବ।)

## Mac ସାହାଯ୍ୟରେ ସାଇଡ୍‌ଲୋଡ୍ କରନ୍ତୁ

ଯଦି ଆପଣ ଅଲଗା ସାଇଡ୍‌ଲୋଡିଂ ଫ୍ରେମ୍‌ୱର୍କ୍ ଇନ୍‌ଷ୍ଟଲ୍ କରିବାକୁ ଚାହୁଁନାହାନ୍ତି, ତେବେ ଆମେ Swipt CLI ସହ ଆସୁଥିବା `sideload` ଟୂଲ୍ ବ୍ୟବହାର କରିବାକୁ ସୁପାରିଶ କରୁଛୁ।

ଏହା Xcode ସାହାଯ୍ୟରେ Swipt କୁ ସାଇନ୍ ଓ ଇନ୍‌ଷ୍ଟଲ୍ କରେ, ତେଣୁ ଏହା ନିମ୍ନଲିଖିତ କାମ କରିପାରେ:

- ଆପଣ ପୂର୍ବରୁ ସାଇନ୍ ଇନ୍ କରିଥିବା Apple ଆକାଉଣ୍ଟ୍ ବ୍ୟବହାର କରେ, ପୁଣି ସାଇନ୍ ଇନ୍ କରିବାକୁ କହେ ନାହିଁ।
- ଡିଭାଇସ୍ ସହ ଆପଣଙ୍କ Mac ର ପୂର୍ବରୁ ଥିବା ପେୟାରିଂ ବ୍ୟବହାର କରିବାକୁ Swipt କୁ କନ୍‌ଫିଗର୍ କରେ, ଡିଭାଇସ୍‌ରେ ପୁଣି ପେୟାର୍ କରିବା ଦରକାର ପଡ଼େ ନାହିଁ।
- ଆପଣଙ୍କ ଡିଭାଇସ୍‌ରେ ମାଗଣା ଡେଭଲପର୍ ସାର୍ଟିଫିକେଟ୍ ଉପରେ ବିଶ୍ବାସ କରେ ଏବଂ ପ୍ରଥମ ଥର ପାଇଁ ଆବଶ୍ୟକ ଅନ୍ୟ କନ୍‌ଫିଗରେଶନ୍ ମଧ୍ୟ କରେ।

Terminal ରେ ନିମ୍ନଲିଖିତ କମାଣ୍ଡ୍ ଚଲାନ୍ତୁ:

```shell
npm install -g @swipt/cli
swipt sideload install
```

ତା’ପରେ ପ୍ରମ୍ପ୍ଟ୍ ଅନୁସରଣ କରି ଇନ୍‌ଷ୍ଟଲ୍ କରିବା ପାଇଁ ଡିଭାଇସ୍ ଏବଂ ସାଇନ୍ କରିବା ପାଇଁ ଟୀମ୍ ବାଛନ୍ତୁ।

Swipt ପ୍ରାୟ ସମସ୍ତ ସେଟ୍‌ଅପ୍ ସ୍ୱୟଂଚାଳିତ ଭାବରେ ସମାପ୍ତ କରେ, କିନ୍ତୁ ଆପଣଙ୍କୁ ତଥାପି ଲୁପ୍‌ବ୍ୟାକ୍ VPN ଚାଲୁ କରିବାକୁ ହେବ। [ସେଟ୍‌ଅପ୍](./setup.mdx) ବିଭାଗ ଦେଖନ୍ତୁ।

```shell
swipt sideload update # Swipt ଅପଡେଟ୍ କରନ୍ତୁ କିମ୍ବା ଏହାର ସମୟସୀମା ବଢ଼ାନ୍ତୁ
swipt sideload uninstall # Swipt ଅନ୍‌ଇନ୍‌ଷ୍ଟଲ୍ କରନ୍ତୁ
```
