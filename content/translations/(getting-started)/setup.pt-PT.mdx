## Emparelhar com o dispositivo

O Swipt tem de emparelhar com o seu dispositivo para se ligar aos respetivos serviços de programador.

Se tiver feito o sideload do Swipt com a Swipt CLI, o emparelhamento é configurado automaticamente. Caso contrário, siga as instruções para emparelhar:

Se estiver a utilizar o iOS/iPadOS 27, pode emparelhar no próprio dispositivo seguindo as instruções na aplicação:

Se o emparelhamento no dispositivo falhar, abra uma issue.

Se estiver a utilizar uma versão anterior do iOS e tiver um Mac, pode continuar a utilizar `swipt sideload setup` para configurar o emparelhamento depois de fazer sideload manualmente. Caso contrário, tem de emparelhar com outro software.

Pode importar ficheiros de emparelhamento criados por praticamente qualquer outro software, incluindo:

- [Jitterbug](https://github.com/osy/Jitterbug): `.mobiledevicepairing`
- [idevice](https://github.com/jkcoxson/idevice): `ios_pairing_file.plist`
- [go-ios](https://github.com/danielpaulus/go-ios): `selfIdentity.plist`

Eis a forma mais comum de obter um ficheiro de emparelhamento:

1. Transfira e instale o [iloader](https://iloader.app). No Windows, instale primeiro o [iTunes](https://www.apple.com/itunes/download/win64). No Linux, instale o `usbmuxd` se não estiver pré-instalado.
2. Ligue o iPhone ou iPad ao computador com um cabo USB. Se lhe for pedido, confie no computador e introduza o código.
3. Abra o iloader e selecione o iPhone ou iPad.
4. Selecione «Manage Pairing File».
5. Selecione «Export (Not Recommended)», depois selecione «Confirm» e guarde o ficheiro de emparelhamento.
6. Transfira o ficheiro de emparelhamento para o iPhone ou iPad, por exemplo, através do AirDrop ou do iCloud Drive.

Se já instalou a SideStore anteriormente, é muito provável que já tenha um ficheiro de emparelhamento!

## VPN de loopback

O Swipt precisa de uma VPN de loopback para se ligar aos serviços de programador. O seguinte software é compatível:

#### LocalDevVPN

Instale a aplicação a partir da [App Store](https://apps.apple.com/app/id6755608044) e ative a VPN.

#### sing-box

Instale a aplicação a partir da [App Store](https://apps.apple.com/app/id6785326793), escreva uma configuração correta e ative a VPN.

Tem de configurar `tun.loopback_address` e `tun.route_address`.

Exemplo de configuração:

```json
{
  "inbounds": [
    {
      "type": "tun",
      "address": "172.19.0.1/30",
      "auto_route": true,
      "loopback_address": "10.7.0.1",
      "route_address": "10.7.0.1/32"
    }
  ],
  "route": {
    "auto_detect_interface": true
  }
}
```

Se implementar o sing-box num gateway, como um router, este funcionará para toda a rede local.

#### Clash

Instale a aplicação a partir da [App Store](https://apps.apple.com/app/id6794257189), escreva uma configuração correta e ative a VPN.

Tem de configurar `tun.loopback-address`:

```yaml
tun:
  loopback-address:
    - 10.7.0.1
```

#### Software de código fechado

Se subscrever e utilizar o Surge, tem de configurar `General.tun-included-routes` e `IP Rewrite`:

```ini
[General]
tun-included-routes = %INSERT% 10.7.0.1/32

[IP Rewrite]
10.7.0.1 = reflect
```

`ipv6-vif = disabled` não é necessário para o Swipt.

Para outras aplicações semelhantes ao Surge sem documentação pública, pergunte aos respetivos programadores como efetuar a configuração.

## Desbloqueio automático

Guarde o código para que o Swipt possa desbloquear automaticamente o seu dispositivo quando este estiver bloqueado.

Especificamente, a Swipt CLI pode desbloquear o seu dispositivo para iniciar a Swipt API/MCP, e a Swipt CLI, o MCP e os Swiplets instalados podem desbloquear o seu dispositivo para o operar.
