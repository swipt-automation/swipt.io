## നിങ്ങളുടെ ഡിവൈസുമായി പെയർ ചെയ്യൂ

ഡിവൈസിലെ ഡെവലപ്പർ സർവീസുകളിലേക്ക് കണക്റ്റ് ചെയ്യാൻ Swipt നിങ്ങളുടെ ഡിവൈസുമായി പെയർ ചെയ്യേണ്ടതുണ്ട്.

Swipt CLI ഉപയോഗിച്ച് നിങ്ങൾ Swipt സൈഡ്ലോഡ് ചെയ്തെങ്കിൽ, പെയറിങ് ഓട്ടോമാറ്റിക്കായി സജ്ജീകരിക്കപ്പെടും. അല്ലെങ്കിൽ, പെയർ ചെയ്യാൻ ആപ്പിലെ നിർദ്ദേശങ്ങൾ പിന്തുടരൂ:

പെയറിങ് പൂർത്തിയാക്കാൻ കഴിയുന്നില്ലെങ്കിൽ, ദയവായി പ്രശ്നം ഞങ്ങളെ അറിയിക്കൂ. പകരമായി, മറ്റ് സോഫ്റ്റ്‌വെയറുകളിൽ നിന്ന് ഒരു പെയറിങ് ഫയൽ ഇംപോർട്ട് ചെയ്യാം, ഉദാഹരണത്തിന്:

- [Jitterbug](https://github.com/osy/Jitterbug): `.mobiledevicepairing`
- [idevice](https://github.com/jkcoxson/idevice): `ios_pairing_file.plist`
- [go-ios](https://github.com/danielpaulus/go-ios): `selfIdentity.plist`

## ലൂപ്പ്ബാക്ക് VPN

ഡെവലപ്പർ സർവീസുകളിലേക്ക് കണക്റ്റ് ചെയ്യാൻ Swipt-ന് ഒരു ലൂപ്പ്ബാക്ക് VPN ആവശ്യമാണ്. ഇനിപ്പറയുന്ന സോഫ്റ്റ്‌വെയറുകൾ പിന്തുണയ്ക്കുന്നു:

#### LocalDevVPN

[App Store](https://apps.apple.com/app/id6755608044)-ൽ നിന്ന് ഇൻസ്റ്റാൾ ചെയ്ത് VPN ഓണാക്കൂ.

#### sing-box

[App Store](https://apps.apple.com/app/id6785326793)-ൽ നിന്ന് ഇൻസ്റ്റാൾ ചെയ്യൂ, ശരിയായ കോൺഫിഗറേഷൻ എഴുതൂ, തുടർന്ന് VPN ഓണാക്കൂ.

`tun.loopback_address`, `tun.route_address` എന്നിവ കോൺഫിഗർ ചെയ്യേണ്ടതുണ്ട്.

ഉദാഹരണ കോൺഫിഗറേഷൻ:

```json
{
  "inbounds": [
    {
      "type": "tun",
      "address": "172.19.0.1/30",
      "auto_route": true,
      "loopback_address": "10.7.0.1",
      "route_address": "10.7.0.1/32"
    }
  ],
  "route": {
    "auto_detect_interface": true
  }
}
```

റൂട്ടർ പോലുള്ള ഒരു ഗേറ്റ്‌വേയിൽ ഇത് ഡിപ്ലോയ് ചെയ്താൽ, മുഴുവൻ ലോക്കൽ നെറ്റ്‌വർക്കിനും ഇത് പ്രവർത്തിക്കും.

#### Clash

[App Store](https://apps.apple.com/app/id6794257189)-ൽ നിന്ന് ഇൻസ്റ്റാൾ ചെയ്യൂ, ശരിയായ കോൺഫിഗറേഷൻ എഴുതൂ, തുടർന്ന് VPN ഓണാക്കൂ.

`tun.loopback-address` കോൺഫിഗർ ചെയ്യേണ്ടതുണ്ട്:

```yaml
tun:
  loopback-address:
    - 10.7.0.1
```

#### ക്ലോസ്ഡ് സോഴ്സ് സോഫ്റ്റ്‌വെയർ

സബ്‌സ്ക്രിപ്ഷനോടെ നിങ്ങൾ Surge ഉപയോഗിക്കുന്നുണ്ടെങ്കിൽ, `General.tun-included-routes`, `IP Rewrite` എന്നിവ കോൺഫിഗർ ചെയ്യേണ്ടതുണ്ട്:

```ini
[General]
tun-included-routes = %INSERT% 10.7.0.1/32

[IP Rewrite]
10.7.0.1 = reflect
```

Swipt-ന് `ipv6-vif = disabled` ആവശ്യമില്ല.

പൊതുവായ ഡോക്യുമെന്റേഷൻ ഇല്ലാത്ത, Surge പോലുള്ള മറ്റ് ആപ്പുകൾ കോൺഫിഗർ ചെയ്യുന്നത് എങ്ങനെയെന്ന് അവയുടെ ഡെവലപ്പർമാരോട് ചോദിക്കൂ.

## ഓട്ടോമാറ്റിക് അൺലോക്ക്

നിങ്ങളുടെ പാസ്‌കോഡ് സേവ് ചെയ്യൂ, അങ്ങനെ ഡിവൈസ് ലോക്ക് ചെയ്തിരിക്കുമ്പോൾ Swipt-ന് അത് ഓട്ടോമാറ്റിക്കായി അൺലോക്ക് ചെയ്യാനാകും.

കൃത്യമായി പറഞ്ഞാൽ, Swipt API/MCP ആരംഭിക്കാൻ Swipt CLI-ക്ക് നിങ്ങളുടെ ഡിവൈസ് അൺലോക്ക് ചെയ്യാനാകും, ഡിവൈസ് പ്രവർത്തിപ്പിക്കാൻ Swipt CLI, MCP, ഇൻസ്റ്റാൾ ചെയ്ത Swiplet എന്നിവയ്ക്ക് നിങ്ങളുടെ ഡിവൈസ് അൺലോക്ക് ചെയ്യാനാകും.
