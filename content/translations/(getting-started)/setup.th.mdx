## จับคู่กับอุปกรณ์ของคุณ

Swipt ต้องจับคู่กับอุปกรณ์ของคุณเพื่อเชื่อมต่อกับบริการนักพัฒนาของอุปกรณ์

หากคุณไซด์โหลด Swipt ด้วย Swipt CLI ระบบจะตั้งค่าการจับคู่ให้โดยอัตโนมัติ ไม่เช่นนั้นให้ทำตามคำแนะนำเพื่อจับคู่:

หากคุณใช้ iOS/iPadOS 27 คุณสามารถจับคู่บนอุปกรณ์ได้โดยทำตามคำแนะนำในแอป:

หากจับคู่บนอุปกรณ์ไม่สำเร็จ โปรดเปิด Issue

หากคุณใช้ iOS เวอร์ชันก่อนหน้าและมี Mac คุณยังสามารถใช้ `swipt sideload setup` เพื่อตั้งค่าการจับคู่หลังจากไซด์โหลดด้วยตนเองได้ ไม่เช่นนั้นคุณต้องจับคู่ด้วยซอฟต์แวร์อื่น

คุณสามารถนำเข้าไฟล์จับคู่ที่สร้างจากซอฟต์แวร์อื่นได้แทบทุกตัว เช่น:

- [Jitterbug](https://github.com/osy/Jitterbug): `.mobiledevicepairing`
- [idevice](https://github.com/jkcoxson/idevice): `ios_pairing_file.plist`
- [go-ios](https://github.com/danielpaulus/go-ios): `selfIdentity.plist`

วิธีที่นิยมที่สุดในการรับไฟล์จับคู่มีดังนี้:

1. ดาวน์โหลดและติดตั้ง [iloader](https://iloader.app) บน Windows ให้ติดตั้ง [iTunes](https://www.apple.com/itunes/download/win64) ก่อน บน Linux ให้ติดตั้ง `usbmuxd` หากยังไม่ได้ติดตั้งไว้ล่วงหน้า
2. เชื่อมต่อ iPhone หรือ iPad กับคอมพิวเตอร์ด้วยสาย USB หากมีข้อความแจ้ง ให้เชื่อถือคอมพิวเตอร์และป้อนรหัส
3. เปิด iloader แล้วเลือก iPhone หรือ iPad ของคุณ
4. เลือก “Manage Pairing File”
5. เลือก “Export (Not Recommended)” จากนั้นเลือก “Confirm” แล้วบันทึกไฟล์จับคู่
6. ส่งไฟล์จับคู่ไปยัง iPhone หรือ iPad ของคุณ เช่น ผ่าน AirDrop หรือ iCloud Drive

หากคุณเคยติดตั้ง SideStore มาก่อน คุณน่าจะมีไฟล์จับคู่อยู่แล้ว!

## VPN ลูปแบ็ค

Swipt ต้องใช้ VPN ลูปแบ็คเพื่อเชื่อมต่อกับบริการนักพัฒนา รองรับซอฟต์แวร์ต่อไปนี้:

#### LocalDevVPN

ติดตั้งจาก [App Store](https://apps.apple.com/app/id6755608044) แล้วเปิด VPN

#### sing-box

ติดตั้งจาก [App Store](https://apps.apple.com/app/id6785326793) เขียนการกำหนดค่าที่ถูกต้อง แล้วเปิด VPN

คุณต้องกำหนดค่า `tun.loopback_address` และ `tun.route_address`

ตัวอย่างการกำหนดค่า:

```json
{
  "inbounds": [
    {
      "type": "tun",
      "address": "172.19.0.1/30",
      "auto_route": true,
      "loopback_address": "10.7.0.1",
      "route_address": "10.7.0.1/32"
    }
  ],
  "route": {
    "auto_detect_interface": true
  }
}
```

หากติดตั้ง sing-box บนเกตเวย์ เช่น เราเตอร์ ก็จะใช้งานได้ทั่วทั้งเครือข่ายเฉพาะที่

#### Clash

ติดตั้งจาก [App Store](https://apps.apple.com/app/id6794257189) เขียนการกำหนดค่าที่ถูกต้อง แล้วเปิด VPN

คุณต้องกำหนดค่า `tun.loopback-address`:

```yaml
tun:
  loopback-address:
    - 10.7.0.1
```

#### ซอฟต์แวร์แบบปิดซอร์ส

หากคุณใช้ Shadowrocket ให้เปิด **Include Route 10.7.0.1/32** ในการตั้งค่า แล้วเชื่อมต่อ VPN ใหม่ หากไม่เห็นตัวเลือกนี้ ให้อัปเดต Shadowrocket

หากคุณสมัครสมาชิก Surge และใช้งานอยู่ คุณต้องกำหนดค่า `General.tun-included-routes` และ `IP Rewrite`:

```ini
[General]
tun-included-routes = %INSERT% 10.7.0.1/32

[IP Rewrite]
10.7.0.1 = reflect
```

Swipt ไม่จำเป็นต้องใช้ `ipv6-vif = disabled`

สำหรับแอปอื่นที่คล้าย Surge แต่ไม่มีเอกสารเผยแพร่ต่อสาธารณะ โปรดสอบถามวิธีตั้งค่าจากนักพัฒนาของแอปนั้น

## ปลดล็อคอัตโนมัติ

บันทึกรหัสของคุณเพื่อให้ Swipt สามารถปลดล็อคอุปกรณ์ของคุณโดยอัตโนมัติเมื่ออุปกรณ์ล็อคอยู่

กล่าวคือ Swipt CLI สามารถปลดล็อคอุปกรณ์ของคุณเพื่อเริ่ม Swipt API/MCP และ Swipt CLI และ MCP รวมถึง Swiplet ที่ติดตั้งไว้สามารถปลดล็อคอุปกรณ์ของคุณเพื่อควบคุมอุปกรณ์ได้
