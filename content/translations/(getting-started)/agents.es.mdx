## Instalación de Skills

#### Claude Code

En Claude Code:

```shell
/plugin marketplace add swipt-automation/skills
/plugin install swipt@swipt-skills
```

Con Claude Code CLI:

```shell
claude plugin marketplace add swipt-automation/skills
claude plugin install swipt@swipt-skills
```

#### Claude

En Ajustes > Plugins:

- Selecciona Añadir > Añadir mercado > Añadir desde repositorio y, a continuación, introduce `https://github.com/swipt-automation/skills`.
- Cambia a Descubrir, busca Swipt y selecciona Añadir.

#### Otros entornos

```shell
npx skills add swipt-automation/skills
```

## Uso de la CLI y MCP

Si has instalado Swipt con `swipt sideload install`, la API local ya está activada y los agentes de tu red local pueden usar tu dispositivo.

Para usar Swipt en apps que solo admiten MCP, como Claude o ChatGPT, ve a Desarrollador > API > Cloudflare en Swipt y selecciona Quick Tunnel para publicar un servidor MCP público sin iniciar sesión.
