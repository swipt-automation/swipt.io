## 스킬 설치

#### Claude Code

Claude Code에서:

```shell
/plugin marketplace add swipt-automation/skills
/plugin install swipt@swipt-skills
```

Claude Code CLI를 사용하는 경우:

```shell
claude plugin marketplace add swipt-automation/skills
claude plugin install swipt@swipt-skills
```

#### Claude

‘설정’ > ‘플러그인’에서:

- ‘추가’ > ‘마켓플레이스 추가’ > ‘저장소에서 추가’를 선택한 다음 `https://github.com/swipt-automation/skills`를 입력하십시오.
- ‘탐색’으로 전환하고 Swipt를 검색한 다음 ‘추가’를 선택하십시오.

#### 기타 환경

```shell
npx skills add swipt-automation/skills
```

## CLI 및 MCP 사용

`swipt sideload install`로 Swipt를 설치한 경우 로컬 API가 이미 켜져 있으므로 로컬 네트워크의 에이전트가 기기를 사용할 수 있습니다.

Claude 또는 ChatGPT처럼 MCP만 지원하는 앱에서 Swipt를 사용하려면 Swipt에서 ‘개발자’ > ‘API’ > ‘Cloudflare’로 이동한 다음 Quick Tunnel을 선택하십시오. 로그인하지 않고도 공개 MCP 서버를 게시할 수 있습니다.
