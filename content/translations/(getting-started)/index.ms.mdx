## Gambaran Keseluruhan

Swipt ialah platform automasi.

## Keperluan

- Muat sisi
- iOS 27 (Sokongan peringkat pertama)
- iOS 17.4–26 (Memerlukan peranti Mac, Windows atau Linux tambahan untuk mencipta fail pasangan. Saya tidak mempunyai peranti fizikal untuk ujian, jadi sokongan akan sangat bergantung pada sumbangan luar.)

## Muat Sisi dengan Mac

Jika anda tidak mahu memasang rangka kerja muat sisi kendiri, kami mengesyorkan alat `sideload` yang terbina dalam Swipt CLI.

Alat ini menandatangani dan memasang Swipt menggunakan Xcode, jadi ia boleh:

- Menggunakan Akaun Apple yang telah anda gunakan untuk mendaftar masuk, tanpa meminta anda mendaftar masuk semula.
- Mengkonfigurasikan Swipt supaya menggunakan perpasangan sedia ada antara Mac anda dengan peranti, tanpa perlu berpasangan semula pada peranti.
- Mempercayai sijil pembangun percuma dan melakukan persediaan awal yang lain pada peranti anda.

Dalam Terminal, jalankan perintah berikut:

```shell
npm install -g @swipt/cli
swipt sideload install
```

Kemudian, ikuti gesaan untuk memilih peranti tempat Swipt akan dipasang dan pasukan yang akan digunakan untuk menandatanganinya.

Swipt melengkapkan hampir semua persediaan secara automatik, tetapi anda masih perlu memulakan VPN Gelung Balik. Lihat [Persediaan](./setup.mdx).

```shell
swipt sideload update # Kemas kini Swipt atau lanjutkan tempoh sahnya
swipt sideload uninstall # Nyahpasang Swipt
```
