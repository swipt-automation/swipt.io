## আপনার ডিভাইসের সাথে পেয়ার করুন

ডিভাইসের ডেভেলপার পরিষেবাগুলির সাথে কানেক্ট করতে আপনার ডিভাইসটিকে Swipt-এর সাথে পেয়ার করা প্রয়োজন।

আপনি যদি Swipt CLI দিয়ে Swipt সাইডলোড করে থাকেন, তাহলে পেয়ারিং স্বয়ংক্রিয়ভাবে সেট আপ হয়ে যায়। অন্যথায়, পেয়ার করতে নির্দেশাবলি অনুসরণ করুন:

আপনি যদি iOS/iPadOS 27 ব্যবহার করেন, তাহলে অ্যাপের নির্দেশাবলি অনুসরণ করে ডিভাইসেই পেয়ার করতে পারবেন:

ডিভাইসে পেয়ারিং ব্যর্থ হলে অনুগ্রহ করে একটি ইস্যু খুলুন।

আপনি যদি iOS-এর আগের কোনো ভার্সন ব্যবহার করেন এবং আপনার একটি Mac থাকে, তাহলে ম্যানুয়ালি সাইডলোড করার পরেও পেয়ারিং সেট আপ করতে `swipt sideload setup` ব্যবহার করতে পারবেন। অন্যথায়, আপনাকে অন্য সফটওয়্যার দিয়ে পেয়ার করতে হবে।

প্রায় যেকোনো অন্য সফটওয়্যার দিয়ে তৈরি পেয়ারিং ফাইল আপনি ইমপোর্ট করতে পারেন, যেমন:

- [Jitterbug](https://github.com/osy/Jitterbug): `.mobiledevicepairing`
- [idevice](https://github.com/jkcoxson/idevice): `ios_pairing_file.plist`
- [go-ios](https://github.com/danielpaulus/go-ios): `selfIdentity.plist`

পেয়ারিং ফাইল পাওয়ার সবচেয়ে প্রচলিত উপায় হলো:

1. [iloader](https://iloader.app) ডাউনলোড করে ইনস্টল করুন। Windows-এ আগে [iTunes](https://www.apple.com/itunes/download/win64) ইনস্টল করুন। Linux-এ `usbmuxd` আগে থেকে ইনস্টল করা না থাকলে সেটি ইনস্টল করুন।
2. USB কেবল দিয়ে আপনার iPhone বা iPad কম্পিউটারের সাথে কানেক্ট করুন। জিজ্ঞাসা করা হলে কম্পিউটারটিকে বিশ্বাস করুন এবং আপনার পাসকোড দিন।
3. iloader খুলুন এবং আপনার iPhone বা iPad নির্বাচন করুন।
4. “Manage Pairing File” নির্বাচন করুন।
5. “Export (Not Recommended)” নির্বাচন করুন, তারপর “Confirm” নির্বাচন করে পেয়ারিং ফাইলটি সেভ করুন।
6. পেয়ারিং ফাইলটি আপনার iPhone বা iPad-এ স্থানান্তর করুন, যেমন AirDrop বা iCloud Drive দিয়ে।

আপনি যদি আগে SideStore ইনস্টল করে থাকেন, তাহলে খুব সম্ভবত আপনার কাছে ইতিমধ্যেই একটি পেয়ারিং ফাইল আছে!

## লুপব্যাক VPN

ডেভেলপার পরিষেবাগুলির সাথে কানেক্ট করতে Swipt-এর জন্য একটি লুপব্যাক VPN প্রয়োজন। নিচের সফটওয়্যারগুলি সমর্থিত:

#### LocalDevVPN

[App Store](https://apps.apple.com/app/id6755608044) থেকে ইনস্টল করে VPN চালু করুন।

#### sing-box

[App Store](https://apps.apple.com/app/id6785326793) থেকে ইনস্টল করুন, সঠিক কনফিগারেশন লিখুন, তারপর VPN চালু করুন।

আপনাকে `tun.loopback_address` ও `tun.route_address` কনফিগার করতে হবে।

উদাহরণ কনফিগারেশন:

```json
{
  "inbounds": [
    {
      "type": "tun",
      "address": "172.19.0.1/30",
      "auto_route": true,
      "loopback_address": "10.7.0.1",
      "route_address": "10.7.0.1/32"
    }
  ],
  "route": {
    "auto_detect_interface": true
  }
}
```

রাউটারের মতো কোনো গেটওয়েতে এটি ডিপ্লয় করলে পুরো লোকাল নেটওয়ার্কের জন্য এটি কাজ করবে।

#### Clash

[App Store](https://apps.apple.com/app/id6794257189) থেকে ইনস্টল করুন, সঠিক কনফিগারেশন লিখুন, তারপর VPN চালু করুন।

আপনাকে `tun.loopback-address` কনফিগার করতে হবে:

```yaml
tun:
  loopback-address:
    - 10.7.0.1
```

#### ক্লোজড-সোর্স সফটওয়্যার

আপনি যদি Shadowrocket ব্যবহার করেন, তাহলে “সেটিংস”-এ **Include Route 10.7.0.1/32** চালু করুন, তারপর VPN আবার কানেক্ট করুন। এই অপশনটি দেখতে না পেলে Shadowrocket আপডেট করুন।

আপনি যদি সাবস্ক্রিপশন নিয়ে Surge ব্যবহার করেন, তাহলে আপনাকে `General.tun-included-routes` ও `IP Rewrite` কনফিগার করতে হবে:

```ini
[General]
tun-included-routes = %INSERT% 10.7.0.1/32

[IP Rewrite]
10.7.0.1 = reflect
```

Swipt-এর জন্য `ipv6-vif = disabled` প্রয়োজন নেই।

পাবলিক ডকুমেন্টেশন নেই এমন Surge-এর মতো অন্যান্য অ্যাপের ক্ষেত্রে, কীভাবে কনফিগার করতে হবে তা সংশ্লিষ্ট ডেভেলপারদের জিজ্ঞাসা করুন।

## স্বয়ংক্রিয় আনলক

আপনার পাসকোড সেভ করুন, যাতে ডিভাইস লক থাকলে Swipt সেটি স্বয়ংক্রিয়ভাবে আনলক করতে পারে।

নির্দিষ্টভাবে বললে, Swipt API/MCP চালু করার জন্য Swipt CLI আপনার ডিভাইস আনলক করতে পারে, এবং ডিভাইস চালানোর জন্য Swipt CLI, MCP ও ইনস্টল করা Swiplet আপনার ডিভাইস আনলক করতে পারে।
