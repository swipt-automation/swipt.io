## Panoramica

Swipt è una piattaforma di automazione.

## Requisiti

- Sideloading
- iOS 27 (supporto di primo livello)
- iOS 17.4–26 (Richiede un dispositivo Mac, Windows o Linux aggiuntivo per creare un file di abbinamento. Non ho dispositivi fisici per i test, quindi il supporto dipenderà in larga misura dai contributi esterni.)

## Sideloading con un Mac

Se non vuoi installare un framework di sideloading autonomo, ti consigliamo lo strumento `sideload` integrato in Swipt CLI.

Firma e installa Swipt tramite Xcode, quindi può:

- Usare l’Account Apple con cui hai già effettuato l’accesso, senza chiederti di accedere di nuovo.
- Configurare Swipt in modo che usi l’abbinamento già esistente tra il Mac e il dispositivo, senza doverlo ripetere sul dispositivo.
- Autorizzare il certificato sviluppatore gratuito e completare le altre operazioni di configurazione iniziale sul dispositivo.

Esegui in Terminale:

```shell
npm install -g @swipt/cli
swipt sideload install
```

Poi segui le indicazioni per scegliere il dispositivo su cui installare Swipt e il team con cui firmarlo.

Swipt completa automaticamente quasi tutta la configurazione, ma devi comunque avviare la VPN di loopback. Consulta la sezione [Configurazione](./setup.mdx).

```shell
swipt sideload update # Aggiorna Swipt o rinnovane la validità
swipt sideload uninstall # Disinstalla Swipt
```
