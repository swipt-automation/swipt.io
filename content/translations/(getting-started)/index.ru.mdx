## Обзор

Swipt — платформа автоматизации.

## Требования

- Сайдлоадинг
- iOS 27 (приоритетная поддержка)
- iOS 17.4–26 (Для создания файла пары требуется дополнительный Mac или устройство с Windows или Linux. У меня нет физических устройств для тестирования, поэтому поддержка будет во многом зависеть от внешнего вклада.)

## Сайдлоадинг с помощью Mac

Если Вы не хотите устанавливать отдельный инструмент для сайдлоадинга, рекомендуем встроенную в Swipt CLI утилиту `sideload`.

Она подписывает и устанавливает Swipt с помощью Xcode, поэтому может:

- Использовать Аккаунт Apple, в который уже выполнен вход, и не просить войти снова.
- Настроить приложение Swipt на работу с уже созданной парой между Mac и устройством, чтобы не создавать пару на устройстве заново.
- Подтвердить доверие к бесплатному сертификату разработчика и выполнить на устройстве остальную начальную настройку.

В приложении «Терминал» выполните команды:

```shell
npm install -g @swipt/cli
swipt sideload install
```

Затем следуйте подсказкам, чтобы выбрать устройство для установки и команду разработчиков для подписи.

Почти всю настройку Swipt выполнит автоматически, но Петлевой VPN нужно запустить самостоятельно. Подробнее — в разделе «[Начальная настройка](./setup.mdx)».

```shell
swipt sideload update # Обновить Swipt или продлить срок действия подписи
swipt sideload uninstall # Удалить Swipt
```
