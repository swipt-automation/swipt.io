## ನಿಮ್ಮ ಸಾಧನದೊಂದಿಗೆ ಪೇರಿಂಗ್

ಸಾಧನದ ಡೆವಲಪರ್ ಸೇವೆಗಳಿಗೆ ಕನೆಕ್ಟ್ ಆಗಲು, Swipt ಆ್ಯಪ್ ನಿಮ್ಮ ಸಾಧನದೊಂದಿಗೆ ಪೇರ್ ಆಗಬೇಕು.

ನೀವು Swipt CLI ಬಳಸಿ Swipt ಆ್ಯಪ್ ಅನ್ನು ಸೈಡ್‌ಲೋಡ್ ಮಾಡಿದ್ದರೆ, ಪೇರಿಂಗ್ ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಸೆಟಪ್ ಆಗುತ್ತದೆ. ಇಲ್ಲದಿದ್ದರೆ, ಪೇರ್ ಮಾಡಲು ಸೂಚನೆಗಳನ್ನು ಅನುಸರಿಸಿ:

ನೀವು iOS/iPadOS 27 ಬಳಸುತ್ತಿದ್ದರೆ, ಆ್ಯಪ್‌ನಲ್ಲಿನ ಸೂಚನೆಗಳನ್ನು ಅನುಸರಿಸಿ ಸಾಧನದಲ್ಲೇ ಪೇರ್ ಮಾಡಬಹುದು:

ಸಾಧನದಲ್ಲೇ ಪೇರ್ ಮಾಡುವುದು ವಿಫಲವಾದರೆ, ದಯವಿಟ್ಟು ಒಂದು ಇಶ್ಯೂ ತೆರೆಯಿರಿ.

ನೀವು iOS ನ ಹಿಂದಿನ ಆವೃತ್ತಿಯನ್ನು ಬಳಸುತ್ತಿದ್ದು ನಿಮ್ಮ ಬಳಿ Mac ಇದ್ದರೆ, ಹಸ್ತಚಾಲಿತವಾಗಿ ಸೈಡ್‌ಲೋಡ್ ಮಾಡಿದ ನಂತರವೂ ಪೇರಿಂಗ್ ಸೆಟಪ್ ಮಾಡಲು `swipt sideload setup` ಅನ್ನು ಬಳಸಬಹುದು. ಇಲ್ಲದಿದ್ದರೆ, ನೀವು ಇತರ ಸಾಫ್ಟ್‌ವೇರ್ ಬಳಸಿ ಪೇರ್ ಮಾಡಬೇಕು.

ಬಹುತೇಕ ಯಾವುದೇ ಇತರ ಸಾಫ್ಟ್‌ವೇರ್‌ನಿಂದ ರಚಿಸಲಾದ ಪೇರಿಂಗ್ ಫೈಲ್‌ಗಳನ್ನು ನೀವು ಇಂಪೋರ್ಟ್ ಮಾಡಬಹುದು, ಉದಾಹರಣೆಗೆ:

- [Jitterbug](https://github.com/osy/Jitterbug): `.mobiledevicepairing`
- [idevice](https://github.com/jkcoxson/idevice): `ios_pairing_file.plist`
- [go-ios](https://github.com/danielpaulus/go-ios): `selfIdentity.plist`

ಪೇರಿಂಗ್ ಫೈಲ್ ಪಡೆಯುವ ಅತ್ಯಂತ ಸಾಮಾನ್ಯ ವಿಧಾನ ಇಲ್ಲಿದೆ:

1. [iloader](https://iloader.app) ಅನ್ನು ಡೌನ್‌ಲೋಡ್ ಮಾಡಿ ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡಿ. Windows ನಲ್ಲಿ, ಮೊದಲು [iTunes](https://www.apple.com/itunes/download/win64) ಅನ್ನು ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡಿ. Linux ನಲ್ಲಿ, `usbmuxd` ಮೊದಲೇ ಇನ್‌ಸ್ಟಾಲ್ ಆಗಿಲ್ಲದಿದ್ದರೆ ಅದನ್ನು ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡಿ.
2. USB ಕೇಬಲ್ ಮೂಲಕ ನಿಮ್ಮ iPhone ಅಥವಾ iPad ಅನ್ನು ಕಂಪ್ಯೂಟರ್‌ಗೆ ಕನೆಕ್ಟ್ ಮಾಡಿ. ಕೇಳಿದರೆ, ಕಂಪ್ಯೂಟರ್ ಅನ್ನು ನಂಬಿ ಮತ್ತು ನಿಮ್ಮ ಪಾಸ್‌ಕೋಡ್ ನಮೂದಿಸಿ.
3. iloader ತೆರೆಯಿರಿ ಮತ್ತು ನಿಮ್ಮ iPhone ಅಥವಾ iPad ಅನ್ನು ಆಯ್ಕೆ ಮಾಡಿ.
4. “Manage Pairing File” ಆಯ್ಕೆ ಮಾಡಿ.
5. “Export (Not Recommended)” ಆಯ್ಕೆ ಮಾಡಿ, ನಂತರ “Confirm” ಆಯ್ಕೆ ಮಾಡಿ ಮತ್ತು ಪೇರಿಂಗ್ ಫೈಲ್ ಅನ್ನು ಸೇವ್ ಮಾಡಿ.
6. ಉದಾಹರಣೆಗೆ AirDrop ಅಥವಾ iCloud Drive ಬಳಸಿ, ಪೇರಿಂಗ್ ಫೈಲ್ ಅನ್ನು ನಿಮ್ಮ iPhone ಅಥವಾ iPad ಗೆ ವರ್ಗಾಯಿಸಿ.

ನೀವು ಈ ಹಿಂದೆ SideStore ಅನ್ನು ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡಿದ್ದರೆ, ನಿಮ್ಮ ಬಳಿ ಈಗಾಗಲೇ ಪೇರಿಂಗ್ ಫೈಲ್ ಇರುವ ಸಾಧ್ಯತೆ ಹೆಚ್ಚು!

## ಲೂಪ್‌ಬ್ಯಾಕ್ VPN

ಡೆವಲಪರ್ ಸೇವೆಗಳಿಗೆ ಕನೆಕ್ಟ್ ಆಗಲು Swipt ಆ್ಯಪ್‌ಗೆ ಲೂಪ್‌ಬ್ಯಾಕ್ VPN ಅಗತ್ಯವಿದೆ. ಕೆಳಗಿನ ಸಾಫ್ಟ್‌ವೇರ್‌ಗಳು ಬೆಂಬಲಿತವಾಗಿವೆ:

#### LocalDevVPN

[App Store](https://apps.apple.com/app/id6755608044) ನಿಂದ ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡಿ ಮತ್ತು VPN ಆನ್ ಮಾಡಿ.

#### sing-box

[App Store](https://apps.apple.com/app/id6785326793) ನಿಂದ ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡಿ, ಸರಿಯಾದ ಕಾನ್ಫಿಗರೇಶನ್ ಬರೆಯಿರಿ ಮತ್ತು VPN ಆನ್ ಮಾಡಿ.

ನೀವು `tun.loopback_address` ಮತ್ತು `tun.route_address` ಅನ್ನು ಕಾನ್ಫಿಗರ್ ಮಾಡಬೇಕು.

ಉದಾಹರಣೆ ಕಾನ್ಫಿಗರೇಶನ್:

```json
{
  "inbounds": [
    {
      "type": "tun",
      "address": "172.19.0.1/30",
      "auto_route": true,
      "loopback_address": "10.7.0.1",
      "route_address": "10.7.0.1/32"
    }
  ],
  "route": {
    "auto_detect_interface": true
  }
}
```

ರೂಟರ್‌ನಂತಹ ಗೇಟ್‌ವೇಯಲ್ಲಿ ಇದನ್ನು ಡಿಪ್ಲಾಯ್ ಮಾಡಿದರೆ, ಇದು ಸಂಪೂರ್ಣ ಸ್ಥಳೀಯ ನೆಟ್‌ವರ್ಕ್‌ಗೆ ಕೆಲಸ ಮಾಡುತ್ತದೆ.

#### Clash

[App Store](https://apps.apple.com/app/id6794257189) ನಿಂದ ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡಿ, ಸರಿಯಾದ ಕಾನ್ಫಿಗರೇಶನ್ ಬರೆಯಿರಿ ಮತ್ತು VPN ಆನ್ ಮಾಡಿ.

ನೀವು `tun.loopback-address` ಅನ್ನು ಕಾನ್ಫಿಗರ್ ಮಾಡಬೇಕು:

```yaml
tun:
  loopback-address:
    - 10.7.0.1
```

#### ಕ್ಲೋಸ್ಡ್-ಸೋರ್ಸ್ ಸಾಫ್ಟ್‌ವೇರ್

ನೀವು ಸಬ್‌ಸ್ಕ್ರಿಪ್ಶನ್ ಮೂಲಕ Surge ಬಳಸುತ್ತಿದ್ದರೆ, `General.tun-included-routes` ಮತ್ತು `IP Rewrite` ಅನ್ನು ಕಾನ್ಫಿಗರ್ ಮಾಡಬೇಕು:

```ini
[General]
tun-included-routes = %INSERT% 10.7.0.1/32

[IP Rewrite]
10.7.0.1 = reflect
```

Swipt ಆ್ಯಪ್‌ಗೆ `ipv6-vif = disabled` ಅಗತ್ಯವಿಲ್ಲ.

ಸಾರ್ವಜನಿಕ ದಸ್ತಾವೇಜು ಇಲ್ಲದ, Surge ನಂತಹ ಇತರ ಆ್ಯಪ್‌ಗಳನ್ನು ಕಾನ್ಫಿಗರ್ ಮಾಡುವುದು ಹೇಗೆ ಎಂದು ಅವುಗಳ ಡೆವಲಪರ್‌ಗಳನ್ನು ಕೇಳಿ.

## ಸ್ವಯಂಚಾಲಿತ ಅನ್‌ಲಾಕ್

ನಿಮ್ಮ ಪಾಸ್‌ಕೋಡ್ ಅನ್ನು ಸೇವ್ ಮಾಡಿ, ಇದರಿಂದ ಸಾಧನ ಲಾಕ್ ಆಗಿರುವಾಗ Swipt ಆ್ಯಪ್ ಅದನ್ನು ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಅನ್‌ಲಾಕ್ ಮಾಡಬಹುದು.

ನಿರ್ದಿಷ್ಟವಾಗಿ ಹೇಳುವುದಾದರೆ, Swipt API/MCP ಅನ್ನು ಪ್ರಾರಂಭಿಸಲು Swipt CLI ನಿಮ್ಮ ಸಾಧನವನ್ನು ಅನ್‌ಲಾಕ್ ಮಾಡಬಹುದು, ಮತ್ತು ಸಾಧನವನ್ನು ಆಪರೇಟ್ ಮಾಡಲು Swipt CLI, MCP ಮತ್ತು ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡಲಾದ Swiplet ನಿಮ್ಮ ಸಾಧನವನ್ನು ಅನ್‌ಲಾಕ್ ಮಾಡಬಹುದು.
