## Pasangkan dengan Perangkat Anda

Swipt perlu dipasangkan dengan perangkat Anda agar dapat terhubung ke layanan pengembangnya.

Jika Anda melakukan sideload Swipt dengan Swipt CLI, pemasangan akan disiapkan secara otomatis. Jika tidak, ikuti instruksi untuk memasangkan:

Jika Anda menggunakan iOS/iPadOS 27, Anda dapat memasangkan langsung di perangkat dengan mengikuti instruksi di app:

Jika pemasangan di perangkat gagal, silakan buka issue.

Jika Anda menggunakan versi iOS yang lebih lama dan memiliki Mac, Anda tetap dapat menggunakan `swipt sideload setup` untuk menyiapkan pemasangan setelah melakukan sideload secara manual. Jika tidak, Anda perlu memasangkan dengan perangkat lunak lain.

Anda dapat mengimpor file pemasangan yang dibuat oleh hampir semua perangkat lunak lain, termasuk:

- [Jitterbug](https://github.com/osy/Jitterbug): `.mobiledevicepairing`
- [idevice](https://github.com/jkcoxson/idevice): `ios_pairing_file.plist`
- [go-ios](https://github.com/danielpaulus/go-ios): `selfIdentity.plist`

Berikut cara paling umum untuk mendapatkan file pemasangan:

1. Unduh dan instal [iloader](https://iloader.app). Di Windows, instal [iTunes](https://www.apple.com/itunes/download/win64) terlebih dahulu. Di Linux, instal `usbmuxd` jika belum terinstal sebelumnya.
2. Hubungkan iPhone atau iPad Anda ke komputer menggunakan kabel USB. Jika diminta, percayai komputer tersebut dan masukkan kode sandi Anda.
3. Buka iloader dan pilih iPhone atau iPad Anda.
4. Pilih “Manage Pairing File”.
5. Pilih “Export (Not Recommended)”, lalu pilih “Confirm” dan simpan file pemasangan.
6. Transfer file pemasangan ke iPhone atau iPad Anda, misalnya dengan AirDrop atau iCloud Drive.

Jika Anda pernah menginstal SideStore sebelumnya, kemungkinan besar Anda sudah memiliki file pemasangan!

## VPN Loopback

Swipt memerlukan VPN loopback agar dapat terhubung ke layanan pengembang. Perangkat lunak berikut didukung:

#### LocalDevVPN

Instal dari [App Store](https://apps.apple.com/app/id6755608044), lalu nyalakan VPN.

#### sing-box

Instal dari [App Store](https://apps.apple.com/app/id6785326793), tulis konfigurasi yang benar, lalu nyalakan VPN.

Anda perlu mengonfigurasi `tun.loopback_address` dan `tun.route_address`.

Contoh konfigurasi:

```json
{
  "inbounds": [
    {
      "type": "tun",
      "address": "172.19.0.1/30",
      "auto_route": true,
      "loopback_address": "10.7.0.1",
      "route_address": "10.7.0.1/32"
    }
  ],
  "route": {
    "auto_detect_interface": true
  }
}
```

Jika diterapkan di gateway, seperti router, sing-box akan berfungsi untuk seluruh jaringan lokal.

#### Clash

Instal dari [App Store](https://apps.apple.com/app/id6794257189), tulis konfigurasi yang benar, lalu nyalakan VPN.

Anda perlu mengonfigurasi `tun.loopback-address`:

```yaml
tun:
  loopback-address:
    - 10.7.0.1
```

#### Perangkat Lunak Sumber Tertutup

Jika Anda berlangganan dan menggunakan Surge, Anda perlu mengonfigurasi `General.tun-included-routes` dan `IP Rewrite`:

```ini
[General]
tun-included-routes = %INSERT% 10.7.0.1/32

[IP Rewrite]
10.7.0.1 = reflect
```

`ipv6-vif = disabled` tidak diperlukan untuk Swipt.

Untuk app lain yang mirip Surge tetapi tidak memiliki dokumentasi publik, tanyakan kepada pengembangnya cara mengonfigurasinya.

## Buka Kunci Otomatis

Simpan kode sandi Anda agar Swipt dapat membuka kunci perangkat Anda secara otomatis saat terkunci.

Secara khusus, Swipt CLI dapat membuka kunci perangkat Anda untuk memulai Swipt API/MCP, dan Swipt CLI, MCP, serta Swiplet yang terinstal dapat membuka kunci perangkat Anda untuk mengoperasikannya.
