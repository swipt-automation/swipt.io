## جائزہ

Swipt ڈیوائس کو خودکار بنانے کا پلیٹ فارم ہے۔

## ضروریات

- سائیڈ لوڈنگ
- iOS 27 (اولین درجے کی سپورٹ)
- iOS 17.4–26 (پیئرنگ فائل بنانے کے لیے ایک اضافی Mac، Windows یا Linux ڈیوائس درکار ہے۔ میرے پاس ٹیسٹنگ کے لیے فزیکل ڈیوائسز نہیں ہیں، اس لیے سپورٹ کا زیادہ تر انحصار بیرونی تعاون پر ہوگا۔)

## Mac کے ذریعے سائیڈ لوڈ کریں

اگر آپ الگ سے سائیڈ لوڈنگ فریم ورک انسٹال نہیں کرنا چاہتے تو Swipt CLI میں شامل `sideload` ٹول استعمال کرنے کی تجویز دی جاتی ہے۔

یہ Xcode کی مدد سے Swipt پر دستخط کر کے اسے انسٹال کرتا ہے، اس لیے یہ درج ذیل کام کر سکتا ہے:

- آپ سے دوبارہ سائن اِن کرنے کو کہے بغیر اسی Apple اکاؤنٹ کا استعمال کرنا جس میں آپ پہلے سے سائن اِن ہیں۔
- Swipt کو اس طرح کنفیگر کرنا کہ وہ ڈیوائس کے ساتھ آپ کے Mac کی موجودہ پیئرنگ استعمال کرے اور ڈیوائس پر دوبارہ پیئر نہ کرنا پڑے۔
- مفت ڈیولپر سرٹیفیکیٹ پر اعتبار کرنا اور آپ کے ڈیوائس پر پہلی بار استعمال کے لیے درکار دیگر کنفیگریشن مکمل کرنا۔

Terminal ایپ میں یہ کمانڈ چلائیں:

```shell
npm install -g @swipt/cli
swipt sideload install
```

پھر ہدایات پر عمل کرتے ہوئے انسٹال کرنے کے لیے ڈیوائس اور دستخط کرنے کے لیے ٹیم منتخب کریں۔

سیٹ اپ کا تقریباً سارا کام Swipt کی طرف سے خودکار طور پر مکمل ہو جاتا ہے، لیکن لوپ بیک VPN آپ کو پھر بھی خود شروع کرنا ہو گا۔ [سیٹ اپ](./setup.mdx) دیکھیں۔

```shell
swipt sideload update # Swipt کو اپ ڈیٹ کریں یا اس کی میعاد کی تجدید کریں
swipt sideload uninstall # Swipt کو ان انسٹال کریں
```
