## Spárovanie so zariadením

Apka Swipt sa musí spárovať s vaším zariadením, aby sa mohla pripojiť k jeho vývojárskym službám.

Ak ste apku Swipt nainštalovali sideloadingom pomocou Swipt CLI, spárovanie sa nastaví automaticky. V opačnom prípade vykonajte spárovanie podľa pokynov v apke:

Ak sa spárovanie nedá dokončiť, nahláste nám problém. Prípadne môžete importovať párovací súbor z iného softvéru, napríklad:

- [Jitterbug](https://github.com/osy/Jitterbug): `.mobiledevicepairing`
- [idevice](https://github.com/jkcoxson/idevice): `ios_pairing_file.plist`
- [go-ios](https://github.com/danielpaulus/go-ios): `selfIdentity.plist`

## Loopback VPN

Apka Swipt potrebuje na pripojenie k vývojárskym službám loopback VPN. Podporovaný je tento softvér:

#### LocalDevVPN

Nainštalujte si apku z [App Storu](https://apps.apple.com/app/id6755608044) a zapnite VPN.

#### sing-box

Nainštalujte si apku z [App Storu](https://apps.apple.com/app/id6785326793), napíšte správnu konfiguráciu a zapnite VPN.

Musíte nastaviť `tun.loopback_address` a `tun.route_address`.

Vzorová konfigurácia:

```json
{
  "inbounds": [
    {
      "type": "tun",
      "address": "172.19.0.1/30",
      "auto_route": true,
      "loopback_address": "10.7.0.1",
      "route_address": "10.7.0.1/32"
    }
  ],
  "route": {
    "auto_detect_interface": true
  }
}
```

Ak sing-box nasadíte na bránu, napríklad router, bude fungovať v celej lokálnej sieti.

#### Clash

Nainštalujte si apku z [App Storu](https://apps.apple.com/app/id6794257189), napíšte správnu konfiguráciu a zapnite VPN.

Musíte nastaviť `tun.loopback-address`:

```yaml
tun:
  loopback-address:
    - 10.7.0.1
```

#### Softvér s uzavretým zdrojovým kódom

Ak máte predplatné apky Surge a používate ju, musíte nastaviť `General.tun-included-routes` a `IP Rewrite`:

```ini
[General]
tun-included-routes = %INSERT% 10.7.0.1/32

[IP Rewrite]
10.7.0.1 = reflect
```

Apka Swipt nevyžaduje nastavenie `ipv6-vif = disabled`.

Pri iných apkách podobných Surge, ktoré nemajú verejnú dokumentáciu, sa opýtajte ich vývojárov, ako to nastaviť.

## Automatické odomykanie

Uložte si kód, aby apka Swipt mohla automaticky odomknúť vaše zariadenie, keď je zamknuté.

Konkrétne môže Swipt CLI odomknúť vaše zariadenie, aby spustilo Swipt API/MCP, a Swipt CLI, MCP a nainštalované Swiplety môžu odomknúť vaše zariadenie, aby ho mohli ovládať.
