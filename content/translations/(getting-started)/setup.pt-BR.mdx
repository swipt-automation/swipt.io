## Emparelhe com seu dispositivo

O Swipt precisa se emparelhar com seu dispositivo para se conectar aos serviços de desenvolvedor dele.

Se você fez o sideload do Swipt com a Swipt CLI, o emparelhamento é configurado automaticamente. Caso contrário, siga as instruções para emparelhar:

Se você usa o iOS/iPadOS 27, pode emparelhar no próprio dispositivo seguindo as instruções no app:

Se o emparelhamento no dispositivo falhar, abra uma issue.

Se você usa uma versão anterior do iOS e tem um Mac, ainda pode usar `swipt sideload setup` para configurar o emparelhamento depois de fazer o sideload manualmente. Caso contrário, você precisa emparelhar com outro software.

Você pode importar arquivos de emparelhamento criados por quase qualquer outro software, incluindo:

- [Jitterbug](https://github.com/osy/Jitterbug): `.mobiledevicepairing`
- [idevice](https://github.com/jkcoxson/idevice): `ios_pairing_file.plist`
- [go-ios](https://github.com/danielpaulus/go-ios): `selfIdentity.plist`

Esta é a forma mais comum de obter um arquivo de emparelhamento:

1. Baixe e instale o [iloader](https://iloader.app). No Windows, instale primeiro o [iTunes](https://www.apple.com/itunes/download/win64). No Linux, instale o `usbmuxd` se ele não vier pré-instalado.
2. Conecte o iPhone ou iPad ao computador com um cabo USB. Se for solicitado, confie no computador e digite seu código.
3. Abra o iloader e selecione o iPhone ou iPad.
4. Selecione “Manage Pairing File”.
5. Selecione “Export (Not Recommended)”, depois selecione “Confirm” e salve o arquivo de emparelhamento.
6. Transfira o arquivo de emparelhamento para o iPhone ou iPad, por exemplo, com o AirDrop ou o iCloud Drive.

Se você já instalou o SideStore antes, provavelmente já tem um arquivo de emparelhamento!

## VPN de Loopback

O Swipt precisa de uma VPN de loopback para se conectar aos serviços de desenvolvedor. Os seguintes softwares são compatíveis:

#### LocalDevVPN

Instale o app pela [App Store](https://apps.apple.com/app/id6755608044) e ative a VPN.

#### sing-box

Instale o app pela [App Store](https://apps.apple.com/app/id6785326793), escreva uma configuração correta e ative a VPN.

Você precisa configurar `tun.loopback_address` e `tun.route_address`.

Exemplo de configuração:

```json
{
  "inbounds": [
    {
      "type": "tun",
      "address": "172.19.0.1/30",
      "auto_route": true,
      "loopback_address": "10.7.0.1",
      "route_address": "10.7.0.1/32"
    }
  ],
  "route": {
    "auto_detect_interface": true
  }
}
```

Ao implantar o sing-box em um gateway, como um roteador, ele funcionará para toda a rede local.

#### Clash

Instale o app pela [App Store](https://apps.apple.com/app/id6794257189), escreva uma configuração correta e ative a VPN.

Você precisa configurar `tun.loopback-address`:

```yaml
tun:
  loopback-address:
    - 10.7.0.1
```

#### Software de código fechado

Se você assina e usa o Surge, precisa configurar `General.tun-included-routes` e `IP Rewrite`:

```ini
[General]
tun-included-routes = %INSERT% 10.7.0.1/32

[IP Rewrite]
10.7.0.1 = reflect
```

`ipv6-vif = disabled` não é necessário para o Swipt.

Para outros apps semelhantes ao Surge sem documentação pública, pergunte aos respectivos desenvolvedores como fazer a configuração.

## Desbloqueio Automático

Salve seu código para que o Swipt possa desbloquear seu dispositivo automaticamente quando ele estiver bloqueado.

Especificamente, a Swipt CLI pode desbloquear seu dispositivo para iniciar a Swipt API/MCP, e a Swipt CLI, o MCP e os Swiplets instalados podem desbloquear seu dispositivo para operá-lo.
