## الإقران مع جهازك

يحتاج Swipt إلى الإقران مع جهازك للاتصال بخدمات المطور عليه.

إذا تم تحميل Swipt جانبيًا باستخدام Swipt CLI، فسيتم إعداد الإقران تلقائيًا. وإلا فيرجى اتباع التعليمات في التطبيق لإتمام الإقران:

إذا تعذر إكمال الإقران، فيرجى إبلاغنا بالمشكلة. وبدلاً من ذلك، يمكنك استيراد ملف إقران من برامج أخرى، منها:

- [Jitterbug](https://github.com/osy/Jitterbug): `.mobiledevicepairing`
- [idevice](https://github.com/jkcoxson/idevice): `ios_pairing_file.plist`
- [go-ios](https://github.com/danielpaulus/go-ios): `selfIdentity.plist`

## شبكة VPN للاسترجاع

يحتاج Swipt إلى شبكة VPN للاسترجاع للاتصال بخدمات المطور. البرامج التالية مدعومة:

#### LocalDevVPN

ثبّت التطبيق من [App Store](https://apps.apple.com/app/id6755608044) ثم شغّل شبكة VPN.

#### sing-box

ثبّت التطبيق من [App Store](https://apps.apple.com/app/id6785326793)، واكتب إعدادات صحيحة، ثم شغّل شبكة VPN.

يلزم إعداد `tun.loopback_address` و`tun.route_address`.

مثال على الإعدادات:

```json
{
  "inbounds": [
    {
      "type": "tun",
      "address": "172.19.0.1/30",
      "auto_route": true,
      "loopback_address": "10.7.0.1",
      "route_address": "10.7.0.1/32"
    }
  ],
  "route": {
    "auto_detect_interface": true
  }
}
```

يمكنك نشره على بوابة، مثل الموجّه، ليعمل على مستوى الشبكة المحلية بأكملها.

#### Clash

ثبّت التطبيق من [App Store](https://apps.apple.com/app/id6794257189)، واكتب إعدادات صحيحة، ثم شغّل شبكة VPN.

يلزم إعداد `tun.loopback-address`:

```yaml
tun:
  loopback-address:
    - 10.7.0.1
```

#### البرامج مغلقة المصدر

إذا كنت مشتركًا في Surge وتستخدمه، فيلزم إعداد `General.tun-included-routes` و`IP Rewrite`:

```ini
[General]
tun-included-routes = %INSERT% 10.7.0.1/32

[IP Rewrite]
10.7.0.1 = reflect
```

لا يتطلب Swipt ضبط `ipv6-vif = disabled`.

أما التطبيقات الأخرى المشابهة لـ Surge التي لا تتوفر لها وثائق عامة، فيرجى الاستفسار من مطوريها عن كيفية إعدادها.

## فتح القفل التلقائي

يرجى حفظ رمز الدخول ليتمكن Swipt من فتح قفل جهازك تلقائيًا عندما يكون مقفلاً.

وتحديدًا، يمكن لـ Swipt CLI فتح قفل جهازك لبدء Swipt API/MCP، ويمكن لكل من Swipt CLI وMCP وتطبيقات Swiplet المثبتة فتح قفل جهازك لتشغيله.
