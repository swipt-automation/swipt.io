## Parkoppla med enheten

Swipt måste parkopplas med enheten för att kunna ansluta till dess utvecklartjänster.

Om du har sidladdat Swipt med Swipt CLI konfigureras parkopplingen automatiskt. Följ annars anvisningarna i appen för att parkoppla:

Om det inte går att slutföra parkopplingen kan du rapportera problemet till oss. Du kan också importera en parkopplingsfil från annan programvara, till exempel:

- [Jitterbug](https://github.com/osy/Jitterbug): `.mobiledevicepairing`
- [idevice](https://github.com/jkcoxson/idevice): `ios_pairing_file.plist`
- [go-ios](https://github.com/danielpaulus/go-ios): `selfIdentity.plist`

## Loopback-VPN

Swipt behöver ett loopback-VPN för att ansluta till utvecklartjänster. Följande programvara stöds:

#### LocalDevVPN

Installera appen från [App Store](https://apps.apple.com/app/id6755608044) och slå på VPN.

#### sing-box

Installera appen från [App Store](https://apps.apple.com/app/id6785326793), skriv en korrekt konfiguration och slå på VPN.

Du måste konfigurera `tun.loopback_address` och `tun.route_address`.

Exempelkonfiguration:

```json
{
  "inbounds": [
    {
      "type": "tun",
      "address": "172.19.0.1/30",
      "auto_route": true,
      "loopback_address": "10.7.0.1",
      "route_address": "10.7.0.1/32"
    }
  ],
  "route": {
    "auto_detect_interface": true
  }
}
```

Om du kör sing-box på en gateway, till exempel en router, fungerar det för hela det lokala nätverket.

#### Clash

Installera appen från [App Store](https://apps.apple.com/app/id6794257189), skriv en korrekt konfiguration och slå på VPN.

Du måste konfigurera `tun.loopback-address`:

```yaml
tun:
  loopback-address:
    - 10.7.0.1
```

#### Programvara med sluten källkod

Om du prenumererar på och använder Surge måste du konfigurera `General.tun-included-routes` och `IP Rewrite`:

```ini
[General]
tun-included-routes = %INSERT% 10.7.0.1/32

[IP Rewrite]
10.7.0.1 = reflect
```

`ipv6-vif = disabled` behövs inte för Swipt.

För andra Surge-liknande appar utan offentlig dokumentation kan du fråga utvecklarna hur det konfigureras.

## Automatisk upplåsning

Spara lösenkoden så att Swipt kan låsa upp enheten automatiskt när den är låst.

Mer specifikt kan Swipt CLI låsa upp enheten för att starta Swipt API/MCP, och Swipt CLI, MCP och installerade Swiplets kan låsa upp enheten för att styra den.
