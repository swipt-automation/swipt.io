## Enlace con tu dispositivo

Swipt necesita enlazarse con tu dispositivo para conectarse a sus servicios de desarrollador.

Si has instalado Swipt mediante carga lateral con Swipt CLI, el enlace se configura automáticamente. De lo contrario, sigue las instrucciones para realizar el enlace:

Si usas iOS/iPadOS 27, puedes realizar el enlace en el dispositivo siguiendo las instrucciones de la app:

Si el enlace en el dispositivo falla, abre una incidencia.

Si usas una versión anterior de iOS y tienes un Mac, puedes seguir usando `swipt sideload setup` para configurar el enlace después de hacer la carga lateral manualmente. De lo contrario, necesitas realizar el enlace con otro software.

Puedes importar archivos de enlace creados con casi cualquier otro software, como los siguientes:

- [Jitterbug](https://github.com/osy/Jitterbug): `.mobiledevicepairing`
- [idevice](https://github.com/jkcoxson/idevice): `ios_pairing_file.plist`
- [go-ios](https://github.com/danielpaulus/go-ios): `selfIdentity.plist`

Esta es la forma más habitual de obtener un archivo de enlace:

1. Descarga e instala [iloader](https://iloader.app). En Windows, instala primero [iTunes](https://www.apple.com/itunes/download/win64). En Linux, instala `usbmuxd` si no viene preinstalado.
2. Conecta el iPhone o iPad al ordenador con un cable USB. Si se te solicita, confía en el ordenador e introduce tu código.
3. Abre iloader y selecciona el iPhone o iPad.
4. Selecciona “Manage Pairing File”.
5. Selecciona “Export (Not Recommended)”, después selecciona “Confirm” y guarda el archivo de enlace.
6. Transfiere el archivo de enlace al iPhone o iPad, por ejemplo, con AirDrop o iCloud Drive.

Si ya has instalado SideStore alguna vez, ¡lo más probable es que ya tengas un archivo de enlace!

## VPN de bucle invertido

Swipt necesita una VPN de bucle invertido para conectarse a los servicios de desarrollador. Se admite el siguiente software:

#### LocalDevVPN

Instala la app desde el [App Store](https://apps.apple.com/app/id6755608044) y activa la VPN.

#### sing-box

Instala la app desde el [App Store](https://apps.apple.com/app/id6785326793), escribe una configuración correcta y activa la VPN.

Tendrás que configurar `tun.loopback_address` y `tun.route_address`.

Ejemplo de configuración:

```json
{
  "inbounds": [
    {
      "type": "tun",
      "address": "172.19.0.1/30",
      "auto_route": true,
      "loopback_address": "10.7.0.1",
      "route_address": "10.7.0.1/32"
    }
  ],
  "route": {
    "auto_detect_interface": true
  }
}
```

Si despliegas sing-box en una puerta de enlace, como un router, funcionará en toda la red local.

#### Clash

Instala la app desde el [App Store](https://apps.apple.com/app/id6794257189), escribe una configuración correcta y activa la VPN.

Tendrás que configurar `tun.loopback-address`:

```yaml
tun:
  loopback-address:
    - 10.7.0.1
```

#### Software de código cerrado

Si usas Surge con una suscripción, tendrás que configurar `General.tun-included-routes` y `IP Rewrite`:

```ini
[General]
tun-included-routes = %INSERT% 10.7.0.1/32

[IP Rewrite]
10.7.0.1 = reflect
```

`ipv6-vif = disabled` no es necesario para Swipt.

Si usas otra app similar a Surge sin documentación pública, consulta a sus desarrolladores cómo configurarla.

## Desbloqueo automático

Guarda tu código para que Swipt pueda desbloquear automáticamente tu dispositivo cuando esté bloqueado.

En concreto, Swipt CLI puede desbloquear tu dispositivo para iniciar Swipt API/MCP, y Swipt CLI, MCP y los Swiplets instalados pueden desbloquear tu dispositivo para manejarlo.
