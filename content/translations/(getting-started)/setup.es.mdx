## Enlace con tu dispositivo

Swipt necesita enlazarse con tu dispositivo para conectarse a sus servicios de desarrollador.

Si has instalado Swipt mediante carga lateral con Swipt CLI, el enlace se configura automáticamente. De lo contrario, sigue las instrucciones de la app para realizar el enlace:

Si no se puede completar el enlace, comunícanos el problema. También puedes importar un archivo de enlace de otro software, como los siguientes:

- [Jitterbug](https://github.com/osy/Jitterbug): `.mobiledevicepairing`
- [idevice](https://github.com/jkcoxson/idevice): `ios_pairing_file.plist`
- [go-ios](https://github.com/danielpaulus/go-ios): `selfIdentity.plist`

## VPN de bucle invertido

Swipt necesita una VPN de bucle invertido para conectarse a los servicios de desarrollador. Sigue las instrucciones de la app para descargar y activar [LocalDevVPN](https://apps.apple.com/app/id6755608044) o [sing-box](https://sing-box.sagernet.org). Para sing-box, tendrás que importar el [perfil de ejemplo](/setup/LocalDevVPN.json).

## Desbloqueo automático

Guarda tu código para que Swipt pueda desbloquear automáticamente tu dispositivo cuando esté bloqueado.

En concreto, Swipt CLI puede desbloquear tu dispositivo para iniciar Swipt API/MCP, y Swipt CLI, MCP y los Swiplets instalados pueden desbloquear tu dispositivo para manejarlo.
