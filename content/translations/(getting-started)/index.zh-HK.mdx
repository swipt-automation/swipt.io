## 概覽

Swipt 是一個自動化平台。

## 要求

- 側載
- iOS 27（第一級支援）
- iOS 17.4–26（需要額外一部 Mac、Windows 或 Linux 裝置來建立配對檔案。我沒有實體裝置可供測試，因此相關支援將會很大程度上依賴外部貢獻。）

## 使用 Mac 側載

如果不想安裝獨立的側載框架，建議使用 Swipt CLI 內置的 `sideload` 工具。

此工具會使用 Xcode 簽署並安裝 Swipt，因此可以：

- 使用你已登入的 Apple 帳户，無需再次登入。
- 將 Swipt 設定為使用 Mac 與裝置現有的配對，無需在裝置上重新配對。
- 在裝置上信任免費開發者證書，並完成其他首次設定。

請在「終端機」中執行：

```shell
npm install -g @swipt/cli
swipt sideload install
```

然後按照提示選擇要安裝 Swipt 的裝置，以及用於簽署的團隊。

Swipt 會自動完成幾乎所有設定步驟，但你仍需啟動回繞 VPN。請參閲「[首次設定](./setup.mdx)」。

```shell
swipt sideload update # 更新 Swipt 或延長有效期
swipt sideload uninstall # 解除安裝 Swipt
```
