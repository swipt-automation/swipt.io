## 与设备配对

Swipt 需要与设备配对，才能连接其开发者服务。

如果使用 Swipt CLI 完成了侧载，配对会自动完成；否则，请根据指引完成配对：

如果使用的是 iOS/iPadOS 27，可以根据 App 内的指引在设备上完成配对：

如果在设备上配对失败，请提交 Issue。

如果使用的是更早版本的 iOS 且有 Mac，仍然可以在手动侧载后使用 `swipt sideload setup` 设置配对；否则，需要通过其他软件进行配对。

可以导入几乎任何其他软件创建的配对文件，包括：

- [Jitterbug](https://github.com/osy/Jitterbug)：`.mobiledevicepairing`
- [idevice](https://github.com/jkcoxson/idevice)：`ios_pairing_file.plist`
- [go-ios](https://github.com/danielpaulus/go-ios)：`selfIdentity.plist`

获取配对文件最常用的方法如下：

1. 下载并安装 [iloader](https://iloader.app)。在 Windows 上，请先安装 [iTunes](https://www.apple.com/itunes/download/win64)；在 Linux 上，如果未预装 `usbmuxd`，请安装它。
2. 使用 USB 线将 iPhone 或 iPad 连接到电脑。如果出现提示，请信任此电脑并输入密码。
3. 打开 iloader 并选择 iPhone 或 iPad。
4. 选择“Manage Pairing File”。
5. 选择“Export (Not Recommended)”，然后选择“Confirm”并保存配对文件。
6. 将配对文件传输到 iPhone 或 iPad，例如通过 AirDrop 或 iCloud Drive。

如果以前安装过 SideStore，很可能已经有配对文件了！

## 环回 VPN

Swipt 需要环回 VPN 才能连接开发者服务。支持以下软件：

#### LocalDevVPN

从 [App Store](https://apps.apple.com/app/id6755608044) 安装并打开 VPN。

#### sing-box

从 [App Store](https://apps.apple.com/app/id6785326793) 安装，编写正确的配置，然后打开 VPN。

需要配置 `tun.loopback_address` 和 `tun.route_address`。

示例配置：

```json
{
  "inbounds": [
    {
      "type": "tun",
      "address": "172.19.0.1/30",
      "auto_route": true,
      "loopback_address": "10.7.0.1",
      "route_address": "10.7.0.1/32"
    }
  ],
  "route": {
    "auto_detect_interface": true
  }
}
```

将其部署在路由器等网关上，即可在整个局域网中生效。

#### Clash

从 [App Store](https://apps.apple.com/app/id6794257189) 安装，编写正确的配置，然后打开 VPN。

需要配置 `tun.loopback-address`：

```yaml
tun:
  loopback-address:
    - 10.7.0.1
```

#### 闭源软件

如果你订阅并使用 Surge，需要配置 `General.tun-included-routes` 和 `IP Rewrite`：

```ini
[General]
tun-included-routes = %INSERT% 10.7.0.1/32

[IP Rewrite]
10.7.0.1 = reflect
```

Swipt 不需要 `ipv6-vif = disabled`。

对于其他没有公开文档的类 Surge App，请向其开发者咨询配置方法。

## 自动解锁

保存你的密码，以便 Swipt 可以在锁定时自动解锁你的设备。

具体来说，Swipt CLI 可以解锁设备以启动 Swipt API/MCP；Swipt CLI、MCP 和已安装的 Swiplet 可以解锁设备以进行操作。
