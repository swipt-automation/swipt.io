## Visão geral

O Swipt é uma plataforma de automatização.

## Requisitos

- Sideload
- iOS 27 (suporte de primeira linha)
- iOS 17.4–26 (Requer um Mac ou um dispositivo Windows ou Linux adicional para criar um ficheiro de emparelhamento. Não tenho dispositivos físicos para testar, pelo que o suporte dependerá muito de contribuições externas.)

## Fazer sideload com um Mac

Se não pretender instalar uma framework de sideload autónoma, recomendamos a ferramenta `sideload` integrada na Swipt CLI.

Esta ferramenta assina e instala o Swipt com o Xcode, o que lhe permite:

- usar a Conta Apple em que já tem sessão iniciada, sem pedir que volte a iniciar sessão;
- configurar o Swipt para usar o emparelhamento já existente entre o Mac e o dispositivo, sem ser necessário voltar a emparelhar no dispositivo;
- confiar no certificado gratuito de programador e realizar outras configurações iniciais no dispositivo.

No Terminal, execute:

```shell
npm install -g @swipt/cli
swipt sideload install
```

Em seguida, siga as indicações apresentadas para escolher o dispositivo onde pretende instalar e a equipa com a qual pretende assinar.

O Swipt trata automaticamente de quase toda a configuração, mas continua a ser necessário iniciar a VPN de loopback. Consulte a secção [Configuração inicial](./setup.mdx).

```shell
swipt sideload update # Atualizar o Swipt ou renovar a respetiva validade
swipt sideload uninstall # Desinstalar o Swipt
```
