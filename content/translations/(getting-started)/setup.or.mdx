## ଆପଣଙ୍କ ଡିଭାଇସ୍ ସହ ପେୟାର୍ କରନ୍ତୁ

ଡିଭାଇସ୍‌ର ଡେଭଲପର୍ ସେବା ସହ ସଂଯୋଗ କରିବା ପାଇଁ Swipt କୁ ଆପଣଙ୍କ ଡିଭାଇସ୍ ସହ ପେୟାର୍ କରିବା ଆବଶ୍ୟକ।

ଯଦି ଆପଣ Swipt CLI ସହ Swipt କୁ ସାଇଡ୍‌ଲୋଡ୍ କରିଛନ୍ତି, ତେବେ ପେୟାରିଂ ସ୍ୱୟଂଚାଳିତ ଭାବରେ ସେଟ୍ ଅପ୍ ହୁଏ। ନଚେତ୍, ପେୟାର୍ କରିବା ପାଇଁ ନିର୍ଦ୍ଦେଶାବଳୀ ଅନୁସରଣ କରନ୍ତୁ:

ଯଦି ଆପଣ iOS/iPadOS 27 ବ୍ୟବହାର କରୁଛନ୍ତି, ତେବେ ଆପ୍‌ରେ ଥିବା ନିର୍ଦ୍ଦେଶାବଳୀ ଅନୁସରଣ କରି ଆପଣ ଡିଭାଇସ୍‌ରେ ହିଁ ପେୟାର୍ କରିପାରିବେ:

ଯଦି ଡିଭାଇସ୍‌ରେ ପେୟାରିଂ ବିଫଳ ହୁଏ, ତେବେ ଦୟାକରି ଏକ ଇସ୍ୟୁ ଖୋଲନ୍ତୁ।

ଯଦି ଆପଣ iOS ର ଏକ ପୂର୍ବବର୍ତ୍ତୀ ଭର୍ଶନ୍ ବ୍ୟବହାର କରୁଛନ୍ତି ଏବଂ ଆପଣଙ୍କ ପାଖରେ ଏକ Mac ଅଛି, ତେବେ ମାନୁଆଲ୍ ଭାବରେ ସାଇଡ୍‌ଲୋଡ୍ କରିବା ପରେ ପେୟାରିଂ ସେଟ୍ ଅପ୍ କରିବା ପାଇଁ ଆପଣ ତଥାପି `swipt sideload setup` ବ୍ୟବହାର କରିପାରିବେ। ନଚେତ୍, ଆପଣଙ୍କୁ ଅନ୍ୟ ସଫ୍ଟୱେୟାର ସହ ପେୟାର୍ କରିବାକୁ ପଡ଼ିବ।

ଆପଣ ପ୍ରାୟ ଯେକୌଣସି ଅନ୍ୟ ସଫ୍ଟୱେୟାର ଦ୍ୱାରା ତିଆରି ପେୟାରିଂ ଫାଇଲ୍ ଇମ୍ପୋର୍ଟ୍ କରିପାରିବେ, ଯେପରିକି:

- [Jitterbug](https://github.com/osy/Jitterbug): `.mobiledevicepairing`
- [idevice](https://github.com/jkcoxson/idevice): `ios_pairing_file.plist`
- [go-ios](https://github.com/danielpaulus/go-ios): `selfIdentity.plist`

ପେୟାରିଂ ଫାଇଲ୍ ପାଇବାର ସବୁଠାରୁ ସାଧାରଣ ଉପାୟ ହେଉଛି:

1. [iloader](https://iloader.app) ଡାଉନ୍‌ଲୋଡ୍ କରି ଇନ୍‌ଷ୍ଟଲ୍ କରନ୍ତୁ। Windows ରେ, ପ୍ରଥମେ [iTunes](https://www.apple.com/itunes/download/win64) ଇନ୍‌ଷ୍ଟଲ୍ କରନ୍ତୁ। Linux ରେ, ଯଦି `usbmuxd` ପୂର୍ବରୁ ଇନ୍‌ଷ୍ଟଲ୍ ହୋଇନାହିଁ, ତେବେ ଏହାକୁ ଇନ୍‌ଷ୍ଟଲ୍ କରନ୍ତୁ।
2. ଏକ USB କେବୁଲ୍ ମାଧ୍ୟମରେ ଆପଣଙ୍କ iPhone କିମ୍ବା iPad କୁ ଆପଣଙ୍କ କମ୍ପ୍ୟୁଟର ସହ ସଂଯୋଗ କରନ୍ତୁ। ଯଦି ଆପଣଙ୍କୁ ପଚରାଯାଏ, ତେବେ କମ୍ପ୍ୟୁଟରକୁ ବିଶ୍ବାସ କରନ୍ତୁ ଏବଂ ଆପଣଙ୍କ ପାସ୍‌କୋଡ୍ ଲେଖନ୍ତୁ।
3. iloader ଖୋଲନ୍ତୁ ଏବଂ ଆପଣଙ୍କ iPhone କିମ୍ବା iPad ବାଛନ୍ତୁ।
4. “Manage Pairing File” ବାଛନ୍ତୁ।
5. “Export (Not Recommended)” ବାଛନ୍ତୁ, ତା’ପରେ “Confirm” ବାଛନ୍ତୁ ଏବଂ ପେୟାରିଂ ଫାଇଲ୍ ସେଭ୍ କରନ୍ତୁ।
6. ପେୟାରିଂ ଫାଇଲ୍‌କୁ ଆପଣଙ୍କ iPhone କିମ୍ବା iPad କୁ ସ୍ଥାନାନ୍ତର କରନ୍ତୁ, ଉଦାହରଣ ସ୍ୱରୂପ AirDrop କିମ୍ବା iCloud Drive ମାଧ୍ୟମରେ।

ଯଦି ଆପଣ ପୂର୍ବରୁ SideStore ଇନ୍‌ଷ୍ଟଲ୍ କରିଥିଲେ, ତେବେ ସମ୍ଭବତଃ ଆପଣଙ୍କ ପାଖରେ ପୂର୍ବରୁ ଏକ ପେୟାରିଂ ଫାଇଲ୍ ଅଛି!

## ଲୁପ୍‌ବ୍ୟାକ୍ VPN

ଡେଭଲପର୍ ସେବା ସହ ସଂଯୋଗ କରିବା ପାଇଁ Swipt କୁ ଲୁପ୍‌ବ୍ୟାକ୍ VPN ଆବଶ୍ୟକ। ନିମ୍ନଲିଖିତ ସଫ୍ଟୱେୟାର ସମର୍ଥିତ:

#### LocalDevVPN

[App Store](https://apps.apple.com/app/id6755608044) ରୁ ଇନ୍‌ଷ୍ଟଲ୍ କରି VPN ଚାଲୁ କରନ୍ତୁ।

#### sing-box

[App Store](https://apps.apple.com/app/id6785326793) ରୁ ଇନ୍‌ଷ୍ଟଲ୍ କରନ୍ତୁ, ସଠିକ୍ କନ୍‌ଫିଗରେସନ୍ ଲେଖନ୍ତୁ ଏବଂ VPN ଚାଲୁ କରନ୍ତୁ।

ଆପଣଙ୍କୁ `tun.loopback_address` ଏବଂ `tun.route_address` କନ୍‌ଫିଗର୍ କରିବାକୁ ହେବ।

ଉଦାହରଣ କନ୍‌ଫିଗରେସନ୍:

```json
{
  "inbounds": [
    {
      "type": "tun",
      "address": "172.19.0.1/30",
      "auto_route": true,
      "loopback_address": "10.7.0.1",
      "route_address": "10.7.0.1/32"
    }
  ],
  "route": {
    "auto_detect_interface": true
  }
}
```

ରାଉଟର୍ ପରି ଏକ ଗେଟ୍‌ୱେରେ ଏହାକୁ ଚଲାଇଲେ, ଏହା ସମଗ୍ର ଲୋକାଲ୍ ନେଟ୍‌ୱର୍କ୍ ପାଇଁ କାମ କରେ।

#### Clash

[App Store](https://apps.apple.com/app/id6794257189) ରୁ ଇନ୍‌ଷ୍ଟଲ୍ କରନ୍ତୁ, ସଠିକ୍ କନ୍‌ଫିଗରେସନ୍ ଲେଖନ୍ତୁ ଏବଂ VPN ଚାଲୁ କରନ୍ତୁ।

ଆପଣଙ୍କୁ `tun.loopback-address` କନ୍‌ଫିଗର୍ କରିବାକୁ ହେବ:

```yaml
tun:
  loopback-address:
    - 10.7.0.1
```

#### କ୍ଲୋଜ୍‌ଡ୍-ସୋର୍ସ ସଫ୍ଟୱେୟାର

ଯଦି ଆପଣ Shadowrocket ବ୍ୟବହାର କରୁଛନ୍ତି, ତେବେ “ସେଟିଂସ୍” ରେ **Include Route 10.7.0.1/32** ଚାଲୁ କରନ୍ତୁ, ତା’ପରେ VPN କୁ ପୁଣି ସଂଯୋଗ କରନ୍ତୁ। ଯଦି ଆପଣ ଏହି ବିକଳ୍ପ ଦେଖୁନାହାନ୍ତି, ତେବେ Shadowrocket ଅପଡେଟ୍ କରନ୍ତୁ।

ଯଦି ଆପଣ ସବସ୍କ୍ରିପସନ୍ ସହ Surge ବ୍ୟବହାର କରୁଛନ୍ତି, ତେବେ ଆପଣଙ୍କୁ `General.tun-included-routes` ଏବଂ `IP Rewrite` କନ୍‌ଫିଗର୍ କରିବାକୁ ହେବ:

```ini
[General]
tun-included-routes = %INSERT% 10.7.0.1/32

[IP Rewrite]
10.7.0.1 = reflect
```

Swipt ପାଇଁ `ipv6-vif = disabled` ଆବଶ୍ୟକ ନୁହେଁ।

ସାର୍ବଜନୀନ ଡକ୍ୟୁମେଣ୍ଟେସନ୍ ନଥିବା Surge ପରି ଅନ୍ୟ ଆପ୍‌ଗୁଡ଼ିକ ପାଇଁ, ଏହାକୁ କିପରି କନ୍‌ଫିଗର୍ କରିବେ ସେ ବିଷୟରେ ସେଗୁଡ଼ିକର ଡେଭଲପର୍‌ମାନଙ୍କୁ ପଚାରନ୍ତୁ।

## ସ୍ୱୟଂଚାଳିତ ଅନଲକ୍

ଆପଣଙ୍କ ପାସ୍‌କୋଡ୍ ସେଭ୍ କରନ୍ତୁ, ଯାହାଫଳରେ ଡିଭାଇସ୍ ଲକ୍ ଥିବା ବେଳେ Swipt ଏହାକୁ ସ୍ୱୟଂଚାଳିତ ଭାବରେ ଅନଲକ୍ କରିପାରିବ।

ନିର୍ଦ୍ଦିଷ୍ଟ ଭାବରେ, Swipt API/MCP ଆରମ୍ଭ କରିବା ପାଇଁ Swipt CLI ଆପଣଙ୍କ ଡିଭାଇସ୍ ଅନଲକ୍ କରିପାରିବ, ଏବଂ ଡିଭାଇସ୍ ପରିଚାଳନା କରିବା ପାଇଁ Swipt CLI, MCP ଓ ଇନ୍‌ଷ୍ଟଲ୍ ହୋଇଥିବା Swiplet ଆପଣଙ୍କ ଡିଭାଇସ୍ ଅନଲକ୍ କରିପାରିବେ।
