## Parowanie z urządzeniem

Aplikacja Swipt musi sparować się z Twoim urządzeniem, aby łączyć się z jego usługami deweloperskimi.

Jeśli aplikacja Swipt została zainstalowana przez sideloading za pomocą Swipt CLI, parowanie konfiguruje się automatycznie. W przeciwnym razie postępuj zgodnie z instrukcjami w aplikacji, aby wykonać parowanie:

Jeśli nie można ukończyć parowania, zgłoś nam problem. Możesz też zaimportować plik parowania z innego oprogramowania, na przykład:

- [Jitterbug](https://github.com/osy/Jitterbug): `.mobiledevicepairing`
- [idevice](https://github.com/jkcoxson/idevice): `ios_pairing_file.plist`
- [go-ios](https://github.com/danielpaulus/go-ios): `selfIdentity.plist`

## VPN pętli zwrotnej

Aplikacja Swipt potrzebuje VPN pętli zwrotnej, aby łączyć się z usługami deweloperskimi. Obsługiwane jest następujące oprogramowanie:

#### LocalDevVPN

Zainstaluj aplikację z [App Store](https://apps.apple.com/app/id6755608044) i włącz VPN.

#### sing-box

Zainstaluj aplikację z [App Store](https://apps.apple.com/app/id6785326793), napisz poprawną konfigurację i włącz VPN.

Musisz skonfigurować `tun.loopback_address` i `tun.route_address`.

Przykładowa konfiguracja:

```json
{
  "inbounds": [
    {
      "type": "tun",
      "address": "172.19.0.1/30",
      "auto_route": true,
      "loopback_address": "10.7.0.1",
      "route_address": "10.7.0.1/32"
    }
  ],
  "route": {
    "auto_detect_interface": true
  }
}
```

Jeśli wdrożysz sing-box na bramie sieciowej, np. routerze, będzie działać w całej sieci lokalnej.

#### Clash

Zainstaluj aplikację z [App Store](https://apps.apple.com/app/id6794257189), napisz poprawną konfigurację i włącz VPN.

Musisz skonfigurować `tun.loopback-address`:

```yaml
tun:
  loopback-address:
    - 10.7.0.1
```

#### Oprogramowanie o zamkniętym kodzie źródłowym

Jeśli masz subskrypcję aplikacji Surge i jej używasz, musisz skonfigurować `General.tun-included-routes` i `IP Rewrite`:

```ini
[General]
tun-included-routes = %INSERT% 10.7.0.1/32

[IP Rewrite]
10.7.0.1 = reflect
```

Aplikacja Swipt nie wymaga ustawienia `ipv6-vif = disabled`.

W przypadku innych aplikacji podobnych do Surge, które nie mają publicznej dokumentacji, zapytaj ich twórców, jak to skonfigurować.

## Automatyczne odblokowywanie

Zachowaj swój kod, aby aplikacja Swipt mogła automatycznie odblokowywać Twoje urządzenie, gdy jest zablokowane.

Dokładniej rzecz biorąc, Swipt CLI może odblokować Twoje urządzenie, aby uruchomić Swipt API/MCP, a Swipt CLI, MCP i zainstalowane Swiplety mogą odblokować Twoje urządzenie, aby je obsługiwać.
