## Parowanie z urządzeniem

Aplikacja Swipt musi sparować się z Twoim urządzeniem, aby łączyć się z jego usługami deweloperskimi.

Jeśli aplikacja Swipt została zainstalowana przez sideloading za pomocą Swipt CLI, parowanie konfiguruje się automatycznie. W przeciwnym razie postępuj zgodnie z instrukcjami, aby wykonać parowanie:

Jeśli używasz systemu iOS/iPadOS 27, możesz wykonać parowanie na urządzeniu, postępując zgodnie z instrukcjami w aplikacji:

Jeśli parowanie na urządzeniu się nie powiedzie, utwórz zgłoszenie.

Jeśli używasz starszej wersji systemu iOS i masz Maca, po ręcznym sideloadingu nadal możesz skonfigurować parowanie za pomocą polecenia `swipt sideload setup`. W przeciwnym razie musisz wykonać parowanie za pomocą innego oprogramowania.

Możesz zaimportować pliki parowania utworzone przez niemal każde inne oprogramowanie, na przykład:

- [Jitterbug](https://github.com/osy/Jitterbug): `.mobiledevicepairing`
- [idevice](https://github.com/jkcoxson/idevice): `ios_pairing_file.plist`
- [go-ios](https://github.com/danielpaulus/go-ios): `selfIdentity.plist`

Oto najpopularniejszy sposób uzyskania pliku parowania:

1. Pobierz i zainstaluj [iloader](https://iloader.app). W systemie Windows najpierw zainstaluj [iTunes](https://www.apple.com/itunes/download/win64). W systemie Linux zainstaluj `usbmuxd`, jeśli nie jest preinstalowany.
2. Podłącz iPhone’a lub iPada do komputera kablem USB. Jeśli pojawi się monit, zaufaj komputerowi i wprowadź kod.
3. Otwórz iloader i wybierz iPhone’a lub iPada.
4. Wybierz „Manage Pairing File”.
5. Wybierz „Export (Not Recommended)”, następnie wybierz „Confirm” i zapisz plik parowania.
6. Przenieś plik parowania na iPhone’a lub iPada, na przykład przez AirDrop lub iCloud Drive.

Jeśli wcześniej instalowano SideStore, najprawdopodobniej masz już plik parowania!

## VPN pętli zwrotnej

Aplikacja Swipt potrzebuje VPN pętli zwrotnej, aby łączyć się z usługami deweloperskimi. Obsługiwane jest następujące oprogramowanie:

#### LocalDevVPN

Zainstaluj aplikację z [App Store](https://apps.apple.com/app/id6755608044) i włącz VPN.

#### sing-box

Zainstaluj aplikację z [App Store](https://apps.apple.com/app/id6785326793), napisz poprawną konfigurację i włącz VPN.

Musisz skonfigurować `tun.loopback_address` i `tun.route_address`.

Przykładowa konfiguracja:

```json
{
  "inbounds": [
    {
      "type": "tun",
      "address": "172.19.0.1/30",
      "auto_route": true,
      "loopback_address": "10.7.0.1",
      "route_address": "10.7.0.1/32"
    }
  ],
  "route": {
    "auto_detect_interface": true
  }
}
```

Jeśli wdrożysz sing-box na bramie sieciowej, np. routerze, będzie działać w całej sieci lokalnej.

#### Clash

Zainstaluj aplikację z [App Store](https://apps.apple.com/app/id6794257189), napisz poprawną konfigurację i włącz VPN.

Musisz skonfigurować `tun.loopback-address`:

```yaml
tun:
  loopback-address:
    - 10.7.0.1
```

#### Oprogramowanie o zamkniętym kodzie źródłowym

Jeśli używasz aplikacji Shadowrocket, włącz **Include Route 10.7.0.1/32** w Ustawieniach, a następnie ponownie połącz się z VPN. Jeśli nie widzisz tej opcji, uaktualnij aplikację Shadowrocket.

Jeśli masz subskrypcję aplikacji Surge i jej używasz, musisz skonfigurować `General.tun-included-routes` i `IP Rewrite`:

```ini
[General]
tun-included-routes = %INSERT% 10.7.0.1/32

[IP Rewrite]
10.7.0.1 = reflect
```

Aplikacja Swipt nie wymaga ustawienia `ipv6-vif = disabled`.

W przypadku innych aplikacji podobnych do Surge, które nie mają publicznej dokumentacji, zapytaj ich twórców, jak to skonfigurować.

## Automatyczne odblokowywanie

Zachowaj swój kod, aby aplikacja Swipt mogła automatycznie odblokowywać Twoje urządzenie, gdy jest zablokowane.

Dokładniej rzecz biorąc, Swipt CLI może odblokować Twoje urządzenie, aby uruchomić Swipt API/MCP, a Swipt CLI, MCP i zainstalowane Swiplety mogą odblokować Twoje urządzenie, aby je obsługiwać.
