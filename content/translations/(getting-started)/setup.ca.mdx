## Enllaç amb el dispositiu

L’app Swipt s’ha d’enllaçar amb el teu dispositiu per connectar-se als seus serveis de desenvolupador.

Si has instal·lat Swipt mitjançant càrrega lateral amb la Swipt CLI, l’enllaç es configura automàticament. Si no, segueix les instruccions per fer l’enllaç:

Si utilitzes l’iOS/iPadOS 27, pots fer l’enllaç al mateix dispositiu seguint les instruccions de l’app:

Si l’enllaç al dispositiu falla, obre una incidència.

Si utilitzes una versió anterior de l’iOS i tens un Mac, encara pots fer servir `swipt sideload setup` per configurar l’enllaç després de fer la càrrega lateral manualment. Si no, has de fer l’enllaç amb un altre programari.

Pots importar arxius d’enllaç creats amb gairebé qualsevol altre programari, com ara:

- [Jitterbug](https://github.com/osy/Jitterbug): `.mobiledevicepairing`
- [idevice](https://github.com/jkcoxson/idevice): `ios_pairing_file.plist`
- [go-ios](https://github.com/danielpaulus/go-ios): `selfIdentity.plist`

Aquesta és la manera més habitual d’obtenir un arxiu d’enllaç:

1. Descarrega i instal·la [iloader](https://iloader.app). Al Windows, instal·la primer l’[iTunes](https://www.apple.com/itunes/download/win64). Al Linux, instal·la `usbmuxd` si no està preinstal·lat.
2. Connecta l’iPhone o l’iPad a l’ordinador amb un cable USB. Si se’t demana, confia en l’ordinador i introdueix el codi.
3. Obre iloader i selecciona l’iPhone o l’iPad.
4. Selecciona “Manage Pairing File”.
5. Selecciona “Export (Not Recommended)”, després selecciona “Confirm” i desa l’arxiu d’enllaç.
6. Transfereix l’arxiu d’enllaç a l’iPhone o l’iPad, per exemple, amb AirDrop o l’iCloud Drive.

Si ja havies instal·lat SideStore abans, el més probable és que ja tinguis un arxiu d’enllaç!

## VPN de bucle local

L’app Swipt necessita una VPN de bucle local per connectar-se als serveis de desenvolupador. S’admet el programari següent:

#### LocalDevVPN

Instal·la l’app des de l’[App Store](https://apps.apple.com/app/id6755608044) i activa la VPN.

#### sing-box

Instal·la l’app des de l’[App Store](https://apps.apple.com/app/id6785326793), escriu una configuració correcta i activa la VPN.

Has de configurar `tun.loopback_address` i `tun.route_address`.

Exemple de configuració:

```json
{
  "inbounds": [
    {
      "type": "tun",
      "address": "172.19.0.1/30",
      "auto_route": true,
      "loopback_address": "10.7.0.1",
      "route_address": "10.7.0.1/32"
    }
  ],
  "route": {
    "auto_detect_interface": true
  }
}
```

Si despleges sing-box en una passarel·la, com ara un router, funcionarà a tota la xarxa local.

#### Clash

Instal·la l’app des de l’[App Store](https://apps.apple.com/app/id6794257189), escriu una configuració correcta i activa la VPN.

Has de configurar `tun.loopback-address`:

```yaml
tun:
  loopback-address:
    - 10.7.0.1
```

#### Programari de codi tancat

Si tens una subscripció a Surge i l’utilitzes, has de configurar `General.tun-included-routes` i `IP Rewrite`:

```ini
[General]
tun-included-routes = %INSERT% 10.7.0.1/32

[IP Rewrite]
10.7.0.1 = reflect
```

L’app Swipt no necessita `ipv6-vif = disabled`.

Per a altres apps semblants a Surge sense documentació pública, pregunta als seus desenvolupadors com s’han de configurar.

## Desbloqueig automàtic

Desa el codi perquè l’app Swipt pugui desbloquejar automàticament el dispositiu quan estigui bloquejat.

Concretament, la Swipt CLI pot desbloquejar el dispositiu per iniciar Swipt API/MCP, i la Swipt CLI, MCP i els Swiplets instal·lats poden desbloquejar el dispositiu per fer-lo servir.
