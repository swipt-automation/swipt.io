## Enllaç amb el dispositiu

L’app Swipt s’ha d’enllaçar amb el teu dispositiu per connectar-se als seus serveis de desenvolupador.

Si has instal·lat Swipt mitjançant càrrega lateral amb la Swipt CLI, l’enllaç es configura automàticament. Si no, segueix les instruccions de l’app per fer l’enllaç:

Si no es pot completar l’enllaç, comunica’ns el problema. També pots importar un arxiu d’enllaç d’altre programari, com ara:

- [Jitterbug](https://github.com/osy/Jitterbug): `.mobiledevicepairing`
- [idevice](https://github.com/jkcoxson/idevice): `ios_pairing_file.plist`
- [go-ios](https://github.com/danielpaulus/go-ios): `selfIdentity.plist`

## VPN de bucle local

L’app Swipt necessita una VPN de bucle local per connectar-se als serveis de desenvolupador. S’admet el programari següent:

#### LocalDevVPN

Instal·la l’app des de l’[App Store](https://apps.apple.com/app/id6755608044) i activa la VPN.

#### sing-box

Instal·la l’app des de l’[App Store](https://apps.apple.com/app/id6785326793), escriu una configuració correcta i activa la VPN.

Has de configurar `tun.loopback_address` i `tun.route_address`.

Exemple de configuració:

```json
{
  "inbounds": [
    {
      "type": "tun",
      "address": "172.19.0.1/30",
      "auto_route": true,
      "loopback_address": "10.7.0.1",
      "route_address": "10.7.0.1/32"
    }
  ],
  "route": {
    "auto_detect_interface": true
  }
}
```

Si despleges sing-box en una passarel·la, com ara un router, funcionarà a tota la xarxa local.

#### Clash

Instal·la l’app des de l’[App Store](https://apps.apple.com/app/id6794257189), escriu una configuració correcta i activa la VPN.

Has de configurar `tun.loopback-address`:

```yaml
tun:
  loopback-address:
    - 10.7.0.1
```

#### Programari de codi tancat

Si tens una subscripció a Surge i l’utilitzes, has de configurar `General.tun-included-routes` i `IP Rewrite`:

```ini
[General]
tun-included-routes = %INSERT% 10.7.0.1/32

[IP Rewrite]
10.7.0.1 = reflect
```

L’app Swipt no necessita `ipv6-vif = disabled`.

Per a altres apps semblants a Surge sense documentació pública, pregunta als seus desenvolupadors com s’han de configurar.

## Desbloqueig automàtic

Desa el codi perquè l’app Swipt pugui desbloquejar automàticament el dispositiu quan estigui bloquejat.

Concretament, la Swipt CLI pot desbloquejar el dispositiu per iniciar Swipt API/MCP, i la Swipt CLI, MCP i els Swiplets instal·lats poden desbloquejar el dispositiu per fer-lo servir.
