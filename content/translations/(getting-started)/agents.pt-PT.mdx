## Instalar Skills

#### Claude Code

No Claude Code:

```shell
/plugin marketplace add swipt-automation/skills
/plugin install swipt@swipt-skills
```

Com a Claude Code CLI:

```shell
claude plugin marketplace add swipt-automation/skills
claude plugin install swipt@swipt-skills
```

#### Claude

Em Definições > Plug-ins:

- Selecione Adicionar > Adicionar mercado > Adicionar a partir de repositório e, em seguida, introduza `https://github.com/swipt-automation/skills`.
- Mude para Descobrir, pesquise Swipt e selecione Adicionar.

#### Outros ambientes

```shell
npx skills add swipt-automation/skills
```

## Utilizar a CLI e o MCP

Se tiver instalado o Swipt com `swipt sideload install`, a API local já está ativada e os agentes na rede local podem utilizar o seu dispositivo.

Para utilizar o Swipt em aplicações compatíveis apenas com MCP, como o Claude ou o ChatGPT, aceda a Programador > API > Cloudflare no Swipt e selecione Quick Tunnel para publicar um servidor MCP público sem iniciar sessão.
