## Koppelen met je apparaat

Swipt moet met je apparaat koppelen om verbinding te maken met de ontwikkelaarsdiensten op het apparaat.

Als je Swipt via sideloading met de Swipt CLI hebt geïnstalleerd, wordt de koppeling automatisch ingesteld. Volg anders de instructies in de app om te koppelen:

Als het koppelen niet lukt, meld het probleem dan bij ons. Je kunt ook een koppelbestand uit andere software importeren, waaronder:

- [Jitterbug](https://github.com/osy/Jitterbug): `.mobiledevicepairing`
- [idevice](https://github.com/jkcoxson/idevice): `ios_pairing_file.plist`
- [go-ios](https://github.com/danielpaulus/go-ios): `selfIdentity.plist`

## Loopback-VPN

Swipt heeft een loopback-VPN nodig om verbinding te maken met ontwikkelaarsdiensten. De volgende software wordt ondersteund:

#### LocalDevVPN

Installeer de app via de [App Store](https://apps.apple.com/app/id6755608044) en schakel VPN in.

#### sing-box

Installeer de app via de [App Store](https://apps.apple.com/app/id6785326793), schrijf een correcte configuratie en schakel VPN in.

Je moet `tun.loopback_address` en `tun.route_address` configureren.

Voorbeeldconfiguratie:

```json
{
  "inbounds": [
    {
      "type": "tun",
      "address": "172.19.0.1/30",
      "auto_route": true,
      "loopback_address": "10.7.0.1",
      "route_address": "10.7.0.1/32"
    }
  ],
  "route": {
    "auto_detect_interface": true
  }
}
```

Als je sing-box op een gateway zoals een router inzet, werkt het voor het hele lokale netwerk.

#### Clash

Installeer de app via de [App Store](https://apps.apple.com/app/id6794257189), schrijf een correcte configuratie en schakel VPN in.

Je moet `tun.loopback-address` configureren:

```yaml
tun:
  loopback-address:
    - 10.7.0.1
```

#### Closed-source software

Als je een Surge-abonnement hebt en Surge gebruikt, moet je `General.tun-included-routes` en `IP Rewrite` configureren:

```ini
[General]
tun-included-routes = %INSERT% 10.7.0.1/32

[IP Rewrite]
10.7.0.1 = reflect
```

`ipv6-vif = disabled` is niet nodig voor Swipt.

Voor andere Surge-achtige apps zonder openbare documentatie vraag je de ontwikkelaars hoe je ze instelt.

## Automatische ontgrendeling

Bewaar je toegangscode zodat Swipt je apparaat automatisch kan ontgrendelen wanneer het vergrendeld is.

Concreet kan de Swipt CLI je apparaat ontgrendelen om de Swipt API/MCP te starten, en kunnen de Swipt CLI, MCP en geïnstalleerde Swiplets je apparaat ontgrendelen om het te bedienen.
