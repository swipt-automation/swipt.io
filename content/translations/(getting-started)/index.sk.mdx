## Prehľad

Swipt je automatizačná platforma.

## Požiadavky

- Sideloading
- iOS 27 (prioritná podpora)
- iOS 17.4–26 (Na vytvorenie párovacieho súboru je potrebný ďalší Mac alebo zariadenie so systémom Windows či Linux. Nemám fyzické zariadenia na testovanie, takže podpora bude vo veľkej miere závisieť od externých príspevkov.)

## Sideloading pomocou Macu

Ak nechcete inštalovať samostatný framework na sideloading, odporúčame nástroj `sideload` vstavaný v Swipt CLI.

Apku Swipt podpíše a nainštaluje pomocou Xcode, takže dokáže:

- Použiť Apple účet, do ktorého ste už prihlásení, takže sa nemusíte znova prihlasovať.
- Nastaviť apku Swipt na používanie existujúceho spárovania Macu so zariadením, takže na zariadení netreba znova párovať.
- Dôverovať bezplatnému vývojárskemu certifikátu a vykonať na zariadení ďalšie úvodné nastavenia.

V apke Terminál spustite:

```shell
npm install -g @swipt/cli
swipt sideload install
```

Potom podľa pokynov vyberte zariadenie, na ktoré sa má apka nainštalovať, a tím, ktorý sa použije na podpísanie.

Takmer celé úvodné nastavenie dokončí apka Swipt automaticky, ale stále musíte spustiť Loopback VPN. Pozrite si časť [Úvodné nastavenie](./setup.mdx).

```shell
swipt sideload update # Aktualizovať apku Swipt alebo predĺžiť jej platnosť
swipt sideload uninstall # Odinštalovať apku Swipt
```
